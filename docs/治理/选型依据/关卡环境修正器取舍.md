# 关卡环境修正器取舍

DEC-ENVIRONMENT-MODIFIERS · 2026-09-07；所有者批准建议纳入文档，具体结构与边界为受托DECIDED，玩法参数为TEST。

## 问题与选择

所有者提出地点电磁风暴使电子设备间歇失效、低重力等环境条件，并要求查同类游戏拓展建议；阅读候选后要求加入文档。将环境作为普通关卡也能使用的地点条件，特殊活动引用相同定义。唯一内容入口为[环境候选与验证](../../内容/设施与资源/关卡环境修正器候选与验证.md)，保留原设施候选及稳定ID，活动目录仅引用，不重复维护。

所有者随后明确要求架构支持日/周挑战复用，并确认Primary伤害×2且禁Secondary、无限工具使用、Energy端口无限供能等方向，再要求参考以撒、深岩、GTFO等扩充玩家/敌人强化。候选分别进入[活动总入口](../../内容/活动/特殊活动修改器候选库.md)和[战斗强化目录](../../内容/活动/玩家与敌人强化修改器候选.md)，技术责任为[共享运行合同](../../技术/关卡与活动修改器编译及运行合同.md)。这项明确授权允许特殊挑战改变普通有限资源/双槽规则，不授权普通配件无限资源或无限实体。

目标是让现有潜行、持续追杀、有限资源与设施操纵出现新的选择。接受能被队伍利用的风险，保留有利环境与正常环境；不将环境数量、原型顺序或建议组合解释为商业首发承诺。

## 方案取舍

| 选择 | 理由 | 淘汰或保留的替代方向 |
|---|---|---|
| 地点条件与活动共用定义 | 普通任务也能获得环境差异，组合与恢复只需一份真相 | 淘汰活动独占和两份近似目录 |
| 电磁风暴先影响电子辅助与自动炮塔，明确保护核心射击 | 产生停机窗口且保留双电子枪合法配装；敌我同类设备同规则 | 不采用无前兆全电器停机；关键设施扩展须有安全状态、可解性和恢复合同 |
| 低重力先做固定方向的局部区域 | 先检验空间和投掷变化，控制导航、搬运与相机验证范围 | 暂不引入零重力和随机翻转；全Site低重力保留为后续验证可能 |
| 优先风暴、工业噪声、积水，再低重力 | 前三项直接利用当前设施与潜行动词，低重力牵涉更多移动边界 | 不同时制作全候选；先后顺序不是实测成本排名 |
| 热泄漏遵循当前枪械无Heat | 设施热风险可以成立，无需改变已批准枪械规则 | 旧“影响所有Energy散热”不适用于当前枪械；未来持续输出平台必须另过准入 |
| 类型化成本免除和无限供给来源 | 直接表达所有者趣味规则，保持单次结果、库存与奖励可追溯 | 淘汰巨大整数、每帧补满、先扣后返和独立无限资源经济 |
| 玩家强化、敌人强化、双方变化分别保存 | 既提供爽快规则，也提供可读的新敌情；所有候选有明确目标与能力需求 | 不强制每个玩家Buff附惩罚；不复制遗物成长、日常排行榜或一次游玩限制 |

## 约束、影响与重审

责任接口涉及任务环境初态/Seed锁定、设施状态与声音传播、敌人合法感知、电子辅助显示、重力与导航、恢复快照和活动组合准入。具体合同与验收由环境内容及相关上游规则维护，不在此复制字段。现有十二个程序任务配置不会自动加载新条件；候选必须有对应空间能力和配置证据才能进入批准池。

出现以下任一结果即重审：玩家主要在等待；某类配装整局失效；单人、搬运或撤离软锁；敌人无说明免疫；环境成为无限资源/安全击杀漏洞；关卡验证成本超过它产生的战术差异。先调整范围、动作和空间；无新证据不靠提高奖励或堆更多修正器掩盖问题。

任务落位由[修改器任务映射与组合准入](../../内容/任务/修改器任务映射与组合准入.md)拥有；2026-09-07受托补齐四环境、三趣味规则及两项低依赖强化。选择先做快速整备/贯列弹道，是因为它们能复用九枪已有动作与贯穿结果，不需要先增加新敌人部位表现或AI优先级；正面增甲/反工事习性与全候选保留在下一层，不伪称成本已实测。

具体取舍：局部周期有常态可走路线，拒绝只准卡秒等机器；噪声只掩蔽普通移动/操作，拒绝免费静音枪与重置追杀；积水使用有限故障储能与干侧控制，拒绝第二份无限触电池；无限工具保留损伤/有成本维修和公开并发，允许覆盖有限战斗；端口固定前向落位，拒绝强迫回跑充能或偷减普通Ammo。环境不抢关键任务能力，取证不改真相，货运不改成慢车。已有设施/可选端口条件不满足则拒绝候选，不能为过Gate临时增敌或免费供电。

纸面九组组合采用明确清单而非任意相乘；不列出不等于永远删除。参数责任仍在原环境/活动/强化目录，本文不复制表。游戏验证依赖实施Gate；使用同图正常/单项对照，再验证组合、多人、迁移和可访问性。外部资料只支持借鉴模式，证据入口见[研究与批准边界](../../sources/证据登记与覆盖限制.md)；没有Unity构建、真人试玩、成本基准或外部独立审阅。
