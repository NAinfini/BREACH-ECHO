# Visual DNA：分层壁垒

## 本次任务与验收

起始提交：`df27f9c3652892e1d2b2ada761ab4b955a32d5f9`。本次只决定可观察、可生产的视觉语法，不把概念图当作 Unity 实机、性能或玩家测试证据。

完成条件：三套候选按同一权重比较；选出唯一母体并说明另外两套的去留；明确形状、轮廓、明度、颜色、材质、光照、细节、运动、VFX 与 UI 约束；同步视觉、资产、风险、准备度与所有者队列；通过文档自测试、链接与登记检查。实机场景、Steam Deck 性能、陌生玩家五秒识别和正式资产管线仍是后续 Gate。

## 决定

VISUALDNA-001 · DECIDED · 权威：项目所有者在本轮明确委托比较与锁定，由美术指导作受托选择。

**唯一 Visual DNA 锁定为“分层壁垒 / Layered Bastion”。** 它不是橙青配色模板，而是一个世界构造规则：人类把可维修、可替换、可识别的工业生存层，搭建在不可完全理解的筑路者巨构之上；虚空兽则以不服从任何工程网格的有机体量侵入两者。

`layered-bastion.png` 是当前主视觉目标。`resonance-austerity.png` 不再是平行候选，只保留其环形负空间、连续巨构和极少接口作为筑路者子语言参考。`maintenance-brutalism.png` 不作为全局方向；其中的威胁尺度和冷暖分区只可用于稀有场景，不得带回其高成本写实噪声。

## 同权比较

这是基于现有概念图、玩法合同与生产约束的桌面评审，不是玩家调研。每项 1 至 5 分，按权重折算为 100 分。

| 评估项 | 权重 | 维护巨构 | 分层壁垒 | 共振肃穆 |

| 战斗、潜行与交互可读性 | 25 | 4 | 5 | 3 |

| 程序关卡与模块复用 | 15 | 3 | 5 | 3 |
| 单人制作与混合资产收敛 | 15 | 2 | 4 | 3 |

### 维护巨构：淘汰为全局母体

优点是威胁规模、FPS 构图和明暗分区直接；缺点是依赖大量定制巨构、写实材质与高密度表面，最容易变成“另一款昂贵的黑暗科幻射击”。它对购买资产的统一修整要求最高，也没有自然解释人类层与筑路者层的视觉关系。

### 分层壁垒：胜出

它把玩法和生产问题变成同一套画面结构。暖色、矩形、可维修的人类层承载终端、炮塔、补给、路线和掩体；冷色、连续、大尺度的筑路者层承载异常空间与远古基础设施；虚空兽以破坏网格和轮廓的体量出现。脚手架、管线、梯道和普通机械可安全使用合格外部基础资产，原创投入集中在界桥、核心武器、角色轮廓和敌人主体。

主要风险是橙青对比、脚手架和工业杂物很容易滑向通用科幻。解决方式不是增加更多细节，而是限制颜色职责、减少微型噪声、强化三种造物体系的形状差异。

### 共振肃穆：降级为筑路者子语言

它的环、连续曲面、巨大负空间和少量能量裂隙最能建立筑路者身份；但若作为整款游戏母体，会产生低交互密度、低人类生活痕迹、过大空间和大面积低明度，削弱程序任务、资源搜索与近距离战术。它只服务筑路者原生区域、界桥核心和重大揭示，不支配普通人类设施。

## 约束与后果

VISUALDNA-002 · DECIDED。

- 人类层必须看出维护路径、载荷、连接、磨损和临时修复；筑路者层必须看出连续、尺度失配、环形负空间和少量精确接口；虚空兽不得自然贴合建筑网格。
- 人类资产允许广泛 Kitbash；筑路者核心结构、界桥、虚空兽主体、固定角色关键轮廓和标志性武器外壳需要原创控制。
- 青色只表示界桥、网络或筑路者能量；琥珀色只表示人类工作照明、维护或可用设施；红色表示即时危险或不可恢复失败。任何关键状态同时使用形状、动作、图标或声音，不靠颜色单独传达。
- 画面以大形体和中尺度功能件建立层级；微型 greeble、污渍、线缆和贴花不得淹没交互边缘、敌人前兆或路线。
- 未来资产即使单独更漂亮，只要破坏三层造物语法，就不能进入正式内容包。

## 工业方向与低模取舍

VISUALDNA-003 · DECIDED · 权威：项目所有者提出模型质量与产能风险，由美术指导在已委托范围内裁决。

**保留工业方向，但把生产目标从容易失控的高写实收敛为中等多边形风格化工业；不转成全局低模。** 低模只减少部分表面建模工时，并不会自动解决比例、轮廓、UV、材质统一、绑定、权重、动画穿插、第一人称手部接触或 Unity 导入。把整个项目改成低模还会削弱维护巨构的重量、潜行恐怖的材质线索和三类造物体系的差异，却仍然要支付角色与武器动画成本。

可控方案是选择性精度：环境主要靠模块 Kit、Trim Sheet、平铺材质、贴花、灯光和少量英雄件形成质量；低模用于灰盒、远景、普通小道具、碰撞代理和 LOD；精度集中在第一人称武器/手部接触、角色关节、敌人轮廓与弱点、关键机械交互。AI 生成、免费或购买模型都只是原料，必须通过人工或智能体辅助的拓扑、UV、材质、Rig/权重、动画与游戏内验收。

本决定不锁死统一三角面数。模型预算按资产类别、屏幕占比、变形和实测性能制定；若 Style Target 证明中等多边形方案在目标硬件仍不可行，应先减少材质槽、阴影、透明层、微型几何和远景密度，再以证据评估是否缩减局部资产档位，而不是直接改写整款游戏的视觉身份。

## 被否决方案

不采用三套视觉按区域并列、统一后处理强行缝合、照片级 AAA 写实、纯低模卡通、纯复古低分辨率或“所有异常都发青光”的方案。它们分别造成身份漂移、制作成本失控、与严肃战术不符或玩法信息拥堵。

## 重新审议条件

只有以下实证可重新打开本决定：Unity 灰盒上无法稳定区分三种造物体系；目标硬件在代表场景无法达到性能预算且优化会破坏核心语法；至少两类关键资产在规范化管线中持续需要不可接受的人工修整；或五秒识别测试显示项目仍被多数参与者归为通用科幻。单个商城包、单张漂亮概念图或临时生成结果不构成推翻理由。

## 实施与测试

先制作一个同屏 Style Target：人类维修通道、筑路者环形支撑、一个休眠虚空兽、可交互终端、门状态、炮塔、武器与最小 HUD。固定相机、种子、分辨率、URP版本、色彩空间和曝光，采集亮区、暗区、潜行、战斗、VFX 与 UI 叠加状态。未完成这些测试前，Visual DNA 已锁，但 Visual Production Gate 仍未通过。
