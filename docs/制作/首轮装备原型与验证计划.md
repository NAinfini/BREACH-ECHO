## 为什么是这一批

EQUIPMENT-FIRST-BATCH-002 · DECIDED / 选择理由。

两个枪槽不需要数量或技术家族对称。第一批Secondary暂不做电磁枪，是为了先验证普通弱点重击与能量群伤；这不是电磁不能进入Secondary，也不是Primary更高级。第二目录已经为磁轨、磁锚等保留明确候选归属。现有五加四只是本次筛选结果，没有成为永久配额。

三种当前能量平台都保留，原因是所有者明确要它们成为不同武器：快速单点、离散连射、必须蓄力。它们都使用有限能量块且无Heat；不能用加过热来修补失衡。全部枪通过统一Ammo拾取按自身换算补给，不制造分家族捡弹困境。

不先上班用机枪与自动霰弹：基础持续与近距循环需要先成立，否则它们只是更大弹仓和更快射速。不先上磁轨：先证明重敌普通击杀路径与裸弱点价值，再加入穿甲挑战者，避免敌人被设计成专用钥匙。不先上哨戒、维修机、牵引与多段跳弹：这些方案会同时引入AI、导航、状态复制和几何合法性问题，妨碍判断基础射击的问题来自哪里。

拒绝另外两种方案：只做一把全能枪会遮住双枪互补问题；同时做全部68件活跃候选会把精力花在兼容组合而非验证乐趣。当前九枪不是最小开工包，下面A阶段才是。

## 分阶段加入，禁止同时开工

| 阶段 | 新增验证内容 | 前置与退出条件 |

| C · 协同与环境 | 线圈穿透、低声针束、单点脉冲、蓄力爆破、快凝阻滞、区域监测、烟幕、驱雾、动力刺矛 | B先证明普通战斗成立；再加休眠群、有限唤醒、侧翼入口和雾/远程测试情境，不用程序地图随机性掩盖问题 |

这些是装备加入顺序，不是替代项目M0–M6里程碑，不承诺天数或完成日期。A的目标假体可以临时验证部位，不被冒充新敌人已经实现。未出现真实远程投射物和雾的构建不能宣称对应装置已完成。

## 完整配装走读，不枚举全部组合

- 常规协同：突击步枪＋重型狙击＋防护盾＋扫描器。能处理普通交战与部位窗口，缺少强面清，盾不能让狙击手忽略侧翼。
- 排线与补漏：线圈穿透＋精确手枪＋C4＋烟幕。穿线处理排队目标，手枪处理分散轻敌；面对持续厚甲压力不舒服，但不是不可解。
- 潜行转激战：低声针束＋速射脉冲＋快凝阻滞＋冲击器。远程同步失败后有昂贵但真实的战斗补偿；不能四人无限控住整个房间。
- 爆发与信息：单点脉冲步枪＋蓄力爆破＋区域监测＋驱雾器。需要预判与爆破空间，贴脸危险；环境信息帮助选择出手窗口，不直接增加伤害。

以上是设计走读，不是通过的玩家测试。重复职责和故意极端配装同样合法；不显示配装短板警告、评分或推荐，也不因专精重复而禁用。自动组合校验只拒绝非法目录、重复装备、资源或任务不可解冲突，不拿代理偏好代替玩家选择。

## 必须执行的验收与失败处置

EQUIPMENT-FIRST-BATCH-003 · TEST / 尚未运行。

| 测试情境 | 必须观察或记录 | 失败时怎么处理 |
|---|---|---|
| 同敌人、同补给、同场地轮换武器 | 命中/弱点/实际耗弹、击杀时间、浪费伤害、换弹暴露、玩家能否复述不同打法 | 单纯数值换皮合并；不要靠颜色或更多模组补救 |
| 休眠群：单人操作与四人同步/错拍 | 枪口与撞击刺激、同步结果、剩余敌人持续追杀、远程潜行成本 | 若远程静默清所有目标，改低声平台有效条件；不偷偷全图增援 |
| 狭口、开放区、侧翼与厚甲部位 | 不同枪选择率与失效情境；不用专用穿甲也有合法击杀路径 | 万能枪减少覆盖；完全无用途的陷阱枪重做或淘汰 |
| 多人叠盾、泡沫、冲击和烟幕 | 路径、耐久、控制时长、弹体/视线、敌人不失忆 | 真实耐久/耗材必须消耗且耗尽失效；拒绝资源复制或无限续接，不拒绝有限投入覆盖某场战斗 |
| 资源支付及取消、死亡、重连、转交 | 一次提交一次扣账；取消不同时拿资源与效果；无再部署回满 | 修根因，不以多扣一次或静默删设备掩盖 |
| 掩体遮挡与信息权限 | 每个扫描/监测目标的来源；敌我可见性与声音一致 | 非法情报零容忍，缩小功能而非加“玩家不会注意”说明 |
| 手柄/鼠标、四人延迟、字幕与视觉 | 蓄力/装填提示、无需额外高频点击、友军危险区、噪声/光刺激 | 可读性不足先改反馈；不以拟真强行保留别扭输入 |
| 三项任务与五档难度 | 无装备成为主任务钥匙；高难仍遵守在场上限/远程上限 | 修任务和敌人合同，不能给所有玩家强配同一武器 |

不在未试玩时宣布“每枪一样强”。首次测试先获得基线，再设调参阈值；收集不需要永久保留玩家战报的匿名/本地开发测试记录，不改变既有战报确认后删除合同。

### 九枪审查后的聚焦用例

EQUIPMENT-NINE-GUN-ACCEPTANCE · 2026-09-07；纸面合同已收敛，以下构建测试全部NOT RUN。派生断点和补给表归[战斗原型数值](../内容/装备/战斗原型数值.md)的COMBAT-NINE-GUN-REVIEW，不另存参数副本。

| 用例 | 必须比较 / 失败证据 |
|---|---|
| 同一轻敌单只、分散三只、队友提前击杀 | 九枪分别记录身体/弱点、过杀、漏弹、实际击杀、下一目标可攻击时刻；补给按同槽权益归一，不比装饰性DPS分数 |
| 泵动集中、少量擦中、打甲、分散弹丸、多人错峰 | 逐目标累计实际冲击，单发只一次反应；已提交弹体继续，未提交攻击取消，苏醒倒计时不刷新；允许有限资源换强协同 |
| 线圈首发、连续短蓄、松开/切换与冷却同时到期 | 起手和连续间隔分别成立，取消不发弹；薄板占名额、后排衰减、完整甲截断，不能借换枪重置循环 |
| 针束全伤线前后、身体误中、四人不同射距 | 同步以真实命中为准；记录补杀是否赶上合法前兆、实际邻体刺激，不预设所有休眠体可单杀 |
| 突击与速射：移动靶、长短枪线、队友补刀 | 实际停止射击后的在途弹浪费、命中率、资源收益；若速射始终上位，重审其收益与代价，不加Heat掩盖 |
| 手枪、单点与线圈：单体及多体、不同既有生命线 | 分别检验即时命中、射程/单发阈值、排线收益；若无场景愿意承担单点的弹体代价，重做其职责或参数 |
| 重狙打固守体甲面、绕侧、能力部位与短露头，再对照破阵/投涌 | 采用已成文的真实部位、装甲和锁向/收招合同；纸面断点不代替实际瞄准、掩体与角度验收，不靠重狙专用倍率或重狙必带任务成立 |
| 爆破最低/跨档/满蓄、少弹、取消及近身爆点 | 预览成本一致、只提交一次扣弹；同一目标直击/范围不双伤，边缘不是满伤，零友伤与真实自伤分开 |

这些用例按原A至D的依赖加入，不是要求九枪同时开工。纸面审查未删除枪、改槽、调整基础伤害或储备；无配装警告、宏要求或新制作授权。

## 下一轮挑战者与升级条件

近战下一挑战者为链齿战刃，先证明持续接触输出与敌人反馈，再决定加入。枪械与工具先比较单发榴弹枪、磁轨破甲枪、班用机枪、自动霰弹枪、便携哨戒机、远程关门器与黏附照明弹，按已经出现的体验缺口逐件进入，不全上。另挑一个新颖机制做独立小实验，优先测距空爆枪：只需回答“测距这个额外动作是否值得玩家做”，失败就淘汰，不先制作专属美术和升级树。

商业首发保留首轮中经证据成立者，再补真实缺口。新增内容必须胜过现有平台的一个明确使用场景，同时保留可观察弱点；不能因为候选表写了，就自动成为更新承诺。


## 原型来源与资产一致性

首批灰盒使用人类来源的通用枪械与维修装备，不把具体原型直接宣布为筑路者原件。部分试验武器基于筑路者技术是已确认设定；具体武器的历史谱系仍随角色与叙事内容审阅，不阻塞中性灰盒。

重资产在耗尽、丢出边界、断线、多人同时拾取、切枪和倒地时必须保持唯一实例。所有装备测试有效/无效目标、取消、资源耗尽、回收和重连；不允许重新部署回满耗材。首轮黑启动统一为现场重机枪，开路由机械释放与前向维护旁路承担；参数和动作提交统一见[战斗原型数值](../内容/装备/战斗原型数值.md)。
