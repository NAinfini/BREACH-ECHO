# 产品范围、首发合同与明确不做的事

## 选定的产品

SCOPE-001 · DECIDED · Authority: delegated；决策记录基础产品范围与Operation装备决策。

唯一基础产品为1–4人合作PvE Operation。40–50分钟为标准完整合同的体验目标，15–25分钟为Demo短合同目标，10–15分钟为最初灰盒证明目标；三者不是互相矛盾的全局任务时长。玩家从全服共享、定时轮换的八份合同中锁定一份，经配装、现场侦察、同步清除、路线与设施投资、主目标响应、可选贪取和撤离进入战报；锁定Run不因任务轮换中断。倒地救援、有限资源、设施控制、手制Cluster程序组合、局部可解释后果和有边界的武器改装构成核心循环。Descent不是第二个首发入口，不为它复制首发教程、经济、内容、匹配池或存档实现。

四名固定队员、同局不重复Seat、正史持续存活；无角色职业钥匙，任何角色可选任意合法装备。官方Operation入场槽位为一把Primary、一把Secondary、一件专用近战、一件团队工具、一个个人Utility及Quick Melee。工具与Utility各有自己的资源合同；不把Active藏进一个免费的第三武器。传统动能、电磁实体弹、有限Energy Block三类枪械都可进入首发候选并采用有限资源；当前首发Energy不使用Heat。未来真正持续输出的Energy平台可以使用Heat与冷却，但Heat永远不能生成或回补Energy Block。具体首发目录须从[完整装备候选库](../内容/装备/装备完整候选库与首发筛选.md)筛选；高频战刃、动力刺矛和动力冲击锤已获所有者确认进入首轮验证，不冒称已完成平衡或最终商业量。Staff/Spell不进入现行首发；科技辅助的实体刃、矛、锤按已确认目录验证，不直接复制传统分类。

## 内容规划基线

SCOPE-003 · TEST · 这是排产起点，不是“这些数量足够卖”的证明。

先完成BLACKSTART的一条无软锁可玩链，再依次原型化**换流器黑启动、分布式数据取证、货运线夺回**三个主任务和**辅助防御接管、黑匣子、字形暗仓**三个支线，并从[设施模块目录](../内容/设施与资源/设施模块与首发套件.md)搭建两个区域语法。选择理由、替补与重审条件见[首轮任务原型批次](../治理/选型依据/首轮任务原型批次.md)。当前48个主任务和24个支线仍是比较池，六项原型也不是首发承诺。原型必须先证明不同任务会改变玩家计划、地图拓扑或WorldOutput，而不是站在不同名称的终端旁读条；最终首发数量只依据实测制作吞吐和重复度Gate确定。

装备候选不设20把或其他数量上限，也不以武器百科为目标。[完整装备候选库](../内容/装备/装备完整候选库与首发筛选.md)持续收录具有独立动作、任务解法、资源压力或协作价值的Primary、Secondary、近战、工具、Utility与世界重资产；纯伤害、射速、弹仓或外观差异合并为平台参数/改装。项目所有者已确认Primary与Secondary是系统能力平等、只以固定目录区分的两个枪械槽。固定目录与[首轮装备验证计划](../制作/首轮装备原型与验证计划.md)已受托选择：完整池31枪、19工具、18个人战术装置；首轮9枪、4工具、4战术装置及3近战/1现场重资产分阶段验证。未入选不等于永不制作，入选也不等于最终商业首发清单；不把全池同时排进制作。未来DLC可以扩充已成立的技术家族，但不把电磁或Energy的首次出现预设为DLC，近战允许可读实体武器形态，但必须有不同攻击方式与科技作用。敌对内容按[敌人目录](../内容/敌人/首发敌人目录与行为卡.md)先做逐能体、压射体，再逐个扩到八种常规虚空兽、一个特殊猎界体与三种设施单位；新增穿线体提供蓄力直线远程，破阵体提供冲撞重型，投涌体提供曲射重炮。灼星种和借尸者不进入基础版最低量。完整敌人目标已扩大，但不得同时开工：后一角色只有在前一角色的行为、导航、前兆、性能与任务用途有证据后才进入正式资产制作。四人全部可选；不以长时间升级锁掉合作所需能力。调参表和初版卡的数值均为TEST，未通过多配置试玩不得宣称最终平衡。

首批叙事采用四个角色收藏集合加两个设施事件集合，每集合3–5份相互补充的证据作为制作估算。人物集合在角色批准前不写成历史事实；设施集合可以先用无名维修事件验证交付。更多配音、收藏和皮肤不能阻塞M2。

## 明确后置与不支持

SCOPE-004 · DECIDED。

Descent、其全服联合行动和行星端点是未来扩展；没有获批日期、销售承诺或已部署聚合服务。完整Forge可视编辑器、任意脚本层、Native DLL、完整Total Conversion开放、官方常驻模拟服务器、其他商店、主机平台及跨平台联机不在首发关键路径。保留经过真实官方内容证明的扩展接缝，不提前实现空框架。社区专服保持架构可行性，公开发行服务器工具要单独完成运维/内容包验证。

不做PvP、竞技排位、公开K/D排行榜、单一MVP、战利品抽箱、付费战力、强制每日登录、FOMO关键内容、主线章节门锁、永久个人节点征服、无限刷支援经济、在线生成对话、任意代码自动下载执行。未来Season Pass现在只保留中性Progression Track接缝，是否付费、权益和时间规则仍需所有者商业批准；预留不等于首发承诺。总改支持方向不等于无限制运行第三方代码的权利。

## Demo与后续发布

Demo是一份可从头到尾完成的短Operation，使用同一运行时和较小内容集。支持好友合作及当前已完成的安全包路径，但不因未来TC方向要求Demo先完成整个编辑器生态。Demo只迁移幂等的外观/徽章及明确允许的横向解锁，不迁移正在进行的Run、临时战报、任务资源或秘密档案全量。发行价、日期、标题法律清查与实际支付只由所有者批准。

## 范围变更规则

开发者可以调整TEST值、替换失效依赖、重构架构并记录证据，不能以“范围控制”为名暗删明确要求。双视角、Bot、Deck目标或主机恢复若成本不可接受，提交OWNER-04：当前成本证据、推荐删改、损失和替代方案。没有承诺它们便宜，也没有替所有者放弃它们。
