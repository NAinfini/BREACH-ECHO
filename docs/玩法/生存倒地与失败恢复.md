# 生存、倒地与失败恢复

## 玩家目的

失败前有可理解、可执行的补救机会；真正失误有代价，但死亡不能用来洗掉资源和任务后果。

## 范围与术语

Downed 是仍有有限行动的状态；Last Wind 是有效贡献触发自救；Last Chance 是团队无站立成员时检查已提交恢复路径；技术迁移恢复不等于游戏 checkpoint。永久收益归[进度](知识永久进度与壁垒.md)。

## 已确认规则

LIFE-001 · CANON · 来源：SRC-SSOT-2.0 §4A.16、§11.2–§11.5。

Operation 没有 Gameplay Recovery Anchor/checkpoint rollback。恢复梯子是活着临场处理→Downed/Last Wind→队友 revive/carry→专用 ReviveEffect→已提交 Last Chance→不可恢复 Wipe。坏资源状态与 Cart 后果不能靠死亡重置。玩家不承受长期残肢惩罚。

LIFE-002 · DECIDED · 来源：当前产品基线；历史见Git。

Operation不回满；紧急低生命恢复线20%、手动救援3s/40%生命、起身Grace最多2s且攻击解除、倒地45s、Carry按半速消耗为TEST初值，归测试参数。低生命恢复只在连续10秒无受伤且场内不存在能到达该玩家的Active敌人时发生，不会使敌人调查、回巢或退出Active。所有比例基于当前合法HealthCap，不能恢复被牺牲/封印部分。Downed可爬行/Ping及用规则允许的枪，不能执行需要双手的重资产/Carry。普通Healing不等于Revive。

LIFE-003 · CANON · 来源：SRC-SSOT-2.0 §4A.16、§11.5。

Last Wind 接受有效击杀/贡献，队友助攻不能抢走恢复；已提交 DoT、Summon、Turret、Projectile、Reaction、ReviveDrone 继续运行。全员 Downed 不立即判死，合法恢复出现便取消 Wipe；防故意保留弱敌当无限保险。

## 玩家流程

LIFE-004 · DECIDED · 来源：本轮系统扩写。

受伤→找安全或消耗医疗→倒地仍输出/标记→队友选择拉起或搬离→显示可用自救目标/贡献提示→团队全倒时显示仍存续的恢复来源→恢复或结算。失败画面列最后可观察的因果链，不能把未公开数据当“你应该知道”。

## 状态与数据所有权

LIFE-005 · DECIDED · 来源：本轮系统扩写。

Authority 拥有 HealthCap、Health、lifeEpoch、DownedSince、eligibleContribution、ReviveTransaction、Grace、RecoveryCandidateSet。每次倒地生成唯一 lifeEpoch，所有恢复事务只可提交一次；呈现可提前准备但不能先改生命。医疗、投射物所有权与 Last Wind 贡献保持根事件关联。

| 当前 | 条件 | 提交结果 |
|---|---|---|
| Alive | FatalEvent且模式允许倒地 | Downed，登记倒地前已提交效果 |
| Downed | 有效 ReviveEffect/LastWind | Alive，原子恢复生命与短Grace |
| Downed | 出血归零且本Tick无有效恢复 | Out，停止主动行动；不再接受普通手动救援或Last Wind |
| Out | 明确声明支持Out的专用ReviveEffect | Alive；首轮不因此新增复活装备 |
| Downed | Carry开始/结束 | 更新搬运关系与bleedout策略，不复制身体 |
| TeamRecovering | 任一合法复活提交 | TeamActive，取消失败候选 |
| TeamRecovering | 所有恢复路径证明失效 | WipeFinal，发一次结果 |
| WipeFinal | 重复旧消息 | 只重发既有结果，不再次结算 |

## 模式配置

LIFE-006 · DECIDED · 来源：本轮系统扩写；基线 SRC-SSOT-2.0 §11.5。

Operation 连续资源且无回滚；Descent 可有更宽松的层转换/增援 profile，但不回滚历史。恢复量只在公开 profile定义，不因团队“表现太差”隐形加保底。

## 内容接口与 Last Chance 存续

LIFE-007 · DECIDED · 来源：本轮系统扩写。

可恢复 Provider 声明目标资格、触发条件、需要资源、未来推进条件与终止条件。Last Chance 建立有限可达候选集：已发弹、仍有目标的 DoT、已部署且能执行救援的设备等。任意视觉残留、无目标炮塔或不会产生 Revive 的循环不能拖住失败。

有时间推进的合法自救链继续模拟；不加随意十秒处决。若状态分析不能证明终止，必须让玩家看到还在等待哪条路径，并提供全体真人明确放弃此次尝试的候选动作；采用全体仍连接真人一致确认放弃，30秒未形成一致则继续合法恢复模拟；这不是任意处决计时，流程须测试。自动循环既无活目标也无恢复能力时可证明退出，不需要靠偷偷删伤害结束。

## 边界

LIFE-008 · DECIDED · 来源：本轮系统扩写。

双人同时拉起同一玩家：一个事务胜出，其余取消未消耗成本；已消耗且已生效的过程成本不回滚。射手倒地后击杀由 AttackRoot 分配贡献，不按最后一击抢恢复。新倒地 epoch 不重复消费旧自救。断线身体保留权威状态，重连不刷新 Grace；Host 迁移冻结模拟时间。搬运者倒地则在最后合法位置解除携带，禁止掉出地图。刷弱敌防护候选是单次倒地贡献资格/有效威胁条件，初始贡献阈值与有效威胁资格见测试参数，不能全局封禁召唤物或队友助攻。

## 倒地与救援动作合同

LIFE-DOWNED-ACTIONS · 2026-09-06受托DECIDED；参数归[初始测试参数](../制作/初始测试参数.md)，枪械时序归[战斗原型数值](../内容/装备/战斗原型数值.md)。

| 装备/动作 | Downed可做什么 | 不允许或中断结果 |
|---|---|---|
| 突击、泵动、线圈、针束、单点脉冲 | 瞄准、射击、换弹、切枪 | 不获得额外射速/弹药；泵动保留完整循环 |
| 精确手枪、重狙、速射脉冲 | 同第一槽，使用各自完整规则 | 不把重狙变手枪，不按槽位降级 |
| 蓄力爆破 | 瞄准、重新蓄力、射击、换块 | 倒地打断尚未提交的蓄力，已发弹体继续；新蓄力仍有自伤和最低承诺 |
| 近战、重资产、设施操作 | 不执行新动作 | 倒地放下重资产/任务物，取消未命中近战 |
| 手持生命探测器、Ping | 可以使用，扫描仍须切出并完成动作 | 不能同时持扫描器开枪；倒地过程取消未提交扫描 |
| 新部署工具、投掷、补给、救援别人 | 不可 | 已存在盾、胶、传感节点和已发弹体按原规则运行 |
| 已埋C4引爆 | 可以提交遥控引爆 | 真实消耗自己的已布置装药；不自动引爆或凭空制造装药 |
| 被搬运伤员 | 可以Ping，接收团队点标 | 暂停主动枪械、扫描和引爆，不生成“移动双人炮台” |

倒地瞬间取消尚未提交的主动动作，但已装入的弹、已发射的攻击、已生效的工具与费用不回滚；可在Downed重新开始允许的动作。枪械姿态使用低位真实枪口与遮挡，不从站立高度穿过掩体。九枪均可参与Last Wind，但不保证每套配装有相同自救难度。

救援者必须Alive、双手可用，与伤员近距无遮挡；搬运中先放下再救。目标不能同时被两人搬运或一人搬运另一人拉起。长按完成才恢复；提前松开、超出范围、移动超过容差、救援者受伤/倒地或目标进入Out都取消。伤员移动出范围也取消。目标受伤只按出血规则扣余时，不另给读条重置惩罚。救援过程中目标可以原地使用允许的武器，出血继续；不暂停整个世界等救援结束。

Last Wind在当前倒地epoch内累计真实生命伤害；倒地前打出的弹如果在倒地后造成伤害，可计入当前epoch，倒地前已经结算的伤害不结转成保险。每名满足条件的贡献者都可以因同一次队友补刀恢复，不抢最后一击。出血到期后的击杀不能复活Out；只有内容明确支持Out的专用恢复提供者才可继续成为Last Chance候选，首轮未选此装备时不得凭叙述产生它。

Out不是正史死亡，玩家可观察仍在进行的队伍行动，不能主动打枪/借观察视角标记未知敌人。全员无站立成员时仍先检查Downed可主动产生的合法击杀及已提交恢复链；无弹、无合法目标或期限已过的链不能挂住Wipe。迁移暂停模拟钟，重连只继承剩余出血、贡献和设备状态。

## 示例

LIFE-009 · DECIDED · 来源：本轮系统扩写。

正常：玩家倒地后先前火焰持续伤害满足贡献，Last Wind复起。失败：全队倒地，最后炮塔只会打尸体且无复活接口，候选集为空后结算。跨系统：医疗胶囊只有 Healing，不能因队伍全倒临时升级为复活；已提交 Revive Drone 仍沿合法路径救人。

## 接管资产与Last Wind的贡献边界

LIFE-FACILITY-CONTRIBUTION · 受托DECIDED。

友军设施没有自动归给接管人的伤害所有权。接管炮塔、给它供电或下达守门指令属于团队设施贡献，不等于玩家已经向目标造成生命伤害；不能因此让全队躺地等待炮塔无条件复活。倒地玩家已按当前epoch对某合法敌人达到Last Wind贡献条件时，后续友军炮塔或队友补刀可以触发其自救，仍不抢最后一击。

全倒时，无任何合资格玩家贡献且无可产生恢复的合法动作链，只有炮塔继续开火并不足以保留Last Chance。反之，已有资格目标正被合法弹体/设施攻击时必须保留对应链，不能因为射手不是玩家就提前Wipe。单人也遵守同一规则，不额外发送恢复事件。

Resource Pack在倒地时按经济合同落地一次；新接替者继承该Seat的空槽、枪弹和生命状态，不因换操作者恢复包或生命。被搬运者仍不能使用枪械和补给；普通医疗包只治Alive，不把应用动作当Revive。该边界与当前无检查点、无免费资源重置要求一致，实际状态竞争尚未测试。
