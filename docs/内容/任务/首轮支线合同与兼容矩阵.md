# 首轮支线合同与主支线兼容矩阵

## 共同边界

SIDE-CONTRACT-001 · 受托决定 / 尚未测试。

标准Operation只生成零到一个常规支线。支线不能成为主线唯一解，不能消耗主线唯一任务资源，不能添加第二个同等规模高潮，也不能要求返回插入点。支线奖励、世界状态和完成凭据由Authority各提交一次；失败只关闭自身奖励或产生已预告的当局后果，不把已合法完成的Primary改写成失败。

所有支线在任务板显示工作类型和风险类别，但不必泄露具体房间或奖励实例。锁定Offer后，支线Definition/version、插入Beat、资源成本、敌人来源和奖励不因退出重掷。每个支线必须在当前主任务的交战合同内成立；“可选”不等于可以暗加无限敌人或无预告设施级刺激。

## 辅助防御接管

SIDE-DEFENSE-001 · 已决定 / 尚未测试。

| 字段 | 合同 |
|---|---|
| DefinitionID / 版本 | `side/defense-reclaim` / `0.1.0-test` |
| 核心动词 | 识别仍受旧协议控制的防御资产 → 取得本地控制依据 → 隔离旧命令 → 重写阵营与命令 → 指定一个有限守区 |
| 必需空间 | `security-control`或有实体身份/电源模块的安保能力槽；资产射界必须覆盖尚未完成的前方空间 |
| 输入 | 一条合法本地凭证/协议重映射，或强制覆盖；至多一枚可选电力单元；已由主任务Cart支付同一控制回路则不重复扣费，不得使用主线保底资源或强制某种配装工具 |
| WorldOutput | 首轮一件任务卡登记的现存防御转为友军；数量扩充须另过预算与路径验证。保留位置、弹药、损伤和已提交动作，门与传感器只改变已声明范围 |
| 奖励 | 当局战术收益、设施诊断与支线Credits依据；没有永久战力升级 |

默认流程是“先躲避、断电或绕过资产，再从侧后进入控制点”，不是站在炮塔面前读条。合法凭证/安静重映射最高产生群组级设备刺激；强制覆盖复用该主任务已经声明的`SecurityIncident`，不得另造一个隐形全图警报或重复来源预算。接管后玩家选择`守门 / 守固定Ingress / 保持待机`中的一个现场合法命令；守备机不得代做目标、搬关键物或花团队资源。

防御全部被玩家或敌人摧毁时，支线进入`Degraded`并只交付诊断；控制器毁坏且无合法重映射时支线失败，Primary继续。单人可依次断电、进入、重写和复电；多人可以诱导火力与接管分工，但不要求同时操作。断线/迁移保存每件资产的阵营、弹药、损伤、命令与最后合法目标；已发射弹体不因改写消失。

统计记录接管路径、事故、取得资产、剩余弹药/耐久、友军有效压制、误伤、封锁的入口和节省/浪费的资源。若该支线在可比较的各种局势中都成为无脑必做，复查路线、库存、射界与收益；玩家集中投入后让一场有限战斗明显变轻松是允许的，不能仅因成功压住一场战斗就削弱，更不能暗中让敌人无视炮塔。

## 黑匣子

SIDE-BLACKBOX-001 · 已决定 / 尚未测试。

| 字段 | 合同 |
|---|---|
| DefinitionID / 版本 | `side/black-box` / `0.1.0-test` |
| 核心动词 | 从事故痕迹定位记录器 → 恢复固定有限供电或机械释放 → 校验来源/完整性 → 当局上传或短距向前携带 |
| 必需空间 | 与事故、运输、安保或研究事件语义匹配的手制地标；一个当前或前方上传点 |
| 输入 | 记录器自带任务凭据；可选使用一份Tool或局部电力提高完整度，不得消耗主线唯一电力单元 |
| WorldOutput | 团队确认一份作者批准的故事证据；上传后开放Archive/字形/Credits资格，不改变主线事实 |
| 奖励 | 故事收藏、可能的字形片段、Credits依据；重要事实未来可再次获得 |

记录器不能像随机录音带一样丢在任意箱子。它必须和烧毁控制台、脱轨货柜、封死安保门、损坏研究设备或尸体/身份凭据形成同一事件场景。玩家至少做一次物理来源校验，例如对照设备序列、门态、时间基准或事故方向；单纯按拾取键不算完整支线。

若当局设施链完整，玩家在原位执行幂等验证上传；若链路失效，记录器成为一个可放下、转交、越界回收的双手物件，只能携带一个前向Cluster到上传座或撤离。携带不减速但需要放下才能用枪。生成器拒绝与主任务同时要求两个不可放弃双手物件的区段。

正常战斗伤害不摧毁记录器。玩家选择穿过已预告的热、压力或工业危险可能降低完整度；记录器彻底损坏只使支线失败，已确认的非敏感片段仍可进入当局战报但不发完整奖励。统计记录定位方式、物理校验、完整度、携带/掉落/上传、危险损伤、发现成员、撤离资格和唯一RecordID；多人共享发现，不抢个人日志。

## 字形暗仓

SIDE-GLYPH-001 · 已决定 / 尚未测试。

| 字段 | 合同 |
|---|---|
| DefinitionID / 版本 | `side/glyph-cache` / `0.1.0-test` |
| 核心动词 | 从现场证据或永久Archive组成候选序列 → 校验Site/门户兼容 → 支付可见供能与路线成本 → 开启秘密空间 → 决定进入、封闭或离开 |
| 必需空间 | 一个兼容`glyph-branch`与Fold/Optional port；入口、秘密空间和返回/前方出口都属于锁定Seed |
| 输入 | 有效字形知识不消耗；需额外可选电力、门户校验和公开路线风险，不能使用主线保底资源 |
| WorldOutput | 门/门户真实开启，生成已存在的秘密房轮廓、固定休眠威胁和唯一奖励；完成后前方重接或返回 |
| 奖励 | RecoveryRecord、实体资源、外观/成就资格、进一步字形、筑路者资料或原型资产；奖励实例在锁定时确定 |

序列只可来自当局实体证据或玩家已经拥有的永久Archive；UI可以帮助组合已经知道的片段，但不能自动给未知答案。错误组合返回有解释的“地址不完整、校验不符或Site不兼容”，不扣知识、不启动传送，也不给穷举进度。固定永久地址还要通过当前Site兼容、供电与局部校验，不能成为每次都能查Wiki打开的免费宝箱。

门户开启前显示成本、已知危险类别和是否存在返回/前方出口，不承诺具体奖励。秘密空间初始固定休眠预算为4–8敌人角色点；若内容明确包含可继续迁入的实体Fold/ThreatIngress，可再配置一份基础总预算不超过6角色点的`GlyphThreatSource`，应用统一难度与Seat倍率。没有合法入口就不得生成该来源。门户关闭、入口封闭或预算耗尽停止迁入；已经进入的敌人不消失。

知识使用不消耗GlyphRecord，也不降低撤离Credits。奖励按唯一WorldRecordID/RewardID登记；重复扫描、队内分享、关门再开或Host Migration不重复发放。单人能完成全部校验与供能；多人可分工找证据、供电和侦察门后，但不能多人同时领取多份。若秘密空间没有额外决策、威胁或资源成本，或成为主线必要路径，该Seed无效。

## 插入顺序、冲突拒绝与奖励账

SIDE-COMPATIBILITY-002 · DECIDED。

生成器在Primary关键路径与资源证明完成后才尝试插入Secondary：先检查语义Cluster，再检查携带时间窗、设施独占、Power/权限、高潮数量、敌人来源、前向重接和奖励唯一性。条件组合必须输出一份具体证明，说明支线资源来自可选预算、入口/出口可达、任务刺激没有改变公开交战合同、完成后仍能进入下一Primary Beat。缺少任一证明即拒绝组合，不用增加资源或移动门来强行通过。

同一世界凭据可以同时增加LogisticsQuota/GrossRecoveryLedger或GlyphRecordLedger并形成撤离Credits依据，但只能登记一次。普通RecoveryRecord不得与案件主证据、战略货物或黑匣子共用同一完成凭据。支线当局消费不倒扣已登记CreditBasis；主线战略货物不能被支线拆成后勤额度。支线结果按实际交付确定Resolved/Degraded/Failed，并在满足撤离/Bank条件后由唯一事务发放，不由房间脚本写账号。防御接管的战术收益当场生效，但诊断记录须按上传/撤离合同带回；黑匣子未上传时必须真实在共享撤离接收区，留在别的房间不算交付；字形按唯一知识/记录凭据入账。主目标失败不吞掉独立完成并交付的支线；未尝试支线只列未尝试。扫描终局的成员LeftBehind不改变已经成立的团队交付，也不另生成一份支线奖。

## 生成与验收

SIDE-COMPATIBILITY-003 · TEST。

每个允许组合至少验证：无支线、完成支线、放弃支线、支线中断、支线资源先被主线使用、主线先Commit、任务物越界、单人、四人并发、断线和Host Migration。程序阶段每个允许组合至少20 Seed自动结构检查，并人工完整游玩5 Seed；全批次同时进入1000 Seed联合生成扫描。拒绝组合必须给稳定原因码，不能在运行时静默删支线后继续显示原Offer。

重点观察：辅助防御是否成为无脑答案；黑匣子是否只是拾取日志；字形暗仓是否沦为Wiki路线；支线是否增加明显回跑、队友等待或第二个同规模高潮；奖励是否诱导玩家牺牲主线唯一资源。当前所有组合的可解性、节奏、资源、性能和乐趣测试均未运行。

## 首轮防御资产实例约束

SIDE-DEFENSE-STOCK · 受托TEST。

黑启动只引用BST-DEFENSE-STOCK的B05炮塔，不复制一台“支线炮塔”。取证的防御支线只在批准配置中放一台现存炮塔，初始180HP/30发，覆盖一个尚未访问档案入口且可绕侧取得控制；它不能覆盖两个独立证据域。货运配对放一台现存炮塔，初始180HP/45发，仅覆盖L05–L07中的一个预先登记扇区，不追随货物移动。每个实例的具体射界和电源随内容配置锁定，不根据队伍装备临时改变。

三者单体上限和攻击参数都引用[战斗原型数值](../装备/战斗原型数值.md)。守备机与维护机的独立行为先做后续设施沙盒验证，未通过前不进入这三个配对，也不为凑敌人种类随机替换。通用候选仍保留它们，不等于本轮承诺量产。

损毁后的诊断降级奖励只来自该支线唯一结果，不按每次修复/损毁重发。通过已有主线操作满足部分支线条件是合法复用；同一资产的世界变化只提交一次，两个合同各自的结果账不能成为反复策反刷奖励的路径。
