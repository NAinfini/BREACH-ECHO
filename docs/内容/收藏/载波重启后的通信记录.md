# 载波重启后的通信记录

集合`collection.facility.carrier`，三篇。依据已批准的历史断层：原生网络重启改变信号，人类通信层无法照旧解码，近距无线电可以另行沟通，重新对接仍有本地施工与验证。记录作者是当时的人类维护班，不是回声，也不知道后来虚空兽入侵、停战和全面关网的经过。各记录载体及具体测试案例仍为候选。见[交付卡](首批收藏目录与交付卡.md)。

## 还有信号

条目ID：`lore.carrier.changed_signal`。作者：节点维护班故障记录；类别：记录事实。时间：历史安全重启后、内战与外敌接触前。记录现象，不让当时的人提前知道完整正史。

标题中英：还有信号／The Signal Is Still There。

> 中文正文：重启后，接收端仍能检测到节点载波，人类通信程序却无法解析消息。重启前保存的样本可以正常读出，当前收到的不能。不能把这次故障登记成“收不到信号”。
>
> 中文正文：原生控制接口仍有响应。这只证明它还在工作，不证明旧地址和传输设置仍有效。暂停使用旧表发起未经确认的跨节点传输，保留重启前后的原始样本供对照。

> 英文正文：Since the restart, the receiver has continued to detect the node's carrier, but the human communication software cannot decode the messages. Stored samples from before the restart still decode correctly. Current traffic does not. This fault must not be logged as “no signal.”
>
> 英文正文：The native control interface still responds. That does not establish that the old addresses or transfer settings remain valid. Suspend unverified transfers using the old tables and retain raw samples from both sides of the restart for comparison.

## 无线电里的一站

条目ID：`lore.carrier.radio_contact`。作者：近距联络值班摘录；类别：记录事实。时间：局部建立独立无线电联络后。候选场景是两座物理邻近、可无线电互达的人类设施，不穿越壁垒人工空间的封闭边界。

标题中英：无线电里的一站／One Station on the Radio。

> 中文正文：已通过常规无线电联系到邻近站。双方人类通信程序都读不出重启后的节点消息，人员可以用无线电直接交谈，交换测试结果。
>
> 中文正文：这条联络没有经过界桥，也不能接通无线电覆盖不到的站点。不要把“邻站已联系”改成“区域网络已恢复”。我们仍不知道更远的站点收到了什么。

> 英文正文：Contact has been made with a nearby station by conventional radio. Neither station's human communication software can read the node messages received since the restart. Personnel can speak directly over the radio and exchange test results.
>
> 英文正文：This contact does not use the Bridge network and does not reach stations outside radio coverage. Do not change “neighboring station contacted” to “regional network restored.” We still don't know what the more distant stations are receiving.

## 两端都要验

条目ID：`lore.carrier.local_rewrite`。作者：区域维修交接记录；类别：记录事实。时间：完成一段局部修复后；实际维护端口和施工记录为候选，不增加通用全网权限规则。

标题中英：两端都要验／Check Both Ends。

> 中文正文：邻站维护员已通过本地端口装入更新后的通信配置。无线电能交换文件和测试结果，不能代替这台设备上的本地安装。两端现已完成消息往返核对，本段通信可用。
>
> 中文正文：其他站点不在本次验收内。没有独立联络的地方，配置和记录仍要由人员带过去，到了还要重新核对。前往这些站点还需确认可用的字形组合；通信配置不能代替通行条件，恢复通信也不等于原有身份获得了更高的控制权限。

> 英文正文：Maintenance at the neighboring station has installed the updated communication configuration through the local port. Radio can carry files and test results; it cannot perform the local installation required by this equipment. Messages have now been checked in both directions. Communication on this link is working.
>
> 英文正文：No other stations are covered by this acceptance. Where there is no independent contact, personnel still have to carry the configuration and records over and verify them on arrival. Reaching those stations also requires a confirmed, usable glyph combination. A communication configuration does not provide passage, and restored communication does not grant existing identities a higher level of control access.
