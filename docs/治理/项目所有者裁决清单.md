# 仅需项目所有者裁决的事项

项目所有者不需要选择网络方案、编程模式、存档格式、日常平衡、活动schema或目录名；这些选择已委托并会记录。所有者现已明确委托代理扩展装备候选并挑选第一批；普通机制与固定目录选择不再返回所有者逐件投票。商业首发最终范围、完整体验开工与创作身份仍按下列边界处理。下列事项仍由所有者决定，因为它们定义游戏身份、花费真实资金、需要账户权限，或修改所有者的明确要求。

## 本次玩家流程总审后的裁决顺序

2026-09-07：本次发现的任务结束、资料分账、交付凭据、单人耐久与里程碑冲突均在现行明确要求内受托处理，不需所有者挑实现方案。审查证据与限制见[准备度矩阵](../制作/游戏开发准备度与责任覆盖矩阵.md)。

当前涉及是否开工的裁决只有OWNER-05；本次审阅不自动关闭它。推荐接受“先侦察和改写设施，再按合同承担战斗，最后全队共享撤离”的体验方向，但只在所有者明确允许后进入M0，随后按M1最小战斗、M2单项黑启动验证，不批准九枪三任务同时开工。高难库存和实际体验缺口由受托设计/验证处理，不要求所有者凭空选补给系数。

库存与其余专项文档审查现已完成，实际边界见准备度矩阵。OWNER-01的[六组收藏与十九篇中英正文](../内容/收藏/首批收藏目录与交付卡.md)现已补齐并完成作者纸面审查；没有把候选直接批准为正史。当前只需审新增普通事件与具体措辞，不重新批准四份基础经历。推荐保留断箭的四阶段证据链与历史通信三篇；回声误判自检、铆钉维修返工、蝶采样交接、配电保冷却留货物四件普通事件供本次创作选择。OWNER-03外貌/声音、OWNER-02支出与Steam、OWNER-06付费赛季继续延后；不因此启动OWNER-05下的游戏实现。

## OWNER-01 — 故事与四名角色

**部分已完成：**项目所有者已于2026-09-06批准[故事总览](../世界与叙事/完整故事总览.md)的客观历史主因果，以及四人围绕安全规程、技术求知、生存账本、污染边界形成的四向人格框架。**代号已完成：**所有者确认Bolt／断箭、Echo／回声、Rivet／铆钉、Monarch／蝶，允许自由本地化。**经历部分已完成：**断箭封门事件的客观经过、两死两生、前期指挥责任、处分复训及当前人格影响已批准，唯一事实见角色CHAR-002；回声长期参与设施通信恢复、喜欢研究但可能难以收手的经历与人格也已批准，见CHAR-003；铆钉生活设施维修与物资回收经历、务实但可能过度将就的性格已批准，见CHAR-004；蝶从返程检验与隔离转向现场采集、耐心但可能过度要求确认的经历与人格已批准，见CHAR-005。**队内基调已完成：**轻松、熟络、互助，不写四人之间的冲突与争吵；按CHAR-006执行，不再要求六组职业矛盾。**仍需所有者决定：**新增共同经历、私人关系事实与具体收藏交付；代号来源不自动获批。**当前建议：**审本轮十九篇收藏候选，重点选择四件新增普通事件与具体表达；不重复审批已确定的基础经历与相处基调。外貌与声音继续按已批准顺序延后。

**当前聚焦问题与推荐：**所有者进一步肯定口吻并授权完成余下对白批次；[唯一试稿](../世界与叙事/外勤小队中英对白与配音试稿.md)现有325条中英候选，72组首轮功能具备四角色入口，非全员及失败文字归战报。推荐保留目前写作基准，最终取材时按完整情境挑句；不要求重新批准相处基调，也不把全部候选直接送录。当前写作缺口已关闭，剩余是最终创作选择与获准后的试听，不是继续无止境扩句。具体句子仍PROPOSED；人物新历史、声音身份、录音和游戏开工均未因此获批。Hub收尾仍需获批生活演出语境。

**为何由所有者决定：**角色身份与作者表达属于创作权，不是库选择。此前要求明确保留这次审阅，并延后年龄、体型、外貌和选角。**决定前：**灰盒使用 01–04 号席位与中性战术呼号；不制作不可逆角色美术，也不安排付费配音。所有者审阅后，再委托一个真正全新、只读且不了解项目上下文的故事评审。本轮文档整理没有冒充完成这项盲审。

## OWNER-02 — 资金、账户、商业身份与产能

**需要所有者决定：**批准初期资产/工具预算上限、周期性服务预算上限和任何付费专家工作；后续批准商店最终名称、价格与发行日期。账户访问只能通过适当的安全连接提供，绝不粘贴凭据。项目所有者已决定所有Steam账户、部署、Workshop发布与商店事项延后，当前先完成不依赖真实Steam服务的灰盒。**当前建议：**M1证明核心交互并确认某项采购能解除实测瓶颈前，不购买任何内容。

**为何由所有者决定：**文档不能擅自承诺支出、许可条款、云服务账单、法律实体或公开发行。Unity、Steam、Meshy 与其他供应商条款，以及具体资产许可，都必须针对实际账户和采购核查。这个公共 Git 仓库不得接收购买的原始模型或保密合作资料。**决定前：**使用本地工具、原创灰盒资产与模拟的平台/控制面测试；真实在线服务、Steam 合作伙伴启用和商业许可仍是部署 Gate。每周可用时间与人员尚不明确，因此路线图按里程碑管理，不承诺日期。

## OWNER-03 — 角色外貌、声音与不可逆品牌呈现

**需要所有者决定：**所有者在2026-09-07明确重新打开整体美术方向，先研究Meshy、参考图、模型、Rig与Animation，再对新系列候选重新选择；不预设中等多边形工业科幻。推荐按[研究与重选计划](../表现与资产/Meshy工作流研究与美术重选计划.md)先比较同场景风格，再逐项确认造型、动作和材质语言。角色外貌、声音、演员和不可逆品牌呈现继续在对应样件与Style Target后确认；不把普通技术细节变成所有者技术考试。

**为何由所有者决定：**本次整体美术重选是所有者明确保留的创作选择，角色身份、声音和商店级品牌承诺也属于创作与商业身份。**决定前：**采用中性测试体与临时音频；不擅自指定四名角色的年龄、性别、面孔、体型或演员。工具研究和风格对照不等于正式量产、付费生成或游戏开工批准；Unity Style Target与性能仍须实际验证。

## OWNER-04 — 削减任何明确要求

**仅在证据要求时由所有者决定：**是否删除或修改可选 TPS、可选机器人队友、Steam Deck 60 FPS、主机迁移、详细统计、临时本地回放、固定正史角色或自动安全模组同步等明确需求。**当前建议：**保留这些合同，按依赖顺序逐项验证；只有性能分析或原型确认成本后，才提交范围明确的取舍。本条是变更控制规则，不是要求所有者重新决定全部功能。

## OWNER-05 — 实施前体验合同批准

**已确认：**Primary与Secondary完全平等，仅通过固定合法目录区分；以两枪、工具和个人战术装置的整套配装平衡，不以体积、强弱或通用性定义槽位。

**本轮受托完成：**所有者明确要求代理研究扩展并挑选第一批。[完整候选库](../内容/装备/装备完整候选库与首发筛选.md)已分目录，[首轮装备计划](../制作/首轮装备原型与验证计划.md)已选择9枪、4工具、4个人战术装置及3近战/1重资产验证配套。无需所有者重新逐件分槽或选择同一批普通机制；这不是商业首发数量承诺。

**仍需所有者审阅：**结合这一批装备看[完整玩家体验](../玩法/系统化战术行动模式.md)，确认是否允许进入灰盒。推荐先用三类任务展示配装的收益、代价与失败，再关闭PRE-GAMEPLAY；不能以本次文档扩展视为整个游戏已经批准开工。参数、枪感、美术和性能继续未测。

## OWNER-06 — 未来Season Pass与赛季商业权益

**未来需要所有者决定，当前不阻塞灰盒：**是否采用付费Season Pass、是否存在免费/付费双轨、价格、时限、包含哪些外观权益、旧奖励如何回归，以及平台与法律披露。日、周、月和临时特殊行动本身已经获准设计，不需要等待本条；当前只实现免费也能使用的中性Progression Track接缝。

**当前建议：**在真实内容产能、活动留存价值和玩家反馈出现前不批准付费Pass。若以后采用，只含可预览的外观、称号、展示物与档案展示，不出售武器、敌人、任务、战力、随机奖励或关键剧情，也不要求连续登录。具体方向与技术隔离见[在线活动与赛季准备](选型依据/在线活动赛季准备与持续内容扩充.md)。
