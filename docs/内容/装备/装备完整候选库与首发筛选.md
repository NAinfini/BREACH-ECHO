# 首发装备完整候选库与筛选入口

## 目的与批准状态

LOADOUT-CANDIDATES-001 · 槽位合同已确认 / 扩展与首轮选择为受托设计。

本文件是装备唯一总入口，不重复各目录的机制卡。当前活跃候选为31把枪（Primary 15、Secondary 16）、19件团队工具和18件个人战术装置，共68项；另保留本文件的8件未来技术近战与12件现场重资产，共88项供研究与筛选。竞争假说可以合并或淘汰，数量没有配额，候选不等于全部值得制作。

所有者已明确要求扩展候选、写入文档并由代理选择第一批。固定目录与首轮9枪、4工具、4战术装置已完成受托选择；配套选择3近战与1现场重资产。完整名单、选择理由、制作阶段和待执行验收只由[首轮装备原型与验证计划](../../制作/首轮装备原型与验证计划.md)拥有。商业首发数量尚未承诺，完整体验Gate仍未关闭，本轮不创建Unity工程。

第一批当前能量平台均无Heat，后续持续照射才允许有限能量加Heat。所有枪有噪声或刺激，统一Ammo拾取，工具与消耗型个人装置按实际耐久/耗材工作，手持生命探测器是无限使用的情报设备；冷却不能凭等待生出其他耗材。任何装备不能成为主任务唯一钥匙。

## 槽位职责

LOADOUT-CANDIDATES-003 · 已确认槽位合同 / 具体内容待定。

| 槽位 | 系统地位 | 内容边界 | 禁止推断 |
|---|---|---|---|
| Primary | 与Secondary完全平等的枪械槽 | 只能装备Primary固定目录中的一把枪 | 不代表主要、通用、更强、更大、更高持续或使用时间更多 |
| Secondary | 与Primary完全平等的枪械槽 | 只能装备Secondary固定目录中的一把枪 | 不代表备用、更弱、更小、快速切出、低储备或只用于特殊场合 |
| Dedicated Melee | 独立近战平台 | 不消耗枪弹，以距离、承诺、姿态或暴露换取处决/控制/结构作用 | 不是第三把免费枪，也不是传统刀剑锤矛换皮 |
| Team Tool | 团队设施与战场塑形槽 | 使用有限Tool资源改变情报、防区、路线压力或恢复空间 | 不是个人超能力或主任务职业钥匙 |
| Personal Utility | 个人战术槽 | 按各卡资源合同提供个人战术能力；手持探测无限使用，其余耗材不由冷却恢复 | 不是第二件Tool、永久被动或免费资源源 |

Primary和Secondary共享统一Ammo拾取与支援界面，但每件武器拥有自己的资源换算、弹仓、装填、换出和换入Profile。两槽的命名只是固定目录地址，平衡对象是两枪、Tool与Utility组成的整套配装。玩家可以构筑互补组合，也可以故意堆叠某一强项并承担盲区。

### 尚未独立立项的机制变体

已独立立项的武器只在两个固定目录维护。下表只保留尚有独特实验问题的变体，不重复列已完成改名或合并的武器。变体证明新动作前，不单独计入候选数量。

| 机制变体 | 比较对象或归属 | 独立立项前要证明什么 |
|---|---|---|
| 大口径战斗步枪 | 与突击步枪/重型狙击竞争的变体 | 慢节奏高冲量、薄甲与远单体思路保留；暂不单列平台，除非姿态或材料作用真能区别两者。 |
| 紧凑突击卡宾枪 | 突击步枪操控改装候选 | 保留转角/腰射与远距衰减交换；仅此差异不另造一枪。 |
| 一体式低特征卡宾枪 | 低声针束步枪的竞争实验 | 保留短距低声动能方案；弱停止力、低弹速、落点噪声仍有成本。若只与电磁针束换材质，先不双做。 |
| 重型转轮手枪 | 精确手枪的高冲量竞争变体 | 少发高冲量、长复位慢装填的思路保留；若仅伤害/射速互换不独立量产。 |
| 自动手枪 | 速射脉冲枪/近距平台的竞争变体 | 保留贴脸短喷、瞬空弹仓和中距差；未证明与现有自动火力不同前不新增。 |
| 折叠式霰弹手枪 | 泵动/自动霰弹的竞争变体 | 一至两发救场、短射程慢重装思路保留；尺寸与低储备不构成独立平台。 |
| 一体式低特征手枪 | 低声针束步枪的竞争变体 | 保留极近距离弱点潜行与低停止力；不能只是更小的免费潜行枪。 |
| 定长点射手枪 | 精确手枪的点射改装实验 | 固定不可中止弹组与预付弹耗保留；先作为射击机制变体，不计独立枪。 |
| 弹针三连步枪 | 低声针束/线圈平台的弹组实验 | 同部位累积和固定三连承诺保留；没有独立部位机制就不新造平台。 |
| 线圈破片手枪 | 线圈穿透/磁轨破甲竞争变体 | 短窗单发蓄力穿薄甲思路保留；仅缩小与加快切出不足以分家。 |
| 弹针点射手枪 | 针束平台弹组实验 | 短窗口固定弹组和身体效率低保留，与三连思路合并评估。 |
| 导向碎片手枪 | Primary · 锁定步枪的竞争变体 | 保留已观察标记与有限角修正，不保留自动获取墙后目标；手枪尺寸不独立立项。 |
| 热射流步枪 | 束流切割/聚焦微波竞争变体 | 短距持续、有限介质或能量、Heat与视线代价保留；若仅换画面则合并，当前不单列。 |
| 蓄力能量手枪 | 蓄力爆破枪的短循环竞争变体 | 低/高蓄节奏保留；若只是更短的蓄力时间不独立量产。 |
| 能量散束手枪 | Primary · 定向震荡枪的竞争变体 | 短距扇形推离、耗能高、单体差保留；与个人冲击器严查控制重复。 |

## 未来技术近战候选

LOADOUT-CANDIDATES-006 · CANON / 2026-09-06所有者确认八件候选方向及首轮三件；名称为工作名，参数与玩法未测。

所有近战靠实体接触伤害，不发射弹丸、矛头、剑气或冲击波。未来科技辅助接触切割、贯入或冲量，不把维修操作伪装成战斗。潜行型低声但非无声，偏精准先手；激战型可更响，以伤害、打断或持续输出交换暴露。不要求每把都能安静清房，也不按玩家配装改变敌人。

| ID / 工作名 | 取向 | 攻击与独特打法 | 代价 | 选择 |
|---|---|---|---|---|
| `MELEE-HIGH-FREQUENCY-BLADE` 高频战刃 | 潜行 | 实体刃接触微振切割；短斩或准备后的精准刺击，同步弱点击杀 | 距离短，对甲、群控弱 | 首轮 |
| `MELEE-POWER-SPEAR` 动力刺矛 | 潜行 | 双手实体突刺，接触后内部机构辅助贯入；窄线距离控制，不发射矛头 | 刺偏落空、贴脸包围难用 | 首轮 |
| `MELEE-WRIST-BLADE` 腕载刺刃 | 潜行 | 前臂短刃快速进出、连续直刺 | 距离极短、单次伤害低，重敌需多次暴露；若与战刃只差动画则合并 | 候选 |
| `MELEE-POWER-HAMMER` 动力冲击锤 | 激战 | 实体锤头命中释放助力冲量，打断、破姿态与救援开窗 | 噪声大、动作慢、挥空危险 | 首轮 |
| `MELEE-POWER-AXE` 动力战斧 | 激战 | 助力重劈集中单体杀伤，瞄准肢体或裸露部位 | 控制弱于锤，收招暴露 | 候选 |
| `MELEE-CHAIN-BLADE` 链齿战刃 | 激战 | 运动链齿接触持续切割孤立目标 | 极响、持续贴身；无锁敌或无敌处决动画 | 下一挑战者 |

| `MELEE-POWER-LONGBLADE` 动力长刃 | 激战 | 双手长实体刃横斩近群、纵斩单体，助力控制挥动 | 横斩需要空间，碰墙截断有效路径，破甲弱于战斧 | 候选 |

首轮先验证战刃与锤，再加入刺矛对照距离与窄线命中；普通/蓄力、取消、噪声与不耗补给的资源合同归[近战合同](首轮近战攻击与资源合同.md)，数值TEST且未测。完整阶段归[首轮计划](../../制作/首轮装备原型与验证计划.md)。Quick Melee是持枪脱身动作，不占候选武器名额。

贴身工具创意仍保留为未立项实验，不计上述八件：液压扩张钳在固定目标上夹撬装甲/卡滞结构，付双手持续暴露且不能绕关键门；电黏附拘束器贴身限制肢体、低伤且不能无限控；低温相变注入器以有限介质延迟脆化部位；牵引锚具限制轻敌相对位置，对重敌不拖动并需导航/网络验证。超声疲劳、接缝剪切作为武器接触机制竞争方案，未证明独立打法前不另造武器；反冲位移作为拳套竞争动作保留，不默认取代快速推击。

## 团队工具候选

LOADOUT-CANDIDATES-007 · 内容责任已拆分 / 候选与首轮分层。

全部19项活跃工具机制、成本与否决条件由[团队工具候选目录](团队工具候选目录.md)拥有，首轮选择由[原型计划](../../制作/首轮装备原型与验证计划.md)拥有。本文件不保留重复工具性能表。

原12项的去向：侦察扫描器合并为个人手持生命探测器；快凝泡沫投射器改名快凝阻滞器；便携哨戒机、协议桥接器、战地稳定器、便携冷却循环器、维修微型机保留；便携功率耦合器改名便携供电器；展开式防护板改名展开式防护盾；绊线预警网作为区域监测器的物理传感节点实现；多谱照明桅杆改名多谱照明器。

声学诱导器不进入活跃池：保留“物理声源会刺激敌人”的场景机制，但不用它把已激活敌人引成失忆、反复转头的免费目标。若未来证明有限声源能在持续追杀合同中产生独特玩法，再单独评估；不把既有诱饵描述当已批准AI规则。

## 个人Utility候选

LOADOUT-CANDIDATES-008 · 内容责任已拆分 / 有限资源主动窗口。

全部18项活跃个人战术装置机制由[个人战术装置候选目录](个人战术装置候选目录.md)拥有。它们不是第二件持续工具，手持探测器不耗扫描次数，其他消耗型装置不能用冷却替代补给；烟幕不会清除已唤醒追杀，驱雾不会自动净化毒气。

原14项的去向：定向冲击器、救援牵引索、反应护层保留；信号抑制幕收窄为装备隔振夹；动力锚定器改名反冲锚定器；定向闪扰器改为有实体投掷轨迹的闪扰弹；微粒遮蔽罐改名微粒烟幕弹；微型拦截器改名应急投射物拦截器；远程锁扣改名远程关门器。原定向脉冲雷的预布触发思路并入工具定向感应地雷的控制型竞争实验，不在两个槽重复摆同一种雷。

定向屏障不作为活跃个人装置：防御先由展开式防护盾承担，双手重型移动屏障仍在现场重资产候选；保留举盾失去射击的交换，避免三份盾同时开工。诱饵信标与声学诱导器同样后置，不允许失忆式救急。应急超驱淘汰为独立装置：分段换弹、取消与技巧由基础输入合同提供，不加人人必带的操作速度税。攻击回响器淘汰：重复枪击事件、归因和资源漏洞的成本高，且魔法式回放与题材不符；不实现旧方案。

| `ORDNANCE-MOBILE-BARRIER` 重型移动屏障 | 一人双手推进，为队友建立可移动掩体和救援路线 | 持有者无输出、耐久有限、转向慢 | 与现有防护盾/展开掩体工具重叠；只保留一种主层级 |
| `ORDNANCE-MICRO-MORTAR` 微型迫击系统 | 架设后用有限弹药打击已合法标记的远端区域 | 需要架设、观察员和弹道空间；不能读取全图目标 | 室内顶棚、程序地图和网络复杂度极高；首发不推荐 |

## 组合检查与明显陷阱

任何首发组合都必须同时通过以下检查：

1. Primary与Secondary目录都必须包含能独立赢得选择率的武器，不能把一个槽做成强制主枪、另一个做成清残血附件。
2. 每把枪有明确强项、代价和失败情境；槽位之间不使用统一强弱、体积、弹量、切换或持续输出系数。
3. 低特征选项无论归入哪个目录都必须支付弹量、停止力、射程、操控或失手暴露等可观察代价；不存在免费潜行答案。
4. 三个技术家族在完整首发两枪池中至少各有一个真实可玩代表，不要求两目录家族对称。
5. 每个固定目录至少能与另一个目录形成多种互补配对；不得出现唯一正确搭配或某件装备的固定伴侣税。
6. 测试必须覆盖互补配装、重复职责配装和故意极端配装，并把Tool与Utility一起计入清群、单体、控制、潜行、情报和防护覆盖。
7. 狙击平台可以对大型敌人暴露部位极强，但必须在射速、储备、近距、轻群或过度击杀中承担足够代价；手枪可以存在，但没有自动入选权。
8. 所有组合都能完成主任务，但并非都能舒服应对每种可选内容；不能用具体枪ID做门锁或Boss硬钥匙。
9. 当前三种Energy平台保持独立且无Heat；只有未来持续束流、喷射或长时间照射平台可以使用Heat。
10. 首发不是候选池总量。未选择内容保留为候选，只有完成独立生产Gate后才能进入更新或DLC。
