# 首发任务目录与兼容矩阵

## 范围与制作顺序

MSN-001 · DECIDED。

本文把六个任务族展开为首发可制作的十二个主任务变体和六个支线。所有名称是工作名；任务流程和玩家问题是合同。先以固定[BLACKSTART](blackstart-greybox-mission.md)证明系统，再制作三个不同动作的主任务原型，最后扩到十二个变体；生成器不得以随机门位置冒充内容差异。

## 十二个主任务变体

MSN-002 · TEST。

| ID / 工作名 | 任务族 | 核心流程 | 必须做出的选择与世界变化 | 降级/失败 |
|---|---|---|---|---|
| `salvage/selective-strip` 选择性拆解 | 废料 | 扫描三组设备→判断可运/可拆→分配携带能力→撤离 | 拆成更多低值废料，或保留笨重完整机件换高值与移动压力 | 丢弃不失败；损坏只按剩余价值结算 |
| `salvage/unstable-cache` 失稳仓 | 废料 | 稳定仓门→限时取件窗口→决定继续贪取或封仓 | 每次再开增加热/敌人入口，封仓永久停止本局奖励 | 失稳后保住已搬出物，不处决队伍 |
| `resource/coolant-line` 冷却链 | 战略资源 | 找泄漏→接驳临时回路→护送冷却罐→装载 | 冷却用于设施安全或全部带回壁垒；影响后段环境 | 污染/破损降低数量并增加热区旁路 |
| `resource/solar-feed` 日照燃料 | 战略资源 | 恢复泵→选择储罐→调压→搬运燃料 | 高纯罐路线危险但价值高；低纯罐可稳定任务供能 | 超压毁一罐，剩余路线仍可完成 |
| `technology/prototype-cradle` 原型摇篮 | 技术回收 | 获取权限→解除固定→维持冷却→用双手资产撤离 | 保完整原型或现场拆为蓝图与部件 | 冷却失败转为残缺技术，不生成替代品 |
| `technology/fabrication-heart` 制造核心 | 技术回收 | 查故障→更换模块→启动自检→防守或切断 | 带走核心失去本局制造收益，在线修复可现场补给 | 自检中断保留已恢复子模块 |
| `research/truth-window` 真值窗口 | 研究数据 | 恢复两份日志→校验时钟/签名→快速上传或完整提取 | 快速上传保知识，完整提取多资料但暴露更久 | 数据损坏时明确标为不完整/不可信 |
| `research/echo-array` 残响阵列 | 研究数据 | 对齐三个接收器→追踪信号源→隔离干扰→读取 | 把Power留给阵列取得字形，或转给防御保安全 | 少一个接收器仍得粗略结果，不伪造精度 |

| `network/friendly-firewall` 旧令防线 | 设施恢复 | 避开自动防御→取授权片→重建身份映射→接管 | 破坏炮塔求快，或保存它们换终局火力 | 摧毁资产不失败，但失去后续帮助 |
| `threat/quarantine-cage` 隔离笼 | 威胁处理 | 追踪猎界体→诱入区→封锁→取得反制→前向重接 | 永久击杀或代价更低的长期封存 | 陷阱失败转追猎，不脚本传送 |
| `threat/nest-severance` 巢链切断 | 威胁处理 | 定位三个能量取食点→断开迁入路线→清除本地体 | 先断路线减少增援，或先救资源承担迁入 | 漏一个入口则撤离段仍有可读压力 |

## 主支线兼容规则

MSN-004 · DECIDED。

兼容以资源族、独占空间、携带槽、同一设施状态和高潮节奏五项判断，不按名称硬配。默认矩阵：

| 主任务族 | 推荐支线 | 禁止或需专门变体 |
|---|---|---|
| 废料 | 字形暗仓、黑箱上传、防御回收 | 遗失小队与选择性拆解同时大量搬运需禁用 |
| 战略资源 | 黑箱上传、防御回收 | 样本链若占同一冷却/携带接口则禁用 |
| 技术回收 | 字形暗仓、遗失小队 | 重资产回收与原型摇篮双重双手搬运禁用 |
| 研究数据 | 样本链、字形暗仓 | 黑箱上传若复制同一上传决策则禁用 |
| 设施恢复 | 防御回收、黑箱上传 | 字形暗仓不能复用主任务唯一Glyph |
| 威胁处理 | 重资产回收、样本链 | 遗失小队不能引入第二个独立Predator链 |

兼容表只是首轮许可。每个具体组合仍要声明所需Cluster、资源预算、高潮Beat和失败互作用；两个任务都要求同一唯一对象、同一房间或同一不可逆Power状态时，生成器必须拒绝。

## 节奏与区域配置

MSN-005 · DECIDED。

每个40–50分钟合同按“低压侦察→第一承诺→释放→中段变化→第二承诺/高潮→撤离压力”排列，至少有两段可辨识低压时间。主任务第一次引入的机制先在低风险Beat使用，再在高潮组合。支线从关键路径分出后应在前方重接；预计额外时间初值为5–10分钟TEST，不允许把任务长度主要填成原路返回。

无限探索区优先废料、技术、研究与巢链，补给少、资料/信用点价值高；限界探索区优先设施恢复、战略资源与防御回收，可接管资产多。区域是权重而非硬锁，同一任务在两个区域必须通过设施系统和敌人来源改变问题，而不仅换贴图。

## 内容卡交付字段

MSN-006 · DECIDED。

每个任务资产必须包含DefinitionID/version、合法Region/Site、Primary/Secondary、Beat Graph、所需/可选Cluster Tags、关键实例与资源、状态机、降级/失败、单人动作顺序、1–4人并发、敌人Source、奖励来源、叙事槽、教学目标、统计事件及Seed stream。所有任务动作通过Authority事务；场景脚本不能私自发奖励或修改账号。

## 验收与未证明项

MSN-007 · TEST。

每个变体先固定Seed走通正常、降级、资源耗尽、任务物损坏、单人、四人并发、断线/迁移；主线零无提示软锁。每个已批准主支线组合至少20个Seed自动验证，并由人工检查5个Seed的路线、等待、节奏和视觉重复。至少三种主任务在同一战斗底盘上产生不同计划，才进入十二变体量产。所有结果当前为NOT RUN。
