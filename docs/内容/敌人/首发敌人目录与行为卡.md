# 首发敌人目录与行为卡

## 范围与首发生态

ENY-001 · DECIDED。

基础版先生产两组敌对来源：虚空兽与失控设施防御。灼星种、借尸者及其完整生态属于未来内容，不进入首发最小内容量。本文拥有敌人身份、行为、部位、反制和组合；数值唯一由[战斗试制参数](../装备/战斗原型数值.md)拥有，感知/决策/导航实现由[AI运行架构](../../技术/人工智能运行架构.md)拥有。

首个战斗切片只做逐能体与压射体；随后按固守体、缝行体、穿线体、探讯体、破阵体、投涌体以及三种设施单位的顺序逐个验证。八种常规虚空兽和三种设施单位都通过灰盒后，才制作正式网格、动画和音频。工作名用于制作，可在不改变角色合同时重命名。

虚空兽不掉弹药、货币或装备。战斗收益来自解除压力、开放世界资产、样本任务或保护回收物，不能把它们变成刷怪经济。休眠体是同一敌人定义的`Dormant`状态，不是廉价雕像；供电不立即统一唤醒，具体刺激见[遭遇规则](../../玩法/敌人遭遇与难度.md)。

探讯体必须在生成时绑定一个具体`CallBinding`。绑定到已启用且有余额的有限来源时，通信成功只提交一次来源请求；绑定到生成时已存在的传播群时，只把刺激传给该组，不创建实体；没有合法绑定、来源未启用、余额耗尽、入口封闭或通信在提交前被打断时，必须给可见失败反馈且不生成任何单位。一个通信不能按入口数量复制请求，Host Migration也不能重放已提交调用。

## 顶层状态与行为共同合同

ENY-004 · DECIDED。

虚空兽激活主状态为`Dormant / Stirring / Active / Displaced / Disabled / Dead`；`Stirring`是短暂苏醒前兆，击杀可阻止其完成，普通硬直不能暂停或重置倒计时，进入`Active`后本局持续追杀可达的存活玩家，不会调查、放弃、回巢或重新休眠。视线只影响攻击选择与瞄准质量，不决定是否继续追击；门和地形必须通过真实寻路拖延或永久隔离，敌人不得穿墙或传送。设施单位以`Standby / Tracking / Engaged / Isolated / HostileProtocol / Controlled / Disabled / Destroyed`表达自身协议，不套用虚空兽休眠语义。每次转换必须由合法唤醒、协议或任务事件触发，并记录原因。

多帧动作声明前摇、Commit点、恢复、合法取消和部位要求。攻击在Commit后即使敌人随后死亡也按已提交弹体/冲量结算；前摇中关键能力部位被破坏则取消并给明确反馈。行为树不能每次Think重启动画，也不能因LOD切换重置冷却或仇恨。

## 组合与内容最低量

ENY-005 · TEST。

首发完整内容目标为八种常规虚空兽、一个特殊猎界体和三种设施单位；这不是销售充分性或制作可行性已经通过的证明。组合按玩家行为目的构成：逐能体+压射体训练移动与掩体，固守体+缝行体制造前后决策，穿线体惩罚排队站位，探讯体+真实Source测试潜行因果，破阵体打开普通防线，投涌体迫使离开固定阵地，设施防御+虚空兽测试第三方交火。每个常规任务最多突出两个新角色，其余为已学会的支撑，不能一局同时教学全部十二种。

Relaxed到Cataclysm优先改变合法来源、组合、协同、资源和环境，不偷偷按Build加抗性。特殊猎界体只进入声明`PredatorReversal`的任务，不进入普通随机预算。限界区提高设施单位权重，无限区提高虚空兽来源与休眠体密度；相同Difficulty仍保持不同问题。

首轮三任务的五档数量、同场种类、重型与远程比例、设施上限及来源构成由[首轮任务难度、敌人和配装用途矩阵](../任务/首轮任务难度敌人与配装矩阵.md)唯一收敛。难度提高时必须先让玩家看见更多实体、更多职责、更多重型与远程火力组合；不得用环境Debuff或资源削减假装已经增加了敌人内容。

## 反馈与可访问性

每种敌人必须有独立轮廓、移动节奏、攻击前兆和非颜色唯一提示。压射前摇、探讯通信、猎界体接近、炮塔锁定至少同时有两类信号（形体/光形、声音、字幕/方向提示）；关闭声音后仍可反应，降低闪烁后仍能区分Commit点。受损部位在模型、动作和行为上同时改变，不能只换血条图标。

## 两类基础敌人的可读攻击与弱点布局

ENY-FIRST-ATTACKS · 2026-09-06，受托设计；参数TEST、实现NOT RUN。本文拥有动作与布局意图，精确时序、范围、倍率和完整度只引用[战斗原型数值](../装备/战斗原型数值.md)，不在这里复制。正式模型与物种外观不因此锁定。

### 逐能体：读懂逼近，在落击前离开攻击线

首轮只验证一种近击，不同时加入扑杀、抓取、旋转横扫和隐形冲刺。接近时靠正常步行/奔行追上目标；进入攻击先压低身体、抬起攻击肢，最后支撑肢扎稳、攻击方向固定，然后向先前位置打出。识别重点是“正在接近—准备挥击—已锁向”，不是记闪光颜色。

玩家可以在锁向后横移离开攻击扇区，也可以后撤至范围外、绕到背后或利用真实门框挡住接触。跳跃和蹲下只有在玩家实际碰撞体避开攻击形状时有效，不附送无敌时间。敌人不能在前摇最后瞬移、延长手臂或转头补命中；玩家也不能只靠占住路径点让敌人永远无法提交。

感知器放在正面上部的可辨识实体上，与躯干分离但不能小到只能靠发光像素定位；左右推进肢位于较低、偏外侧的位置。攻击准备暴露其支撑动作，便于选择削弱移动。两肢破坏收益不重复相乘。休眠姿态至少提供一个可接近的身体或感知器角度，不读取玩家松键时刻突然藏头。破坏感知器不消除持续追杀，因此它首先是精确击杀位置，不宣传为“打瞎后可安全走开”。

攻击落空后完整恢复，给玩家补刀、换弹或援护机会；不是只有打中时才恢复。多个逐能体可真实同时攻击，但需各自实体站位和可读动作，不能叠在一个位置、靠多个看不见的手臂同时造成伤害。也不增加幕后轮流出手配额来假装玩家躲开了。

### 压射体：用有限枪线迫使换位

先停步支撑、抬起发射器并展开器官，再进入锁向，随后发出固定目标点的短连射。轮内弹体可见、速度有限、不追踪；玩家横移或换掩体能够离开弹线。正对它直线后退通常不可靠。声学前兆、器官动作与弹体路径互相吻合，不依赖震屏、运动模糊或铺满屏幕的警告。

感知器在正面上部；发射器偏侧上方，与感知器保持清楚的空间区分；支撑肢在下部。发射器在准备时更容易瞄准，但不是平时无敌、只能按节拍开窗。玩家可以杀本体、拆发射器或切断枪线；没有一种专用武器是必选答案。

压射体恢复时重新寻找合法射线；玩家主动压近后，它不能无限后退、每次恰好保持玩家近战距离之外。若无射线则接近/改道，不持续隔墙更新射击点。发射器被拆后改用参数表的退化近击，保留明确前摇，不偷偷恢复远射。手持探测器只提供跟随点，不额外显示这三个器官。

### 混合战斗的通过条件

同一组“两个逐能体与一个压射体”至少检查四种真实处理：先杀近敌再换线；先拆远射器再处理逼近；破坏推进肢争取救援时间；用盾或泡沫暂时隔开压力。此组只是验收情境，不替代程序任务兵力预算，也不规定队伍必须带控制工具。

验收需分别记录：受击前能否指出哪一个动作预告了攻击；侧移是否实际离开命中几何；锁向后敌人是否偷改目标；瞄不同部位是否改变下一项决策。关闭声音、关闭装饰性屏幕效果、多人动作叠加时重复检查。玩家只能靠背伤害数字才能作决定、躲到掩体后仍被枪口穿墙击中、破坏器官没有可见行为变化，均为失败。上述结果全部待构建和真人测试，不以纸面走读代替。

## 全目录部位布局与攻击窗口

ENY-FULL-COMBAT-CONTRACT · 2026-09-07，受托设计，来源SRC-USER-ALL-ENEMY-CONTRACTS。这里拥有玩家能看见的布局、动作意图和应对方式；数值只在战斗原型数值中维护。没有新武器钥匙、全身等级装甲、低血量狂暴或按队伍配装改变反制。

### 固守体：正面顶住，侧面可拆

甲壳覆盖前方躯干，不长成包住全身的护盾。感知器位于上后侧，正面平射会先撞甲，但从侧上方或它抬身时可看见；持械肢根偏身体一侧，举起攻击肢会暴露更大的连接面。精准伤害点与解除重击的部位分开，玩家能选择杀得更快或先减轻压力。侧后普通身体始终能正常受伤，不仅在攻击动画中才“开放伤害”。

接近时甲面对向当前目标，准备重击时停步、举肢、踏稳，随后锁住方向打出；收招早段仍不能立刻转回侧翼。单人可引它出招再横移，多人可从两侧制造枪线，但没有嘲讽键、强制坦克席位或读取谁拿狙击。无人贴近时仍按Active规则追来，不永远站在价值点守门。

打甲是从正面付额外弹药换通路；绕侧打感知器是承担路线风险换短暴露击杀；打肢根则取消未出的重击并使后续攻击变弱。重狙命中裸露感知器应有显著单发回报，其他枪和近战也吃同一部位规则。破甲不令整只敌人眩晕，失肢也不代表安全，它仍能撞击。

### 探讯体：看清要打的是通信冠，不只追求爆头

感知器在前上部，通信冠在背部更大的独立伸展结构上，两者不能重叠成同一个万能靶。准备呼叫时停步撑开通信冠，形成持续可见的动作和明确声音。玩家可以直接杀本体，也可以先破通信冠，让附近队友继续处理其他压力。

感知器受损只是看得更近，已经认定的呼叫并不因“打瞎了”自动取消。通信冠被打断时收拢/断裂，并给与成功呼叫不同的反馈；没有有效绑定时不演一场必然失败的假警报。呼叫成功只提交原有有限来源或已有传播群请求，不能开新全图来源。失去呼叫后仍用近击追赶，不变成无害巡逻员。

### 缝行体：它能走侧路，不会从背后凭空出现

较低的战斗姿态，侧面感知器可见但不与正面形成宽大爆头靶；外侧攀行肢更容易被侧射击中。它选的是已有维护口与普通路线，不生成新的洞或躲在碰撞外。进入/离开维护口必须能看到肢体接触出口并听到攀行，随后完整准备侧击，不把穿门动作直接结算成扑击伤害。

破攀行肢使它失去后续特殊路径并减速，已经在通道里时沿原路径抵达合法出口。它仍可正常攻击，不因断一条肢直接瘫死。其价值在于改变队伍朝向，不能靠更高伤害、更短前兆或每次精准选择无人看的屏幕后方代替侧路设计。

### 穿线体：长前兆直线贯穿，拆发射器能取消下一发

发射器置于前侧，感知器在其上方分离，支撑肢位于下方。准备时发射器拉直、支撑扎稳，先调整枪线再锁定。线形提示来自它真实瞄准的方向，不追踪墙后玩家，也不等于面罩提供敌人轮廓。

玩家可横移、分散、借厚掩体或先拆发射器；排成一列硬吃会伤及后排。尖体已经离开后，杀掉射手不能救回那条线上没躲开的队友。拆发射器让它转近击；腿部只是让它较难换线，不附送破枪收益。不在狭窄唯一通道中同时铺出无可避路径的贯穿线。

### 破阵体：路线锁住以后，允许玩家骗它撞空

冲撞甲覆盖头前至胸前，感知器偏上侧，转向肢在两侧下部独立露出。蓄势压低甲面并刨地，末段停止跟随；冲出后不绕弯追人。没有足够直走廊时使用近击，不瞬间后跳造出冲刺距离。

破甲降低随后冲撞伤害并移除冲刺破障能力，不移除身体运动；破转向肢才会终止剩余冲刺并禁止再冲。两种收益让玩家选择面对面拆防线，还是绕侧解除推进。冲击已碰到谁就保留谁的伤害，随后被打断不回滚；撞到门/盾只按真实承伤处理，安全密封闸不被大体型标签穿透。撞空后完整恢复，不在收招中反手无前兆扫击。

### 投涌体：打部署和器官，不是等一个任意无敌罩消失

散热囊位于躯干后上部，投射器偏侧上方，支撑肢在下。展开部署会让囊和发射器更容易看见，但这些部位平时只受实际身体遮挡，不设计时无敌。攻击前先撑起、抬炮口、锁落点，再发出有真实飞行轨迹的一弹。

打散热囊偏向高伤害精准处理，并解除蓄压远射；打前侧投射器可能角度更容易，代价是不同伤害回报；破支撑肢只延长之后的部署并减慢换位。已发炮弹不会随拆器官消失。关门/低顶破坏弧线、横移离开落点、压近其最小射程，都应有实际效果，不用全知曲射把玩家从每个掩体后精确炸出来。

### 猎界体：倒下与真正死亡必须看得出来

这是后续特殊任务候选，不进入首轮三合同。其身体、推进肢和背侧带甲再生囊可分别处理。肌体被打倒时保留呼吸/囊体活动和未死信号；再生耗掉有限储备，囊被毁或储备耗尽才失去恢复能力。不能在战报先发一次击杀，再偷偷把同一怪满血刷回来。

正常任务路线是诱入真实隔间争取时间，继续向前取得能帮助破甲/暴露再生囊的能力，再在前方重接点处理它。熟练队伍若已经投入足够火力拆囊或耗尽储备，可以提前永久击杀；任务跳过已无意义的猎杀步骤，不生成替代猎界体。不能为了必须播完流程把普通枪设成无效。封存、提前击杀及重资产耗尽的任务分支仍需专属模板验收，敌人规格成文不表示该模板已实现。

### 三类设施：损坏功能可能也损失接管收益

炮塔的传感头是功能弱点，不增加伤害倍率；打坏它可中止未出的火力，但接管也不会重新长出传感头。炮口实际射界、底座和可绕行掩体保持可读，不能只在地图图标上标一个“安全角度”。

守备机胸前面板有甲，后侧驱动组可拆；拆驱动后原地仍能打到贴近目标，不假装整机死亡，也不会改写后瞬间恢复跟随。没有独立爆头倍数，正面破甲、绕后卸掉移动能力、断电条件与协议接管是不同路线。

维护机露出的维修臂可破，没有虚构武装或反击召唤；停掉维修会保留它本体与剩余材料。接管前打坏维修臂意味着失去维修收益。三类接管都保持原损伤、库存与计时，普通壳体修复不恢复断掉的功能部件。

## 全目录验收与当前未证明项

ENY-FULL-ACCEPTANCE · 纸面定义完成，运行测试NOT RUN。逐种覆盖静止/移动、睡眠/活动、前摇/已提交、身体/甲/功能部位/创口、单人/四人、断线/迁移；非攻击维护机不强行填一个攻击，设施也不套休眠兽唤醒状态。

记录玩家能否在不看伤害数字的情况下认出：打到甲还是身体、只是受击还是攻击已被取消、器官已坏还是仅受损、倒下是否真死。对照裸身体、精准部位、功能拆除和普通门拖延；每种必须存在不依赖指定枪械的处理方法。枪械断点见数值文件，近战按同一部位倍率核算，不新增敌人专属近战免疫。

必须检查的组合是固守＋缝行、探讯＋逐能、穿线＋逐能、破阵＋压射、投涌＋固守，以及炮塔/守备/维护与虚空兽交火。它们是对照场景，不改变三任务的角色池、远程/重型并发上限或五档难度。提前清场、拆器官、封路和接管必须真实降低后续压力，不能用额外单位补回。

本次选择明确部位结果和少量动作，拒绝每种怪加狂暴阶段、属性抗性表、无敌窗口或专属武器钥匙。风险仍是弱点在暗处难读、集中高伤使重敌没有存在感、功能拆除永远不如直接击杀，以及复合远程线封死全部机动；这些需要实际几何与团队测试。先修动作、布局或TEST数值，不把失败归咎于玩家没带推荐配装。
