# 任务候选全集、淘汰规则与兼容框架

## 本文用途

MSN-001 · CANON WORKFLOW。

本文保存当前研究与设计批次发现的**全部任务候选**，不把其中任意数量或名单冒充首发承诺。候选先接受世界观、核心动词、前向空间、合作价值、程序变化、制作成本和重复风险审查。项目所有者已审阅候选池并委托任务设计负责人选择首轮可玩原型；正式首发目录仍未锁定，旧“十二主任务、六支线”数量基线已撤销。

“全集”指当前项目与本轮外部模式研究覆盖到的完整候选集合，不声称穷尽所有未来可能出现的玩法。后续新增候选直接进入本文件对应类别，不创建讨论稿或平行清单。

采用标准不是“别的游戏有”，而是该候选能否让玩家在BREACH中做出可观察、可归因而且符合壁垒需求的决定。

## 所有候选共享的世界与空间合同

MSN-003 · CANON。

1. **大宗物资走工业物流。** 废料、燃料、冷却剂、矿材和整批设备不能靠四名队员反复手搬。小队负责勘定价值、恢复装载机/输送带/货运轨道/管线/货运界桥、清除或封闭运输路径、登记货单并确认壁垒接收。大型固定设施优先原地修复，或只带走紧凑核心、蓝图和样本。
2. **个人携带只服务一次性承诺。** 协议盘、样本箱、黑匣子、原型武器、授权模块、电力单元和伤员允许双手携带；取得后路线继续向前，不能形成同一路段多趟搬运。
3. **关键依赖单调向前。** 正常顺序为插入→侦察→取得条件→执行→世界变化→前方撤离。必需物不得放在需要该物才能进入的空间；必需步骤不得要求返回五至十分钟前的房间。
4. **支路在前方重接。** 支线、工具房和秘密房拥有前方第二出口、单向捷径或完成后远程兑现的结果。若玩家先看到障碍再寻找重资产，取物支路必须在障碍旁、障碍后或下一段主路重接。
5. **标记不是魔法回收。** 标记大宗货物只完成货单登记；还必须存在可用物流、可证实的运输安全和壁垒接收确认，任务才算完成。
6. **防守是阶段，不是任务族。** 任何候选可以含一个短暂承压步骤，但不能只靠更换终端名称和波次数量冒充新任务。
7. **目标必须产生WorldOutput。** 每个主要步骤至少改变路线、供电、视野、设施阵营、资源流、敌人入口、环境危险、情报或撤离条件之一。
8. **敌人仍遵守有限来源。** 普通休眠敌人固定有限；只有合同公开的本地警报和设施主节点能启用预先登记的有限增援源。候选不得用无限波次填补空洞流程。

以下48项全部为`CANDIDATE`。交战合同栏表示最自然的形态，不是已经通过试玩的永久分类。

## 候选筛选框架

MSN-005 · DECIDED / TEST NOT RUN · 受托任务设计裁决；尚未试玩。

候选按下列七项比较；它们是设计审查维度，不是伪精确的乐趣分数，也不能覆盖硬否决：

1. **世界观可信度**：壁垒为什么派四人小队，结果怎样进入壁垒物流、技术、能源或安全体系。
2. **独特玩家动词**：去掉任务名后，玩家实际做的事是否仍与其他候选不同。
3. **前向空间质量**：是否天然支持Branch-Rejoin、新出口和一次携带，而非折返。
4. **合作表达**：四人能否侦察、操作、掩护、运输和控场分工；单人是否仍可顺序完成。
5. **程序变化潜力**：改变拓扑、设施、敌人来源或资源后，是否会改变计划而非只改变路线长度。
6. **交战兼容性**：能否明确属于全程潜行可行、条件升级或必然激活，并兑现事前准备价值。
7. **制作与重复风险**：专属美术、NPC、动画、AI和脚本成本是否值得；是否会退化成终端、防守或清单劳动。

出现以下任一项直接否决普通首发主任务资格：强迫五至十分钟前原路折返；大宗物资靠多人多趟手搬；主目标依赖秘密字形；需要无限敌人才能成立；单人无Bot不可完成；失败后无明确降级/撤离；三个以上步骤只有同一种交互；只因Seed改变房间朝向就宣称不同体验。
