## 指标解释

### A-MODS端分类验收

全部NOT RUN；需要M3实际Loader、下载适配器与两端构建。每例记录下载请求的package_id/version/hash/network_side、激活集合、握手摘要、Profile前后差异与错误码；日志不得包含凭据。

| 场景 | 必须观察到的结果 |
|---|---|
| 作者未声明类别、发布时改类别、手改Workshop标签/metadata、绕过项目工具上传 | 未声明或非法类别拒绝发布；合法变更重新验证且hash变化；展示字段从manifest生成；当前上传的展示信息/manifest不一致拒绝激活；绕过工具仍经加载端复验，旧缓存不受后改页面标签影响 |
| 主机启用管理包H（host_only）、音效C1（client_only）、地图S及其共享依赖D；客户端使用HUD C2（client_only） | 冷缓存下载请求恰为S、D；H/C1请求为零且未安装；客户端激活S、D、C2，新地图可玩；主机保留自己的H/C1 |
| 同场景精确缓存齐全；另测主机仅有H/C1、无缺失共享包 | 零下载仍可加入；个人C2与主机C1不同不触发hash拒绝 |
| H依赖共享D；S错误依赖host_only/client_only；共享item捆绑或Workshop依赖带入单端包 | 前者只同步D；后三者明确拒绝发布/激活，不用下载单端包补洞；缺少或未知network_side亦拒绝 |
| 新武器伪标host_only，或client_only写碰撞/资源/隐藏信息 | 验证失败并定位声明与能力，不进入Ready；合法新武器按双方包共享且玩法仅由Authority执行 |
| 客户端另装共享X、个人C2冲突或依赖房间没有的X | X不在Join Profile激活；不自动下载额外共享内容；兼容个人包保留，冲突包只在玩家选择后本次停用，否则取消；离开恢复原组合 |
| S旧hash不可得、下载中断、磁盘满、校验/编译/激活/握手失败、玩家取消、房间锁更新 | 不Ready、不半激活，原Profile/订阅不变，已验证缓存不被新版覆盖；旧revision不能沿用Ready |
| 断线重连；客户端个人包版本变化；主机消失 | 重连仍匹配原共享锁且个人合法差异允许；无H的成员可加入但不能接任；已有精确H和恢复状态的候选可换主，否则RecoveryBlocked，单端包自动下载仍为零 |

### 统计与记录口径

比例的分母与排除条件必须预先写明；小样本只作早期否决，不是统计显著市场证明。性能同时报P50/P95/P99和最差段、CPU/GPU瓶颈、Host/Client差异；平均FPS不能掩盖尾部卡顿。网络报告bytes/s、packet/s、快照大小、恢复证书延迟与实际RPO；只报ping不够。

失败时保留原日志，修正原因后以新build重测。设计改变需记录新的阈值理由，不把未过标准悄悄降低。源风险登记里的Lab/未来Descent指标保留为未来测试，不因不在首发而伪标通过。
