# 新手教学、首局与长期学习

## 教什么，不教什么

ONB-001 · 受托DECIDED；理解、提示频率和练习效果未测。

玩家无需读世界观或听老玩家讲课，就能找到操作、理解成本与失败原因，并自己选择怎样完成任务。本文拥有学习顺序、练习、提示触发与学习记录，不改变[输入](玩家配装与输入.md)、[设施规则](设施信息与控制规则.md)、[合作](合作单人机器人与公共匹配.md)或[界面](../表现与资产/界面信息与可访问性.md)的实际行为。学习目标不是第一次必胜。

| 层次 | 提供什么 | 不提供什么 |
|---|---|---|
| 操作与规则说明 | 实际绑定、动作阶段、消费时点、取消条件、公开后果和真实拒绝原因；随时可查 | 装备强弱排名、推荐队伍、最短路线或应该先杀谁 |
| 可选分项练习 | 安全重复一个动作，看到自己输入和系统结果之间的关系 | 强制考试、全套顺序通关、靠完成教学解锁基础装备或难度 |
| 主动进阶学习 | 换弹阶段、预输入、贯穿、弱点与同步命中的可复现实验 | 自动倒数出刀、自动瞄弱点、宏、替玩家配装或安排职责 |

可以明确说明“普通Ping不会命令Bot花资源”“当前覆盖会触发警报”；不能推论成“所以你应该带扫描器”“先让铆钉去开门”。学习记录不用于匹配、奖励、难度、掉落或队伍能力评分。

## 首次启动与返回入口

ONB-002 · DECIDED。

首次启动先提供语言、输入、文字/字幕和舒适性设置，可接受默认值并稍后修改；默认关闭震屏、移动镜头晃动、运动模糊的基线不被教程重开。只用短说明交代外勤行动的目的，不要求角色假装不知道内战、虚空兽或壁垒历史。

随后提供“基础练习”“直接前往壁垒”；两者都不产生额外账号准入资格。跳过后训练和操作手册仍在Hub及菜单入口可见，不反复弹窗劝返。没有强制低难、指定枪械、开语音或雇用Bot的要求。

训练按分项打开，可随时退出、重置当前练习或换项目。它是独立的非奖励环境，复用正式动作、敌人/设施行为和内容定义，不复制一套更宽松的命中、噪声或取消规则。显式重置才恢复练习夹具与资源；练习结果不能写入正式物资、后勤额度、Credits、收藏、成就或任务战报。练习中使用公开示例靶和示例字形，不加载本次待出发合同的隐藏地图、真实秘密组合或兵力。

进入训练前保留正式配装预设；试枪不自动覆盖预设。具体页面返回、邀请及局内帮助按[UIFLOW-TRAINING](前端房间与会话流程.md)。练习不是多人任务中可以临时进去补弹、躲伤或复活的房间。

## 分项练习与第一份合同

ONB-003 · DECIDED；时长目标TEST，不构成实际制品。

每个练习先展示一个动作及其结果，成功后才按玩家选择展开变化；不同时介绍一整套装备和经济。基础熟悉段目标约5–8分钟，允许更慢或跳过，不设阅读倒数。其余分项独立进入，不把全部表格塞入首次启动。

| 分项 | 玩家可以亲手尝试 | 清楚的反馈与边界 |
|---|---|---|
| 移动与交互 | 走、跑、蹲、观察、交互、退出；主动Ping并取消面板 | 当前动作与实际键位；Ping是关注/请求，不替真人响应 |
| 两枪与近战 | 试用两个平等槽位、换弹、切枪；切出专用近战，按住蓄力、任意时刻松开攻击、蓄力中取消；对比Quick Melee | 近战与快捷近战分开；不把近战的松开攻击规则套给所有蓄力枪，枪械按自身卡片说明 |
| 工具与装置 | 选择自己想试的Tool/Utility，部署、收回或补充其支持的动作 | 耐久、库存、剩余时间和合法目标；不通过教学要求正式局必须用掉一次装备 |
| 声音与休眠 | 在有明确边界的练习空间对比移动、低声武器和普通攻击；观察刺激、苏醒与持续追杀 | 低声不是无声；关门/失去视线不将醒敌变回休眠。不向正式HUD添加精确噪声半径或隐藏传播群轮廓 |
| 终端与设施 | 查询目标区域，查看权限、断电、不可达三种不同拒绝；预览一次设施动作并选择提交或取消 | 只给合法查询结果；授权不等于修复或供电，预览不等于已执行，取消不能撤销已提交后果 |
| 字形与资料 | 读取示例记录、保存知识、对兼容示例门户进行本地校验 | 知识使用不消耗已登记的撤离收益；示例不解出正式秘密房，主线不以学完这项为条件 |
| 携物与补给 | 拾起/放下双手物；另行拾取、放下、合并同类资源包并实际使用；查看投送消费与回收记录 | 携物不降速；包和任务物不是一个槽，捡包不等于补过弹；通用Ammo按两槽实际补给权益和逐枪效率结算，不要求混带弹种 |
| 倒地与救援 | 对练习倒地目标开始施救、中断再恢复；查看自己的Downed可用动作和退出说明 | 复用真实生命状态夹具，不要求真实任务故意倒地、不强制配Bot；普通救援与Out恢复不混称 |
| 全队撤离 | 用有区内/区外目标的练习场查看一次共享扫描及最终分类 | 区外会被留下，不要求全员站圈，不存在个人先走；扫描不提供无敌或冻结敌人 |
| 可选Bot命令 | 自愿开启练习Bot后，选择队友/目标、停火、下令与撤回，观察受阻或资源不足 | 普通Ping不是消耗授权；不能靠免费物资、完美同步或自动打开战略设备教会流程 |

第一份正式合同来自当前同一任务板，玩家照常选任务、难度、配装及队友。教学状态不产生第九张专属Offer，不改Seed、目标、资源或敌人。规划中的15–25分钟短Demo合同只有完成自身内容验证并实际提供后才能作为可选入门内容；它不是首局必选，也不代表完整40–50分钟内容已经存在。

三类任务只提供不同的学习语境，不把玩家引向固定解法：

- 取证：查询只定位到已授权范围，读到的事实与玩家判断分开；不自动交出证据答案，也不为了教学强制打响。
- 黑启动：启动前的真实预览说明作用范围与有限来源；玩家自己决定何时提交、要不要准备支线设施，不用“未读教学”拦住合法操作。
- 货运：说明玩家负责整备运输路线，展示隔离/全吞吐的公开差异；不指定维修顺序，不要求反复跑回入口运货。

局末可自愿查看本局因果和统计；失败不弹“正确打法”，只提供已有可核实的原因、原规则说明、重试或返回入口。战报和回放仍在本人确认离开后清理；学习记录不能偷存一份永久战报。

## 学习记录与长期掌握

ONB-004 · DECIDED。

每个本地玩家档案按稳定的LearningObjectiveID维护两项独立状态：学习记录与提示偏好。它属于本地参与者，不属于角色Seat；换角色、接替Bot或加入老队伍不继承别人的学习记录。不是需要主机确认的玩法权限。

| 学习记录 | 何时可以记入 |
|---|---|
| Unseen | 尚未实际显示或主动查看相关说明 |
| Introduced | 本人实际看到该说明；仅触发候选、排队或后台同步不算 |
| Practiced | 本人在练习里实际完成对应操作；不能由队友、Bot或跳过按钮代记 |
| Demonstrated | 本人在正式情境完成过对应操作；不是精通、评级或账号毕业 |

学习记录可以由Unseen直接进入Practiced或Demonstrated，熟练玩家不必先看卡片。观察队友动作至多记录相应说明已被看到，不伪造亲手练过。记录保留完成过的最高阶段；重复练习不倒退。提示偏好单独为“情境提示开启/关闭”，全局开关可覆盖显示但不抹掉记录；玩家可分别恢复提示或重置记录。

仅保存目标ID、相关规则版本、上述状态与本版本已自动展示标记，不保存失败录像、路线、击杀明细或语音。跨设备云同步不是本批新增要求；本地损坏/缺失按普通档案处理，最多重新选择提示，不阻塞合法游戏。规则真正改变后只重开受影响说明的展示资格，不清空全部记录；仅改文案、换输入设备或版本号递增不刷“第一次”。显示时读取当前绑定，无需把键位抄进学习存档。

进阶项目由玩家主动打开：比较命中部位、护甲截断、贯穿衰减、打断、每份补给续战和目标承诺；练习输入阶段与取消是否真正提交，而非只看动画结束。允许自由换枪与目标，不输出最强榜单。两名真人可自愿练同步命中，各人自己蓄力、报时和松手；单人可看机制说明并练个人时机，不用脚本队友替他完成团队能力测试。提高来自观察与操作熟练，而不是教学勋章增加伤害。

## 合作、迟加入与局内学习

ONB-005 · DECIDED。

每人独立控制提示；房主、老玩家和其他Seat不能替其关闭或完成教学。全队操作仍按同一权限/预览/提交规则，不新增“等所有新手读完”、投票、暂停或自动Ready。队友先完成了设备操作，新手看到已提交结果即可事后查规则；被跳过的本人练习留给可选训练，不要求队伍再开一次设备或补触发警报。

迟加入先按原接管流程查看规则和当前身体，成功后读取团队合法任务进度、设施事实、资源与已知危险。只给当前可用动作的简短入口，不补播前半局卡片；没有亲眼看到的说明不记Introduced。危机展示不受“三项未学内容”等上限截断，也不从主机全图敌情推导教材。原席重连恢复当前状态，旧队友求援、教学候选和过期扫描不重播。

不向队伍展示某人“还不会”、错误排行榜或学习进度。无语音队伍可以用原Ping/请求/回应协作，教程不代答、不分配角色任务；两人同步清除不是单人通行资格。

## 提示调度、帮助与失败

ONB-006 · DECIDED；并发数量为TEST。

局内默认开启短情境提示，每个目标在相关规则版本下最多自动展示一次；未实际显示的不消耗次数。只有合法可知的当前对象/动作能触发，玩家主动查阅不限次数。已练过或正式做过的动作不再自动介绍；关闭/跳过不是“已经掌握”，也不会因连续失败反复弹出。

| 首次情境候选 | 可以说明什么 | 何时丢弃候选 |
|---|---|---|
| 在无迫近已知危险时首次切出专用近战 | 当前输入方案的蓄力、释放与取消 | 切走装备或开始需要专注的动作；不在挥击中弹卡 |
| 本人首次拾起资源包 | 持包与使用不同，使用入口在哪里 | 包已放下/用掉，或发生危机；不事后提示“尚未使用” |
| 本人主动打开终端查询/覆盖页 | 查询与提交分开；当前可查的授权和代价 | 关闭页面、权限/设备版本变化；真实新代价仍由正常预览展示 |
| 本人首次拿起双手任务物 | 怎样合法放下、再拾回；没有搬运降速 | 已放下或状态失能；不指示前往未发现的目的地 |
| 本人主动打开Bot指令页 | 所选队友、目标与消耗授权；普通Ping不代替命令 | 换对象或退出；不能自动替其确认 |
| 首次查看撤离控制/区域说明 | 共享扫描与区外留下的规则 | 扫描进入紧急阶段时不弹长卡；持续进度和区外名单照常显示 |

任务/难度规则、房间版本、包同步与Mod来源风险在对应前端页面提供操作说明，不加入首次持枪的教学队列。说明加入/取消/拒绝含义，不推荐模组或要求现在接通Steam服务。手册可按动作、设施、资源、生存、联机与字形查找；未解锁收藏不妨碍查询基础公共规则。

同时最多一张教学卡，复用现有输入短提示，不再叠一套按键条。已知直接危险、队友状态、真实操作拒绝与共享任务危机按UX独立优先显示，不受教学开关或次数限制。忙于战斗/救援时不自动展开讲解；候选在对象、阶段或事实失效后丢弃，不积成战后轮播队列。不用隐藏敌人数判断能否显示教学。

手动打开帮助可查看完整操作，但在线世界照常运行，退出键保持可见；不锁镜头、不代取消操作、不使敌人等玩家读完。关闭帮助消耗此次界面输入，不将它穿透成开枪或工具使用。玩家选择关闭教学后，仍能看见当前动作键、设备代价、警报预览、队员状态和撤离进度。

失败解释只到证据边界：“库存不足”“输入发生在不可取消阶段”“当前授权不能访问”，不推断未发现的另一条路线、隐藏弱点或秘密字形。多次失败不暗降难、不送弹、不重新掷图、不推荐装备；玩家仍可主动修改下一局公开难度或去练习。因果不明确就标未知，不把队友默认列为责任人。

## 内容与本地化接口

ONB-007 · DECIDED；下列字段是设计要求，尚无运行实现。

每项内容声明LearningObjectiveID、责任规则ID及语义版本、适用动作/设备、合法触发条件、本人练习/正式完成事件、完整文本键、失效条件和可选练习夹具。先修项目只用于说明顺序和主动导航，不能成为开局或设备使用锁。教材读取当前定义的动作与消耗，不另存枪敌数值表；定义已变但说明不适用的内容不得以旧说明发布。

正式生成器验证危险预兆、可查操作与承诺前成本，不读取个人学习状态来改变布局；所有人得到同一实例。练习夹具的显式重置不进入正常Run事务，官方包路径与实际动作验证仍沿现行架构。这里只规划已有内容的组合练习，不预建通用教学引擎、场景编辑器或另一套任务系统。
