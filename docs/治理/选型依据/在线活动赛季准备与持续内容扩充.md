# 在线活动、赛季准备与持续内容扩充

## 决定

LIVEOPS-DECISION-001 · 已确认产品方向 / 尚未实现。

BREACH支持日、周、月及临时特殊活动。运营人员可以把已经随客户端或受验证ContentPackage发布的任务、敌人、武器和Modifier组成活动，设定UTC起止时间，也可以立即启动、暂停新匹配、延长、结束或回滚。普通八份共享Offer继续存在；活动使用单独的特殊合同入口，不吞掉普通任务选择。

活动不是远程脚本执行。线上控制面只能引用客户端已经认识、通过schema和兼容性验证的稳定ID，并填写被定义允许的参数。新增敌人、武器、任务动词或新Modifier实现仍须通过正常构建或ContentPackage发布，不能在服务器控制台里临时写代码。

每个Run在Ready提交时冻结`EventRevision + RulesetHash + ModifierBundleHash + ContentGraphHash + MissionSeed`。活动被编辑、暂停或回滚只影响尚未锁定的新Run；正在进行的Run继续原快照并按原奖励规则幂等结算。紧急安全熔断只能停止新Run，并明确处理已锁Run，不能悄悄换规则。

## 为什么这样选

LIVEOPS-DECISION-002 · DELEGATED DECISION。

日历排期本身不产生好内容。真正有价值的是用公开、可组合、有代价的规则重新提问：队伍怎样配装、清房、管理资源和应对任务响应。数据驱动活动让运营能快速重组已经验证的系统，同时避免热修脚本、客户端与房主规则不一致、活动中途改写一局，以及为每次周末挑战发新构建。

普通任务板和活动入口分离，是为了让不想追日历的玩家始终能玩基础游戏，也避免一场实验性活动污染全部公开匹配。活动可以给额外Credits、档案、成就或外观，但不能垄断必要武器、敌人、主线事实或基础玩法能力。

## 已拒绝方案

| 方案 | 状态 | 原因 |
|---|---|---|
| 把活动规则硬编码到客户端日期判断 | REJECTED | 无法安全暂停、延长、回滚或处理时区；旧客户端容易产生不同真相 |
| 允许后台下发任意C#/Luau/表达式脚本 | REJECTED | 等同远程代码入口，破坏包验证、恢复和安全边界 |
| 每次活动都发一个完整客户端补丁 | REJECTED AS DEFAULT | 能发布新内容，但不适合仅重组既有规则的日常运营 |
| 活动替换普通八Offer | REJECTED | 玩家被迫参加限时规则，普通匹配与学习路径被破坏 |
| 为PvE活动建设竞技级反作弊 | REJECTED | 不符合成本和产品目标；仍保留认证、schema、幂等与限值，防止服务数据损坏 |
| 现在就实现付费Season Pass | DEFERRED | 价格、权益、法律、内容产能和玩家价值均未批准或验证 |

## 赛季与商业边界

LIVEOPS-DECISION-003 · 未来能力 / 商业方案需要所有者裁决。

运行时预留通用`ProgressionTrackDefinition`：轨道有稳定ID、版本、起止规则、里程碑和奖励引用，可用于免费赛季档案、社区行动、教学路线或未来商业产品。基础玩法只读取“当前账号可领取哪些已验证奖励”，不理解购买价格、商店SKU或Steam Entitlement。

未来若采用Season Pass，必须由项目所有者另行批准价格、时限、付费权益、旧奖励去向和披露。当前推荐是：只含外观、称号、壁垒展示物和档案展示；不售战力、不售随机箱、不把新武器/敌人/任务锁在付费轨道，不要求连续登录，不做会永久消失的关键剧情。是否付费、是否限时及是否存在Premium Track现在均为OPEN。

## 持续内容原则

LIVEOPS-DECISION-004 · CANON DIRECTION。

上线后新增敌人、武器、任务、设施和Modifier走官方内容包与社区Mod相同的稳定内容注册路径，区别只在签名、来源、分发与官方资格。活动按Tag与Capability选择合法池，但最终快照仍记录精确ID和hash；不能仅写“所有步枪”然后让一次热更新在玩家不知情时改变已锁Run。

新武器优先增加横向玩法，不用持续抬高伤害淘汰旧枪。新敌人必须带可读前兆、反制、ThreatCost、ActiveSimulationCost和任务用途。新内容进入普通池与活动池是两个独立批准动作，防止刚发布的内容立刻成为强制活动依赖。

## 重审条件与后续验证

若活动入口显著分裂匹配、日常奖励制造签到压力、Modifier组合产生唯一最优配装、运营控制面不能在故障中回滚，或内容产能无法支撑稳定节奏，就降低活动频率或取消对应Cadence，而不是用更高奖励强迫参与。

实现前须完成本地假服务、时间旅行、跨版本、重复Result、活动中途暂停、控制面失联、错误组合、旧客户端和Run恢复测试。当前没有部署服务器、活动后台、Season Pass、实际排期或运营团队。
