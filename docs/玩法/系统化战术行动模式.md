# 系统化战术行动（Operation）

## 玩家目的与范围

进入失控设施，带着事先选好的装备面对资源、路线和团队执行问题。本文仅拥有模式旅程与配置差异，共享战斗、经济、世界、生命规则分别归其系统文件。

OPS-001 · DECIDED · 来源：当前产品基线；历史见Git。

Run是一个连续Operation/Facility/Mission，无玩家可见Layers；资源、门、设施状态、LogisticsQuota/GrossRecoveryLedger、字形记录、补给与Optional后果连续保留。Mission比改装更核心；采用有限Field Modification，不启用自动Fusion或无限Relic池。移除改装后的同任务对照仍应有趣。

OPS-002 · CANON · 来源：SRC-SSOT-2.0 §4A.8、§4A.16。

完成目标后以可观察的世界恶化推动离开，无“60秒到点处决”式硬撤离计时；留下不提供稳定farm收益。真正不可恢复Wipe意味着失败，无gameplay checkpoint。恢复见[生命](生存倒地与失败恢复.md)，持久收益见[进度](知识永久进度与壁垒.md)。

## 局内改装的定位

OPS-003 · DECIDED · 来源：当前产品基线；历史见Git。

唯一首发Operation；入场锁装备身份，局内以WeaponModule/ToolModule/TeamProtocol改变解法。标准长局初值每玩家2保证+1可选机会；安装预览后3s在合法维护点提交，同挂点替换、旧件留世界。原自动Fusion仅Lab/FUTURE，不能吞掉Operation配件。数量和挂点归[测试参数](../制作/初始测试参数.md)，统一数学归[修改与效果](统一改装与效果系统.md)。

## 玩家旅程与状态

OPS-014 · DECIDED · 来源：当前Operation合同与本轮完整性审计。

循环按四个尺度共享同一承诺，不建立互相脱节的四套进度：

| 尺度 | 循环 | 玩家获得的反馈 |
|---|---|---|
| 秒级 | 观察前兆→移动/瞄准→提交动作→命中/设施响应→重评 | 枪感、部位、声音、资源扣除与明确拒绝 |
| 遭遇级 | 侦察休眠群/来源→选择打、绕或改环境→执行→杀死或永久隔离已激活威胁 | 路线安全、资源消耗、世界状态变化 |
| 单局级 | 任务板→房间/配装→Recon→Commit→Execution→Exit→Debrief | 合同结果、详细战报、收藏与横向奖励 |
| 长期 | 比较战报→学习规则/解锁横向选项→挑下一合同→提高难度或尝试新方案 | 玩家掌握、Archive、外观与更广解法；无永久战力滚雪球 |

若秒级战斗不成立，遭遇和任务不能用奖励拯救；若单局选择无法在战报复述，程序随机与长期奖励不得继续扩量。

OPS-015 · DIRECTION · 来源：SRC-USER-2026-09-05-MISSION-DEPENDENT-STEALTH-LOUDNESS；详细规则见[潜行合同STL-010](潜行唤醒与持续追杀.md)。

任务Offer必须公开“全程潜行可行 / 条件升级 / 必然激活”交战合同。数据盘、普通通风或研究提取可以允许熟练队伍安静完成；设施主节点启动、全功率载波重写等目标可以明确要求后半段进入全面激活。必然激活不是跳过潜行：队伍在触发前清除休眠群、封入口、接管防御、布置重资产和规划移动路线，以此决定激战规模与形状。交战合同不得在Seed生成后暗改，也不得把本应安静的目标临时换成无预告强制尸潮。

OPS-016 · CANON/DIRECTION · 来源：SRC-USER-2026-09-05-GLOBAL-ROTATING-MISSION-BOARD、SRC-USER-2026-09-05-FACILITY-MANIPULATION-AND-CARRY、SRC-USER-2026-09-05-RESOURCE-PACK-SCRAP-AND-RESUPPLY、SRC-USER-2026-09-05-GLYPH-KNOWLEDGE-SECRET-NODES。

完整Operation循环固定为：

`全服共享任务图 → 选择合同与难度 → 组队/匹配 → 按公开风险协同配装并Ready → 插入 → 定位目标 → 逐Zone侦察与推进 → 投资可选设施/权限/资源 → 完成多阶段主目标 → 承担安静、条件升级或必然激活结果 → 立即撤离或继续贪取 → 战报/临时回放 → Credits、字形与收藏结算 → 返回已轮换或仍有效的任务图`。

| 阶段 | 玩家必须作出的决定 | 系统必须兑现的结果 |
|---|---|---|
| 共享任务图 | 在同一轮八份合同中选择区域、主任务、交战合同、已知环境、奖励与难度 | 所有玩家看到同一轮Offer；可精确选择一份Offer/难度，也可明确勾选可接受的多个Offer/难度后快速加入，系统不得暗换未选项；锁定后不因定时轮换中途失效 |
| 房间与配装 | 组齐真人后，Primary、Secondary、专用近战、团队工具、个人Utility与队内职责如何覆盖合同风险 | 房间内始终可复查完整任务卡和队友配装；任务锁定后规则、奖励和Seed不可通过退出重掷，任何任务/难度/包变化都会清除Ready |
| 插入/定位 | 直接推进，还是先查终端、恢复情报或寻找替代路线 | 起始区快速进入操作；普通终端给目标Zone和合法本地事实，不送全图透视 |
| 逐Zone推进 | 对固定有限休眠群同步清除、低特征射击、绕行或主动开战 | 清掉的敌人不补刷；激活敌人持续追杀，直到死亡、永久隔离或行动结束 |
| 设施投资 | 是否为权限、地图、生命信号快照、门控、防御、冷却、运输、资源仓或门户支付电力单元、Component Pack、时间和路线风险 | 操作改变可观察世界；不同Site只提供系统子集，最高权限不自动包办全部优势 |
| 主目标链 | 如何完成定位、访问、运输/修复/校验和最终提交 | 目标含3–5个有空间意义的步骤；不可逆操作前预览激活范围、警报、门与支线后果 |
| 目标响应 | 利用此前清场、封口、炮塔、重资产和补给处理任务结果 | 普通失败不加敌人；只有公开的本地警报或主节点启动启用登记入口和有限预算；节点启动默认只影响目标室与合同明确的连接Zone，不全图唤醒 |
| 贪取/撤离 | 立即保住结果，还是继续做支线、RecoveryRecord、字形秘密节点、故事和原型资产 | 主目标完成即开放合法撤离；继续探索不触发隐藏动态补怪，风险来自仍在场敌人、未停警报、资源与路线 |
| 战报/结算 | 从因果、资源与回放理解为何成功或失败 | 详细统计与临时本地回放；成功撤离结算Credits、字形记录、收藏和横向奖励 |

标准长局节奏目标为：前2–4分钟插入并得到第一项可行动情报；随后在侦察、设施与任务步骤之间反复循环；后段由合同而非统一脚本决定是否发生强制交战。撤离不固定生成尸潮：安静完成允许安静离开，已激活敌人会追至合法隔离或撤离边界，未关闭警报继续消耗其剩余有限预算。

设施选择必须服务这个循环。发电机只是可能的一个设备；玩家还可重新分配电力、封门、改通风/照明、接管安保、恢复扫描、分配冷却、操作运输、利用工业设备、医疗净化、现场制造或改写字形路由。每张任务只突出三至六套相互作用的系统，不能把完整设施清单全部塞入一局，也不能把它们退化成不同名字的终端读条。

电力单元采用双手物理搬运，但不降低地面移动、奔跑、跳跃或翻越速度；切回枪械先把单元放到合法位置。每名玩家只能携带一个可放下、转交、拆分和同类合并的Resource Pack。标准枪械在拾取/支援层统一由Ammo补给，Energy设施端口只提供固定有限的额外充电。DataTap、AssetSurvey、DiagnosticExtract及其他批准的现场回收动作生成LogisticsQuota，约1秒的常用交互既可见又不拖沓；后勤额度只用于补给传输。设施使用实体部件、电力单元、工具或介质。Credits按GrossRecoveryLedger中已登记并成功结算的回收价值计算，不因局内消费而减少。

筑路者字形是可使用的知识，不是Support点数。玩家可在当局收集序列、地址与校验记录；满足门户、供电和本地条件时打开彩蛋式秘密房或秘密节点。成功撤离后，壁垒为经验证的字形记录支付Credits并写入全队永久Archive；当局使用过该知识不降低结算。

Authority拥有run phase和唯一结果；模式不自行复制伤害、物资、合成或存档实现。离队/重连保留当前角色Seat与配装状态，新进者可接管空Seat并读取简短当前目标/资源/已提交决策，不重做briefing才能游玩。

### 一局完整Operation实际怎样玩

这是一份供项目所有者批准体验身份的连续走读，不复制各责任文档的实现字段。玩家看到和做出的事情依次是：

| 时段 | 玩家实际看到与操作 | 必须形成的决定与反馈 | 若失败，玩家应能怎么解释 |
|---|---|---|---|
| 任务板 | 同一轮八份普通Offer；若有活动，另列特殊行动，逐卡比较区域、设施主题、Primary、零到一个常规Secondary、交战合同、Modifier、装备限制、已知危险、奖励、预计长度和五档难度变化 | 先决定“今晚要处理哪种问题”；可精确找一份，也可明确勾选可接受集合后快速加入；活动不吞掉普通Offer，公开匹配不能在不知道规则时盲组 | 没找到房间是人口/筛选问题；不是系统暗换任务、难度或活动规则 |
| 房间与配装 | 看到四个固定Seat、队友Primary/Secondary/近战/团队工具/个人Utility、资源职责和Mod包状态 | 组齐后协同配装；允许重复装备，不设职业钥匙；任何合同、难度或包变化都清除Ready | 入场前已知风险不足导致无解，属于内容合同错误，不归咎玩家猜错 |
| 插入与第一次情报 | 在2–4分钟内看见目标方向、第一组休眠威胁、一个可查询终端或现场线索，以及至少两条前向可能性 | 是直接推进，还是先花位置与时间换取目标Zone、权限或设施状态 | 若前四分钟只有走路、读设定或等终端，本局节奏失败 |
| 休眠群 | 观察传播关系，标记目标，分配同步切割、低特征弱点击杀、门隔离、诱饵绕行或主动交火 | 用准备时间和站位节省弹药/医疗；失手后短`Stirring`允许补杀，进入`Active`后只剩战斗、永久隔离或撤离 | 谁、什么刺激、哪条传播链唤醒了多少敌人；没有会自己消退的追捕条 |
| 前向侦察 | 通过终端与现场观察得知目标Zone、门态和本Site真实可恢复能力，不获得全图透视 | 从至少两条真实存在的路径中选择：拿凭证、局部重映射、强制覆盖，或先取一项设施条件 | 选项不存在却显示按钮、最高权限包办所有收益或唯一凭证锁在自己门后，都属于坏Seed |
| 设施投资 | 实体操作门、配电、通风、安保、扫描、冷却、运输或字形路由中的三至六套系统；常用动作短，重大提交先预览 | 用电力单元、Component Pack、冷却、工具、路线或暴露换取具体WorldOutput；至少两套系统互相影响 | 玩家要能指出“我把什么给了哪里，因此哪扇门、哪条入口、哪件防御或哪项情报改变了” |
| 现场回收与支援 | 每局只遇到二至四种语义匹配的RecoveryRecord来源，以短而不同的现场动作记录；在兼容接收点选择Ammo、Medical或Tool Pod | 主路额度保障恢复空间，可选来源争取第三次投送；现在把额度花在哪里，而不是是否牺牲撤离Credits | 额度消费只减少`LogisticsQuota`，不倒扣`GrossRecoveryLedger`；重复记录、击杀刷额度或自动吸废料属于系统错误 |
| Primary提交 | 完成3–5个有空间意义的步骤，在不可逆提交前看到会影响哪些门、区域、来源、货物或Secondary | 把前半局准备兑现为后半局优势；合同只允许三类公开结果之一：全程潜行可行、条件升级、必然激活 | 任务不能在最后一分钟偷换成全图尸潮，难度也不能改写交战合同 |
| 目标响应 | 清过的休眠群保持消失，封过的入口保持封闭，接管的防御按剩余弹药工作；只有登记的本地警报或主节点来源投入有限敌人 | 持续移动、读前兆、守关键空间、重新分配火力；在场成本、远程和重型硬顶只停止新增，不偷删敌人 | 敌人从哪个实体入口来、来源为何启动、为何停止；没有“太安静所以背后刷一波” |
| 贪取或撤离 | Primary完成后立即开放前向撤离；地图仍保留未做Secondary、字形暗仓、故事证据、RecoveryRecord与原型重资产 | 保住成果，或用现有物资、路线和仍存威胁换取额外价值；没有隐藏撤离秒杀计时 | 继续探索的风险来自已知未清区域、未停来源、资源和路线，不来自动态作弊 |
| 战报与返回 | 先看结果、关键因果和团队资源，再按需展开成员×武器×敌人×阶段统计或临时战术回放 | 理解最大转折并形成下一局计划；无MVP与公开K/D排名 | 证据不足的潜行破坏必须标共同/环境/无法归因，不能为戏剧效果点名 |
| 结算 | Credits、Archive、字形知识、收藏和横向选项按资格幂等提交；离开结算清除本地战报和回放 | 长期获得更多表达、知识与解法，不获得永久基础伤害碾压 | 已Bank的知识可在Wipe后保留；普通未撤离回收价值按进度合同处理，不由回放文件决定 |

三个首轮主任务必须让同一循环产生三种明显不同的句子：**换流器黑启动**是“先塑造战场，再主动启动一场有限但必然的激战”；**分布式数据取证**是“用物理证据和权限路径完成可全程安静的可信结论，失误才转战斗”；**货运线夺回**是“让人员路线领先自动货运线，在安静隔离与更高价值的全吞吐之间承担公开风险”。若玩家只能把三者都复述成“找终端、读条、守一波”，本批设计失败，不得用奖励差异掩盖。

### 残酷一致性结论

文档层已经形成一个可灰盒验证的游戏，不再是互不相干的功能清单；但它仍然只是**可测试的设计**，不是已证明好玩。审阅后的处置如下：

| 发现 | 当前处置 | 未过线时必须做什么 |
|---|---|---|
| 核心张力曾被“潜行、设施、搜集、枪战、字形”五套说法分散 | 统一为“用时间/位置/物资/暴露换更多情报和控制，还是带着未知前进”；所有子系统必须服务`侦察→改写→执行` | 删掉不能改变计划或WorldOutput的系统，不给它补更多奖励 |
| 任务、匹配、配装顺序存在两套流程 | 锁为先看Offer/难度，再匹配或建房，组齐后协同配装并Ready；邀请加入者必须能完整复查已锁任务 | 不建立第二套“盲匹配后随机派任务”流程 |
| 八Offer×五难度会把公开匹配切成四十格，再叠地区与Mod更糟 | 保留精确选择，同时提供玩家显式勾选可接受Offer/难度的快速加入；最终锁定前展示实际命中的任务 | 若真实等待仍不可接受，先合并非关键筛选或减少同时Offer，不做隐藏战力匹配和暗换难度 |
| 前半局可能准备十分钟仍没玩到核心 | 2–4分钟内交付第一项可行动情报、第一组休眠威胁和路线选择；普通终端不允许三人长期空等 | 缩短插入、合并查询、前移选择，不能用开场配音遮住空白 |
| 最高权限、友军炮塔或第三次Pod可能成为每局无脑必做 | 最高权限只解锁Site子集；友军保留固定射界/弹药；第三次Pod必须来自可选路线，三者均支付可见机会成本 | 若选择率在可比较局势中无条件统治，削收益或改变空间成本，不暗加敌人补难度 |
| 低特征枪可能变成“伤害低，所以谁也不用”的陷阱 | 它必须能在声明距离与弱点条件下可靠完成自己的休眠目标；代价落在群体DPS、停止力、弹量和失手传播，而非让正确使用也随机失败 | 若它不能稳定兑现潜行职责，先改阈值、弱点与反馈；不靠隐形潜行倍率作弊 |
| RecoveryRecord与字形都像“插盘收集”，容易变家务 | 每局只取二至四种来源族；RecoveryRecord服务本局补给与Credits，字形服务可推导路由、秘密空间和Archive，两者不能共用同一重复动作链 | 玩家多数仍概括为插盘时，删除来源或重做实体动作，不继续加第九种名词 |
