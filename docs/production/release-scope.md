# 产品范围、首发合同与明确不做的事

## 选定的产品

SCOPE-001 · DECIDED · Authority: delegated；决策记录基础产品范围与Operation装备决策。

唯一基础产品为1–4人合作PvE Operation。40–50分钟为标准完整合同的体验目标，15–25分钟为Demo短合同目标，10–15分钟为最初灰盒证明目标；三者不是互相矛盾的全局任务时长。倒地救援、有限资源、设施控制、手制Cluster程序组合、局部可解释后果和有边界的武器改装构成核心循环。Descent不是第二个首发入口，不为它复制首发教程、经济、内容、匹配池或存档实现。

四名固定队员、同局不重复Seat、正史持续存活；无角色职业钥匙，任何角色可选任意合法枪、工具和个人战术模块。官方Operation入场为两把枪、一件工具、一件战术模块及Quick Melee。工具与模块各有自己的资源合同；不把Active藏进一个免费的第三武器。传统动能、电磁实体弹、有限Energy Block三类枪械采用有限资源；热量不是免费弹药。Staff/Spell不进入官方Operation；主武器近战谱系留在内部实验，Quick Melee保留。

## 内容规划基线

SCOPE-003 · TEST · 这是排产起点，不是“这些数量足够卖”的证明。

先完成BLACKSTART的一条无软锁可玩链，再从[任务目录](../content/mission-catalog.md)选择三个不同动作的主任务原型和三个支线原型、从[设施模块目录](../content/facility-cluster-catalog.md)搭建两个区域语法，最后覆盖既定六任务族：废料、战略资源、技术、研究数据、设施恢复、威胁处理。六族要有不同动作、空间改变或风险决策，不能都是站在终端旁读条。首发计划至少每族两个可组合任务变体、两个区域各一套完整手制Cluster kit；具体房间数只在M4重复度测试后扩充，不以房间数量冒充内容质量。

军械先做AR、Shotgun，再做EM、Energy单发/连发/蓄力三把独立枪；首发规划六个清楚分工的枪平台、三工具、三战术模块、三Team Ordnance。敌对内容按[敌人目录](../content/enemy-catalog.md)先做逐能体、压射体，再扩到五种常规虚空兽、一个特殊猎界体与三种设施单位；灼星种和借尸者不进入基础版最低量。扩展平台或敌人只能在现有每件有使用理由之后加入。四人全部可选；不以长时间升级锁掉合作所需能力。调参表和初版卡的数值均为TEST，未通过多配置试玩不得宣称最终平衡。

首批叙事采用四个角色收藏集合加两个设施事件集合，每集合3–5份相互补充的证据作为制作估算。人物集合在角色批准前不写成历史事实；设施集合可以先用无名维修事件验证交付。更多配音、收藏和皮肤不能阻塞M2。

## 明确后置与不支持

SCOPE-004 · DECIDED。

Descent、其全服联合行动和行星端点是未来扩展；没有获批日期、销售承诺或已部署聚合服务。完整Forge可视编辑器、任意脚本层、Native DLL、完整Total Conversion开放、官方常驻模拟服务器、其他商店、主机平台及跨平台联机不在首发关键路径。保留经过真实官方内容证明的扩展接缝，不提前实现空框架。社区专服保持架构可行性，公开发行服务器工具要单独完成运维/内容包验证。

不做PvP、竞技排位、公开K/D排行榜、单一MVP、战利品抽箱、付费战力、Battle Pass、强制每日任务、FOMO轮换、主线章节门锁、永久个人节点征服、无限刷支援经济、在线生成对话、任意代码自动下载执行。总改支持方向不等于无限制运行第三方代码的权利。

## Demo与后续发布

Demo是一份可从头到尾完成的短Operation，使用同一运行时和较小内容集。支持好友合作及当前已完成的安全包路径，但不因未来TC方向要求Demo先完成整个编辑器生态。Demo只迁移幂等的外观/徽章及明确允许的横向解锁，不迁移正在进行的Run、临时战报、任务资源或秘密档案全量。发行价、日期、标题法律清查与实际支付只由所有者批准。

## 范围变更规则

开发者可以调整TEST值、替换失效依赖、重构架构并记录证据，不能以“范围控制”为名暗删明确要求。双视角、Bot、Deck目标或主机恢复若成本不可接受，提交OWNER-04：当前成本证据、推荐删改、损失和替代方案。没有承诺它们便宜，也没有替所有者放弃它们。
