# 叙事交付、对白与本地化

## 玩家目的与范围

玩家在行动中理解任务，重要信息错过后可补读，剧情播放不控制权威世界结果。正史归[世界观](世界观与正史圣经.md)。

NDL-001 · DECIDED · 来源：SRC-SSOT-2.0 §35.1–§35.2；来源属性：INHERITED。

通过briefing、Terminal日志、环境、壁垒NPC/Handler、Archive、短radio与少量高价值sequence交付；不长篇抢玩法。Dialogue semantic state与voice播放分离，战斗时可按定义暂停/转radio/继续/中断；重要内容Archive可恢复。Skip/快进只改呈现，不重复/漏掉已提交世界后果。选择0..N，重大team choice才SharedDecision，在线客户端按各自语言/字幕/skip偏好播放。

NDL-002 · CANON · 来源：SRC-SSOT-2.0 §35.3。

Text/subtitle/voice语言独立；缺voice asset允许内容回退，CJK/RTL/换行进入本地化验证。Glyph通常不作为普通语言翻译。

## 玩家流程、状态与所有权

NDL-003 · DECIDED · 来源：本轮系统扩写；按SRC-USER-2026-09-05-COLLECTIBLE-ACHIEVEMENT-LORE调整。

Authority确认合法发现后，一路更新本局知识与发现凭据，另一路产生可呈现的语义事件，经本地优先级排队、播放、跳过或打断。永久Archive只按[进度PRG-004/005/014/015](../玩法/知识永久进度与壁垒.md)在合法Bank或满足撤离结算条件时提交；看完、跳过、开菜单与战报确认都不签发收藏或奖励。Authority拥有ConversationChoice/WorldConsequence，Client拥有PlaybackCursor，不能以音频结束时间推进任务。公共行动知识不依赖Archive解锁，收藏只补充局部人物、事件与技术细节。

| 当前 | 事件 | 结果 |
|---|---|---|
| Pending | 高优先级战斗提示 | 丢弃失效短句；仅仍有效且未过期的候选可短暂等待 |
| Playing | 本地Skip | 已提交后果不变，转完成呈现 |
| Playing | 按定义被战斗中断 | 人物短句与短交换直接结束；已合法发现的长档案可按定义补读，不补播过期呼救或玩笑 |
| ChoiceOpen | 合法选择提交 | 唯一世界结果，关闭旧revision |
| Disconnected | 重连 | 恢复semantic state，不重复奖励 |

## 模式、内容与边界

NDL-004 · DECIDED · 来源：本轮系统扩写；SRC-USER-2026-09-05-COLLECTIBLE-ACHIEVEMENT-LORE。

Operation短信息支撑设施决策；Lab不要求叙事。台词卡记录speaker role、text key、事实状态、触发前置、priority、interrupt policy、字幕/SDH、Archive target、world effect ID。收藏卡另记录载体、作者、可信度类别、语义兼容Cluster、关联集合、重复获取与成就条件。缺录音用已验证文字/字幕表达，不伪造已经制作配音。字幕方向不透露未知敌人位置。

日志、维护记录、私人通信、物品说明、Prototype来源、环境痕迹、守门人状态与隐藏字形房可以共同讲述同一局部事件。环境摆设不能单独冒充精确事实；带立场的文本必须保留作者身份；Archive明确标记`记录事实`、`当事人陈述`或`环境推断`。程序生成只移动完整的语义场景Cluster及其进入成本，不能把彼此关联的关键道具随机拆散到不相关房间。

## 参数、示例与验证

NDL-005 · TEST · 来源：本轮扩写。
对白不设统一字数或秒数上限，长度按NDL-DIALOGUE-LENGTH处理。正常：一个玩家英文语音，一个中文字幕，共同任务同一提交。失败：播放未完成就跳过，门不会因此开两次。跨系统：上传后Archive补读证据，普通Lore不占紧急倒地提示通道。

NDL-006 · TEST · 来源：本轮实验建议。
测试CJK/RTL长文本、缺音频、全员同时skip、战斗中断、迁移及不同Archive完成度玩家组队；零重复世界效果，关键任务可在静音和零收藏条件完成。让未读世界观的测试者用两条独立线索复述一个局部事件，并检查其能否分清事实、证词与推断。中文/英文为当前文字基线，更多语言、配音预算、演员与最终成就名仍待相应批准。首批六集合、每集合3–5证据为制作估算，不是假装文本与具体载体已经获批。

## 首批收藏的事实与交付映射

NDL-COLLECTION-MAPPING · 2026-09-07受托完成大纲审查与首稿。六组、十九篇中英正文及具体载体唯一维护于[首批收藏目录与交付卡](../内容/收藏/首批收藏目录与交付卡.md)，本节只保留通用交付验收。角色基础经历和历史不变；新增普通事件、载体、署名与具体措辞为PROPOSED，待OWNER-01创作审阅，不新增真实姓名、年龄、导师、家人或共同事故。

### 收藏交付验收输入

内容卡必须提供：稳定条目/集合ID、事实引用及批准状态、载体与可信度类别、中文/英文文本键、适配Cluster标签、发现交互、知识/奖励分类、重复规则和已定义的成就关系。没有批准的作者不填一个假人名；纯系统记录明确标系统来源，角色陈述仍需有获批说话依据。环境推断只授予推断条目，不能自动改成作者层事实。

同一集合可跨多次兼容普通合同完成，不锁限时活动、唯一Seed或某个角色席位；Cluster连同理解所需设备/痕迹一起布置。发现可以同时服务多个主题索引，但不得复制成两份付费/一次性奖励记录。秘密房的成本仍归字形与任务合同，收藏不另给主目标加必经钥匙。

| 纸面检查输入 | 必须保留的结果 |
|---|---|
| 发现后跳过全文，再失败且未Bank | 不因播完/跳过保留永久记录；只按既有进度合同结算 |
| 先成功Bank，再团灭 | 合法知识保留，未撤离Credits不因Archive可读而提前到账 |
| 四人重复检查同一载体，随后有人迟加入 | 不重复发唯一奖励；迟加入资格按PRG-015，不补发此前全部档案 |
| 中英文字顺序不同、缺语音、全员静音 | 相同事实/奖励结果，主目标和撤离不依赖读完 |
| 取证任务上传点未声明知识Bank | 只推进任务证据；不能因有“上传”二字就保存全队收藏 |
| 地图随机替换了设备、删去相关痕迹或角色未在场 | 内容适配验证失败，不能照播与当前事实冲突的说明 |

已完成事实来源审查与十九篇双语候选正文；尚未完成最终创作批准、玩家复述测试或独立故事盲审，不能由文件字段齐全代替。对应待批准内容只在OWNER-01维护，不再次创建“叙事待定全集”。
## 战斗中的信息优先级

优先级按信息紧迫性与用途决定，不按长短决定：关键战术事实优先于非紧急人物反应与背景内容。战斗不强播长档案，不让关闭语音失去关键操作信息。重复合同不重复假装首次发现核心历史。人物与创作事实仍按OWNER-01，冷却初值为TEST；完整故事审阅入口已独立提供。

当前中英录音取材、语义键、场景前置与表演提示见[对白与配音试稿](外勤小队中英对白与配音试稿.md)。试稿未通过口吻或音频审阅，不是已录制资源；字幕与实际语音时长分开维护，不靠台词播放驱动任务结果。

## 情境对白调度合同

NDL-DIALOGUE-LENGTH · CANON（长度方向）；具体调度与审阅方法受托DECIDED，未试听。来源：SRC-USER-DIALOGUE-CONTEXTUAL-LENGTH，2026-09-07。

所有者明确允许更长的台词，不要求每句简短。对白长度由眼前情境、表达动机和信息时效决定；短句不是自然的证明，长句也不是缺陷。不采用统一字数/秒数上限，也不把所有旧句强行扩长。紧急提醒先说危险或需要做什么，后续解释仅在仍有用、未被新危机抢占时继续；非紧急的设施交流、关心、感谢和共同反应可以包含完整句子及多轮交流，不限于档案独白。

较长台词仍走同一调度通道，不因长而降级，也不因想说完而获得不可打断权。排队过期时间限制的是尚未开始的候选，不是录音长度；开始后被危险抢占则结束，不补播失去语境的尾句。字幕按中英各自的语义与自然停顿分段，不加速录音、挤小字号或截掉句意来塞进一屏。关闭语音、略过交流或中途离开，不延误世界行为。

审阅同时比较紧急短句与有表达空间的完整交流：关键意思是否及时抵达、后半句是否有情绪或解释价值、是否抢玩家沟通、重复后是否烦人。缩短只能解决实际冗余，不能为了达标删掉人物态度。口吻、实际时长及占声密度仍待审阅和试听。

NDL-BARK-SCHEDULING · 受托DECIDED；时间与数量为TEST，未经播放验证。来源：SRC-USER-PLANNING-REVIEW-AFTER-OBSIDIAN。

本文唯一拥有情境对白优先级、冷却与过期规则，适用于长短台词；人物口吻归CHAR-009，具体句子归唯一试稿。拒绝固定轮流说话和“先排队、以后全播完”：前者强迫不知情的人开口，后者会让队友脱险后才听到呼救。安静是有效结果，不是待补的内容缺口。

### 事件与说话人

权威提交事件标识、因果事务标识、已部署说话人、对象、可知事实和有效条件；不录制或识别真人语音来推测意图。候选先按实际行动与知情筛选，再在同优先级适用者中优先选近期少说话者；不以四人各占四分之一为目标。缺获批角色变体时不借用别人的声音，关键事实照常由HUD提供。

每个客户端按自己的语言、字幕与声音偏好播放同一语义候选，时长可不同。人物短句同一客户端最多同时一条，另保留至多一个仍有效的待播候选；更高优先级替换较低者，同级优先迫近危险，其他候选直接丢弃。独立CriticalCue、玩家语音和HUD不等于第二条人物闲谈通道，不受人物冷却封锁。

| 等级 | 适用内容 | 首轮调度与失效边界 |
|---|---|---|
| 紧急战术 | 已知危险、倒地求援、真实警报预告 | 抢占反应/闲聊；同一事件不重复播。不同紧急事实可以出现，但过期候选丢弃，HUD仍即时更新；预告已开始则不补说“要响了” |
| 现场操作 | 当前救援、有效操作进度、当前资源交接 | 不抢紧急句；最多等待2秒，操作已取消、结束或对象已变则丢弃 |
| 受益与脱险反应 | 有效感谢、松口气、对设备的反应 | 不抢前两类；最多等待3秒，进入新危机或对象不再清楚就丢弃。客户端两次此类播放开始至少间隔15秒 |
| 安全闲聊交换 | 无迫近威胁、无紧急操作的共同反应 | 起句前连续安全20秒；每客户端两次闲聊开始至少间隔240秒，不按角色各算一份。功能性呼叫与动作确认不属于此类。任一续句失效即结束整段，不重启、不补播 |

自动反应和闲聊在同一客户端最近八次同类**合法语义事件**内不重复同一具体句。窗口按事件前进，不按成功播放次数前进，也不能靠提交被拒绝的动作刷新；候选少时宁可不播，不为满足窗口强制写八句同义词。玩家主动Ping、Quick Chat和当前紧急战术事实不受八事件措辞禁言：它们需要可预测地表达真实意图与新危险，防刷依靠同对象/同语义去重和短限频，不依靠随机吞掉请求。主机迁移与重连继承事件去重游标和未到期冷却，只接收当前事实，不重播已消费事件；新一局保留当前客户端近期措辞记忆，不要求永久保存战报。

### 感谢、续句与玩家沟通

同一帮助事务只产生一个感谢机会；同一补给舱的多人领取视为同一帮助来源机会，最多一名受益者回应。施援者给自己补充、来源不明或收益为零不触发。感谢必须是实际受益者说的，施援者不自动接“不客气”；高优先级挤掉感谢不影响资源或奖励。持续掩护按一次压力解除窗口合并，不逐发计机会。

短交换的续句仅在本客户端已实际呈现前句（声音或开启的字幕）、有关角色仍在场且事实依然成立时产生。跳过、被抢占或断线导致前句未呈现就丢弃依赖它的续句；仅关闭声音但保留字幕不等于关闭字幕对话。两种呈现都关闭时不产生无意义续句。不同语言客户端可以各自跳过，不同步等待音频结束。不能因续句说“我看着”让真人自动转身、守门或被锁在原地。

能观测到游戏内语音发送/接收活跃时，不启动人物反应和闲聊；结束后再等待2秒并复核语境。不得读取外部通话或保存原始语音；Discord等外部沟通不可可靠感知，因此设置提供“标准／仅战术／关闭人物语音”，不以假装检测外部聊天解决抢话。关闭人物语音与关闭字幕分别生效，危险提示和任务事实保留其独立通道。

### 主动沟通、动作回应与压力表演

NDL-CONTEXTUAL-CALLOUTS · 受托DECIDED；触发阈值与新台词仍为TEST/PROPOSED。来源：SRC-USER-CHATTERREBORN-TRIGGER-RESEARCH。参考作者记录的触发类别，不声称重建GTFO本体或模组源码。

三种入口必须分开：玩家主动Ping/Quick Chat表达意图；动作实际开始或结果提交带来自动确认；现场变化产生人物反应。它们可以形成短交流，但只有纯闲聊才受安全20秒/240秒规则约束。一次有因果关系的准备呼叫、紧急请求与对应动作确认不用等到安全阶段。也不增加第二套通讯菜单，复用现有[合作沟通](../玩法/合作单人机器人与公共匹配.md)与[玩家输入](../玩法/玩家配装与输入.md)。

现场HUD按[UX-FIELD-FEEDBACK](../表现与资产/界面信息与可访问性.md)合并同一事务的阶段，人物候选仍使用本文独立播放规则；HUD三秒短通知或Ping寿命不是台词长度上限。“收到”只表示已读，“我来”只是主动意图，真实动作开始/提交才可说正在做/完成；操作成功、资源感谢和设备声音不能各自生成第二次成功事件。菜单预览悬停不触发全队台词，未提交取消与结果未知也不能生成成功感谢。没有新增人物对白稿或播报通道。

| 入口 | 必须依据什么 | 不能做什么 |
|---|---|---|
| 主动标记目标、资源、通路 | 玩家按下既有Ping、目标合法可知 | 准星扫过队友就自动训话；标记隔墙未知敌人；Ping同时免费扫描 |
| 主动请求等待、集合、物资、准备 | 既有Quick Chat的明确语义与目标 | 看见别人站着就猜他在等；未选定目标便承诺某只由自己处理 |
| 对请求回应 | 真人主动确认，或真实相关动作已开始；Bot确认命令已被合法接受 | 系统替真人答应掩护、用药、开门；Bot没资源仍答应部署 |
| 资源与弹药状态变化 | 指定容器/当前武器的量跨过有意义的边界 | 每用一发播一次；把当前枪没后备说成两枪都空；把捡到包说成已经补充 |
| 战斗与探测变化 | 新的可知目标、逼近、自身受压、弱点实效或威胁解除 | 用隐藏总敌人数调语气，借台词泄露未知敌人或秘密房 |

主动同对象同语义语音首轮最短间隔为3秒TEST，文字/标记仍按原沟通合同反馈。多人同报一个已知对象聚合为一句；目标状态发生实质变化时是新事件，不因刚报过位置吞掉“正在苏醒”。新的更高优先级危险不受低优先级限频阻挡；功能性应答按正在回应的请求ID去重，不加入长期闲聊队列。未通过本地化/内容批准的句子不因请求存在而伪造录音。

每个适用语义可有低声、正常、受压三种表演候选，分开记录素材与实测时长；不是把同一录音提高音量或拉高音调。压力来自说话人已知的近身威胁、受击和正在应对的攻击；不能从全图隐藏敌人数读取紧张程度。切换采用起止迟滞TEST，单句开始后不在词中切素材。自主沟通在激战中不因“太紧张”整类禁用，但仍受关键危险、玩家静音偏好和抢话管理约束。

档案音频正在播放时抑制探索闲聊；眼前出现危险仍可打断档案。角色有情绪不等于每次击杀都欢呼；一次同步近战结果、一次低弹药补救或一次重型威胁解除，比逐发伤害确认更值得反应。实际误伤可有简短提醒或主动道歉，禁止辱骂、逼队友回应和争吵升级；沿用已批准CHAR-006。

不采用模组中催玩家进扫描圈的怒吼方向，也不移植其特定Rundown独白、Shadow专属规则、原作语音或原生DLL。BREACH若没有对应机制，就不为了增加一句台词新增机制。现阶段只规划触发与原创稿，未运行模组或游戏。

### 纸面与后续实测验收

| 输入情境 | 必须得到的结果 |
|---|---|
| 四人同时受益，一舱恢复多种资源 | 最多一句感谢，不逐人逐资源列队 |
| 同一自动反应是唯一候选，连续发生十次合法事件 | 中间可安静；事件窗口移出后才再次成为候选，不永久禁言，也不造同义句绕过 |
| 玩家在不同危险出现时主动请求，只有一种获批措辞 | 不因八事件窗口禁言；同对象刷屏仍被短限频 |
| 高压战斗中收到请求，真人尚未响应 | 不自动替其答应；开始真实掩护/施救后才可确认 |
| 同一目标新出现苏醒动作，或队员只剩当前枪最后弹匣 | 按新的合法状态报点；不泄露全图状态，也不声称所有武器都空 |
| 续句前救援中断、目标死亡、发生新警报 | 不播放失效成功句或笑话；世界结果不等待语音 |
| 英文前句仍在播，中文前句已结束 | 两客户端各自调度，不加速慢的一方，不强制同秒续句 |
| 较长设施交流开始后出现迫近危险 | 危险抢占，不等其讲完；不补播失去语境的后半段 |
| 一条完整交流超过单屏字幕容量 | 按各语言自然停顿分段，不删意、不缩字、不改变玩法时间 |
| 主机迁移、迟加入或重连 | 不重播已发生的感谢、历史呼救和半截闲聊；当前危险由现态提示 |
| 玩家正在游戏内通话，或选择仅战术 | 不启动低优先级反应；关键任务仍可完成 |

上述是规划输入与期望，尚无运行记录。之后记录各客户端每类合法事件数、实际播放数、被抑制原因、占声时间与被打断次数，不采集真人语音。分别做无通话、游戏内通话和外部通话三组中英情境试听；候选冷却和时间窗可根据重复烦躁、信息延误及人物存在感调整。当前不录音、不调用TTS、不制作调度代码，不把TEST参数表称作播放频率已经验证。
