BLACKSTART-CONTRACT-002 · DECIDED。

完整Beat Graph固定为：

`插入并读取公开风险 → 查询或现场定位同步耦合器 → 选择安保短路/维护长路 → 取得并向前安装耦合器 → 配置三枚可选电力单元 → 侦察两个共振连接Zone并封口/清场/布置资产 → 预览并提交主节点启动 → 沿B05/B06/B07处理三种不同故障 → 确认稳定输出与诊断上传 → 开启B08前方撤离`。

三种故障分别使用搬运安装、空间分工操作和破障/旁路，不允许生成器把它们全部替换成同一终端保持。`CouplerAcquired`、每项Cart选择、主节点启动、每个Fault完成、诊断上传和撤离各有独立幂等提交；客户端重放只返回原结果。

主节点启动后，故障链不能回退到未启动，也不允许重新配电抹掉已发生的激活。可选设施故障只让对应收益失效并开放已预告的较险路线；同步耦合器在安装前越界时回收到最近已知合法点，安装后成为设施状态而非可再次拾取物。全队Wipe是不可恢复失败；三项Fault中的单项设备损坏均有前向维护旁路或较低价值的降级完成，不能留下无目标状态。

## 权限、设施耦合与可观察后果

BLACKSTART-CONTRACT-003 · DECIDED。

起始旧制身份只允许公共Terminal查询、普通门和紧急维护设备。进入B02S需要下列两条真实路径之一：在B02M取得仍可验证的本地值班凭证，保持安静但增加路程；或在B01强制覆盖安保门，立即触发只覆盖B01、B02S与安控链的`SecurityIncident`。该事故启动旧防御、改变声明门态并以真实警报声刺激相邻传播群；进入B03后可在安控台切断广播并重映射防御，但已激活敌人和已提交攻击不回滚。当前Seed若没有B02S短路，不得显示该覆盖选项。

每个实例固定四套核心系统：配电、门/隔离、通信/扫描、运输；再从通风和安保中选择一至两套。至少存在两项耦合：

1. 三枚额外电力单元在通风、侧闸、防御、交通和研究库间竞争；没有“全开”配置。
2. 交通供电开放B06至B07短路线，同时打开一个可见侧向接缝；侧闸可以封其中一条压力线，但不能封掉全部必然来源。
3. 安控接管需要通信链和电力；成功后保留炮塔当前弹药、损伤和射界，不免费修满。
4. 研究库耗两枚电力单元并开放额外价值与前方侧入口；不开库不影响主线可解。

未选择的系统在现场保持可理解的断电、关闭或手动旁路状态。所有收益必须在3D世界中表现为雾层变化、门体移动、炮塔阵营/射界、交通平台位置、地图快照或实际可走路线，不能只改变HUD百分比。

## 刺激、敌人和有限来源

BLACKSTART-CONTRACT-004 · TEST。

过热保护暂停对应设备步骤，已提交Fault、预清结果和有限来源账不回滚；已经激活的来源不会因为小队停机就失效，也不能随重启补满。修复条件不满足时，指向前方机械旁路/最低回路，而不是让玩家反复复位。选配设施被毁失去其收益，最低路线仍在；当前工业配置不以“缺一枚额外冷却罐”产生主线失败。

接地变体的裸母线采用[工业危险合同](../设施与资源/工业危险与故障处置合同.md)的INDUSTRIAL-ARC候选，不冒用喷流数值。位置在导流维修段的一条可绕支路，安全侧开关断开该支路可选扫描/有限充能，最低换流回路与应急接收供电独立。前向维修架提供对应绝缘模块，愿意恢复可选能力才需安装；不是第四个必做Fault，也不占三枚可选Cell之外的新关键电池。此配置必须保留旁路及单人顺序解，未修也能推进主任务。只有实体周期、隔离/安装恢复和声学验收通过后才进入生成池；首个相位丢失配置不增加电弧需求。

该电弧候选初态为支路已隔离、绝缘未修、三次重试资格未用；玩家选择恢复可选供电才开始故障预告。它不因走进房间临时生成脉冲，也不在玩家抵达前自动打完三次使风险消失。先修后通电是合法安全解，直接隔离通过也是合法解；本段只约束该候选，不改其他设施的初始状态。
