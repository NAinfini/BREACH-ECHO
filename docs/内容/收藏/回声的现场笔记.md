# 回声的现场笔记

集合`collection.echo.diagnosis`，三篇。新增事件候选：一次当代设施诊断中，回声把本地自检回执误当成远端回应，现场复核后收回判断，交付已验证的有限恢复。不是全网重启原始记录，不发明重大事故；好奇心体现在还想查下去，而非三篇都发表技术格言。来源是整理后的工作交接附件，按[交付卡](首批收藏目录与交付卡.md)投放。

## 终端还在回应

条目ID：`lore.echo.first_response`。作者：回声现场工作笔记；类别：当事人陈述。时间：初次测试，判断尚未证实。

标题中英：终端还在回应／The Terminal Is Responding。

> 中文正文：报修写的是“终端无响应”。屏幕确实没显示，但接口还能收到重复信号。接上测试设备后，出来一条完整回执。看起来远端没死，只是我们一直没读对。
>
> 中文正文：先别写恢复完成。我还没去另一头看过。保留这次发送的内容和原始回执，回来做一次对照。

> 英文正文：The fault report says the terminal is unresponsive. Nothing on the screen, but the interface is still picking up a repeating signal. The test unit got a complete reply. Looks like the far end is alive and we've been reading it wrong.
>
> 英文正文：Don't close the job yet. I haven't checked the other end. Keep the message we sent and the raw reply so I can compare them when I get back.

## 不是另一头

条目ID：`lore.echo.local_selftest`。作者：回声对原测试的更正；类别：当事人陈述。时间：走到对应接收端检查后。标题和正文自带对象，先读本篇也能懂。

标题中英：不是另一头／Not the Far End。

> 中文正文：更正终端测试结果：刚才那条不是远端回复，是本机自检。换了发送内容，回来的东西一字不变。另一头的接收记录也是空的。
>
> 中文正文：显示程序把自检通过和通信成功放在同一栏里，我看快了。原始信号没白留。不然只凭那个“成功”，这台机器明天就该交回去了。

> 英文正文：Correction to the terminal test: that reply came from its own self-test, not the far end. Change the outgoing message and the reply stays exactly the same. Nothing in the receiver's log at the other end, either.
>
> 英文正文：The display puts a passed self-test and a successful connection in the same field. I read it too quickly. Good thing we kept the raw signal. That single “success” would have had this machine handed back tomorrow.

## 留给下一班

条目ID：`lore.echo.limited_handover`。作者：回声交接单附言；类别：当事人陈述。时间：两端本地配置修正、双向测试后。修的是人类通信层，未取得设施高级控制权。

标题中英：留给下一班／For the Next Shift。

> 中文正文：两端的通信配置已改好，往返消息都核对过内容。现在能传消息；设备控制没验收，别把两件事一起签掉。
>
> 中文正文：那段重复信号还在。关掉我们的发送端也没停，今天没查出来源。我申请下次带采样设备来，先接着收，不动已经修好的线路。测试记录在附件里，不用从头猜。

> 英文正文：The communication settings have been corrected at both ends. We've checked the contents of messages going each way. Messaging works now. Equipment control hasn't been accepted, so don't sign off on both together.
>
> 英文正文：That repeating signal is still there, even with our transmitter off. I didn't find its source today. I'd like to bring sampling equipment next time and keep listening without touching the connection we've repaired. The test records are attached. No need to start guessing from scratch.
