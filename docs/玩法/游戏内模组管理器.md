# 游戏内Mod Manager：页面、状态与玩家流程

MODUI-001 · DECIDED。使用游戏内一个统一入口，不要求玩家安装外部管理器。鼠标键盘和控制器均能完成安装、组包、加入同步、失败恢复及诊断；后台下载不夺走游戏内危险场景的焦点。

## 页面责任


### 入口

主菜单和Hub提供`模组`入口。它不是一块挤满Workshop卡片的商城，而是本机运行状态控制面。

### 总览

- 当前Profile名称、`Official / Modded`标记、顶层包数、完整依赖数与总磁盘占用。
- `继续使用`、`新建Profile`、`复制Profile`、`恢复纯净版`、`浏览Steam Workshop`。
- Active/Suspended Run使用的锁显示为只读；编辑会创建新Profile revision，不改变旧Run。

### 已安装

- 按启用、未启用、更新待应用、孤儿/不可下载、冲突、故障筛选。
- 每项显示作者、来源、版本、hash短码、内容类型、依赖、能力、存储占用和被哪些Run/Profile pin。
- “更新可用”与“此Run仍固定旧版”同时显示，避免把更新误解成已经生效。

### 配置档编辑

- 玩家只选择顶层意图；传递依赖自动展开。
- 编译结果显示新增/移除、冲突、Compatibility Patch建议、权限变化和Package Lock摘要。
- Apply只在Hub/主菜单完成；若包更新要求重启Runtime则明确提示并安全重启，不在Operation中途套用。

### 加入Modded Host

1. 展示Host Profile名称、Official/Community分类，以及双方必需模组的缺失数量、实际下载量和安全等级；分别标明主机专用、双方必需和保留的个人客户端模组，不能把主机全部安装项显示为必装。
2. 仅为双方必需的Data/Graph/获支持Luau/资产包及共享依赖自动从Steam Workshop下载，无逐包许可弹窗；主机专用和主机个人客户端包不加入下载队列。精确缓存命中时无需重新下载。
3. 显示下载、校验、编译、staging四段进度；Steam下载完成不等于Runtime验证成功。
4. 失败必须给出唯一主因和可执行下一步，例如`Workshop条目已删除`、`只找到不同hash`、`依赖冲突`、`磁盘缓存不足`、`Host只允许现有缓存成员`。
5. 成功后创建“房间共享包 + 自己的兼容客户端包”的临时Join Profile revision；离开Lobby恢复原组合。个人客户端包冲突时明确列出影响，只能由玩家选择本次停用或取消加入，不能偷偷禁用全部个人模组。

### 诊断

普通玩家看到一行原因和建议；作者模式可展开依赖图、Patch冲突、Validator路径、源码行、能力调用、CPU/内存、日志限流和导出报告。所有状态必须有文字/图标，不只靠红绿颜色；键鼠与控制器焦点顺序一致。


## 关键流程

MODUI-002 · DECIDED。

从主菜单进入Mods，选profile并验证；只有没有活跃Run时可改变Gameplay包。进入朋友房时按[三类模组同步合同](../技术/模组安全包固定与自动同步.md)比较共享锁：共享包全匹配且个人客户端包合法则直接准备；仅共享缺包进入汇总同步页；存在不支持脚本或冲突则阻止加入并解释。主机专用包缺失与个人客户端版本不同本身不阻止加入。下载成功仍需校验和激活，界面不能在100%网络下载时就显示Ready。

取消同步保持原profile和订阅偏好；部分下载可保留为不可激活staging以便重试。依赖的自动选择在确认页可见，删除被其他包依赖的项目要列出影响。加载顺序由依赖图和稳定排序得出，不用任意拖动来“解决”定义冲突。多人房只修改本次session profile，不永久覆盖个人默认组合。

## 错误与无障碍

MODUI-003 · DECIDED。

至少区分：Steam 离线、下载失败、磁盘不足、hash 不符、依赖缺失、循环/定义冲突、SDK 不兼容、旧 hash 不可获取、Luau 编译/能力/预算验证失败、禁止的 DLL/可执行组件、正在使用不能删除、权限受限。每种错误有中文/英文短解释、具体包/版本、可执行修复按钮及返回路径；禁止只显示堆栈或“Unknown error”。

状态不只靠红绿区分；进度具备文本与可读焦点标签；详情长文可滚动而不丢失返回焦点；高风险确认默认不在“删除”上。重启后恢复下载队列和profile，不自动恢复未获同意的能力升级。关闭声音也能知道成功/失败。

## 验收

MODUI-004 · TEST。8 名新玩家中至少 7 人无口头指导完成：加入两个缺失安全包的房间、识别一个含禁止 DLL 的包和一个 Luau 能力校验失败的包、取消后保留原 Profile、找到旧 hash 缺失原因、在控制器上导出诊断；无误删除、半激活、偷偷执行代码或隐藏下载。超过 15 秒仍无法理解的错误由 UX 重写，不让玩家先学习底层包管理概念。
