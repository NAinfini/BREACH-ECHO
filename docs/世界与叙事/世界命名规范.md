# 世界命名规范

## 范围与命名层

NAM-001 · CANON · 来源：SRC-USER-2026-09-04-WORLD-NAMING-SYSTEM；SRC-USER-2026-09-04-WORLD-NAMING-CHINESE-SELECTION。

创作层主名称使用中文，并区分人类常用名、机构分类和原生自称；没有原生证据时保持UNKNOWN，不用人类外名冒充。低智能虚空兽没有语言性自称，记为无/不适用；其已确认生态规则继承[世界观NAR-027](世界观与正史圣经.md)，其余生物学细节仍为OPEN。

本文件是创作层名称唯一责任。NAM-002与NAM-003是已选定的创作主名称；名称选择为CANON不代表对应历史、物种机制或DLC已经获批。全部名称均`LEGAL NOT CLEARED`。

“网道趋能生物群”中的“网道”只是对通路型基础设施的分类描述，不是第二套空间网络；世界中的该网络只有界桥网络这一正式名称。

## 游戏工作标题

NAM-008 · DIRECTION（WORKING TITLE） · 来源：SRC-USER-2026-09-05-GAME-WORKING-TITLE。

当前游戏工作标题为中文**《裂界残响》**、英文**BREACH: ECHO**。这是现阶段用于项目讨论、原型和内部材料的双语标题，不代表最终发行标题已经冻结。标题中的“裂界”与“残响”不自动改名任何世界内事件、设施、能力或物种；它们的正式名称仍由本文件其他条目分别负责。

该标题尚未完成Steam及其他主要商店重名检查、搜索碰撞、主要发行地区商标清查、域名和社交账号可用性检查，因此状态为`LEGAL NOT CLEARED`。在完成清查并获得最终确认前，不提交不可逆品牌资产或对外宣称商标安全。

以上是同一人物在两种语言下的正式创作代号，采用自由本地化而非逐字翻译。Bolt不改成Broken Arrow；Monarch对应中文“蝶”，不改译为“君主”，不保留Moth为第二套现行代号。角色身份沿稳定席位/身份标识关联，不用显示名称当存档或网络身份。

这次批准仅覆盖名称和语言对应，不批准代号来源故事、具体经历、六组关系、收藏事实、外貌、声音或游戏开工。代号不限定职业、武器、性别、动物特征或服装图案；不为解释字面意义新增事故。其余人物细节仍由角色责任文档与OWNER-01维护。旧候选不作运行时兼容别名；只有所有者再次改变创作决定才重开命名。未进行录音、界面可读性或法律清查，不将创作确认写成这些检查已经通过。
