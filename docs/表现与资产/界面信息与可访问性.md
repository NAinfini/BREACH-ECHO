# HUD、控制器、信息与可访问性

## 玩家目的与范围

战斗时知道现在应做什么，调查时能理解已知信息，构筑复盘时能解释因果。HUD不把完整Proc图持续摊在玩家脸上。

UX-001 · CANON · 来源：SRC-SSOT-2.0 §18.1–§18.7。

FPS默认可切TPS，两者同canonical aim/muzzle/hit/movement/interaction，TPS不能额外探知隐藏对象。全核心UI可controller-only，轮盘0..N而非固定八格。普通敌人血条contextual，设置Off/Contextual/Always nearby known；Boss用动态部位/vitals。伤害数字默认Aggregated，按Target/AttackRoot/source/time/category聚合保留Crit/Weakpoint/Reaction/Shield/Armor/Health flags，支持Off/Major/Aggregated/Detailed/Per-hit。队友轮廓可见弱、遮挡/倒地/抓取/关键携物/离散增强，设置Off/Marker/Contextual/Always。左右手viewmodel不改canonical muzzle/hit。

UX-002 · CANON · 来源：SRC-SSOT-2.0 §34.1–§34.2；来源属性：INHERITED。

轻量局部导航+compass，Full Map只显示发现图、connector、队友/Ping/known objective，支持vertical/Fold；无全知敌人雷达、无未发现秘密图。知识获取归[世界](../玩法/设施信息与控制规则.md)。

UX-003 · DECIDED · 来源：SRC-SSOT-2.0 §18.3、§18.8、§31.3。

按武器/输入自适应中等Aim Assist，Sniper低、近距Shotgun与Melee独立，Gyro减弱rotation，不改hitbox/弹道、不发现隐藏目标。字幕/SDH、关键提示双通道、低动态音频、低镜头晃动、非纯色信息、可简化Support输入但成本/结果相同。Streamer HUD展示少量Build核心、隐藏私人信息、无额外知识。

## 流程、状态与所有权

UX-004 · DECIDED · 来源：本轮扩写。

战斗层：目标+生命/弹药/工具+关键威胁；调查层：地图/Terminal/Cart事实；配装层：单件行为/成本/合法性冲突，不显示整套配装短板警告、互补评分或推荐；复盘层：因果/发现。打开菜单不暂停多人模拟，重要危机仍有双通道提示。

| 状态 | 事件 | UI结果 |
|---|---|---|
| Combat | 普通信息更新 | 聚合低优先项，不抢视线 |
| Interaction | 关键威胁到达 | 保留明确退出/危机提示 |
| BuildPreview | 目标实例变化 | 标记过期，刷新消耗/冲突 |
| Remapping | 绑定冲突 | 告知受影响动作并给可恢复选择 |
| Reconnect | 状态快照 | 显示当前世界，清掉过期事务按钮 |

Authority给已知事实和可执行动作；Client拥有布局、文字大小、输入、声音/镜头偏好。呈现偏好不能授予额外状态知识。

## 模式、内容、边界

UX-005 · DECIDED · 来源：本轮扩写。

Operation重点显示团队资源、携带资产与任务后果，Lab才突出构筑链。自由 TPS 是明确要求；只有实测证据要求缩减时才进入[所有者变更控制](../治理/项目所有者裁决清单.md)。内容接口包含semantic priority、文字、图标、方向合法性、输入hint、无色编码、可访问替代。

键盘鼠标/控制器切换不清空选择；长按可替代为切换方式；轮盘候选为空时明确无可用操作。弹窗不遮死亡/断线原因。文字放大后不丢关键确认按钮。公屏不暴露账号秘密、语音原文或隐含敌人数据。

## 参数、示例与验证

UX-006 · TEST · 来源：Xbox XAG/Steam Deck方法，详见[研究](../参考/研究资料技能与文档格式.md)。

从首个greybox就测controller-only、静音、灰度、低晃动、文字放大、Steam Deck分辨率。XAG是设计准则不是“通过合规认证”。字号/对比度/提示时长以具体硬件阅读测试决定；首批无口头帮助完成核心动作目标见玩家文档。

正常：不知道Coupler位置时只有目标说明，Terminal查询后出现waypoint。失败：TPS看见墙后像素不自动标秘密。跨系统：自动Fusion在未来Lab先给消耗预览；Operation改装以可见挂点和tradeoff表达，不弹未知吞噬惊喜。

UX-007 · TEST · 来源：SRC-USER-2026-09-04-RESPONSIVE-GUNPLAY-CANCEL-WINDOWS；SRC-USER-2026-09-04-PLAYER-MASTERY-PROGRESSION。

换弹、可射击、可ADS、动画结束与蓄力缓冲必须有一致的视听/触觉反馈；新手应看懂失败是资源不足、阶段未到、动作中断还是输入无效。测试不同帧率、网络和输入设备是否给出等价窗口，记录宏依赖、网络不同步、视觉假上弹及不可解释拒绝。高级技巧可提升效率，不得隐藏基础操作或授予额外世界知识。

## 壁垒任务板

UX-008 · DECIDED · 来源：SRC-USER-2026-09-05-PROCEDURAL-OPERATION-HUB-BOARD；SRC-USER-2026-09-05-COLLECTIBLE-ACHIEVEMENT-LORE；数据责任见[Operation OPS-011](../玩法/系统化战术行动模式.md)。

中央Hub任务板与快捷菜单读取同一轮八份全服共享普通Offer，并在活动存在时另列特殊行动。所有公开规则在匹配/配装前可读，但不把全文塞成八张密集说明书：卡片负责选任务，详情负责理解条件，Ready负责确认当前版本。预约、到期与Run锁定唯一按[UIFLOW-004/005及信息交接](../玩法/前端房间与会话流程.md)执行；配装期间只显示“已选定，尚未出发”，锁定成功才显示“本局规则已锁定”。没有预约过期豁免。

| 层级 | 默认显示 | 展开内容与边界 |
|---|---|---|
| 任务板卡片 | 主任务/设施主题、当前五档之一的难度、预计长度、交战合同、全部修改器名称、禁用槽与关键限制、主/支收益类别、新开截止 | 支线名称和用途可在卡内展开；规则数量不能折成不透明的“另有变化”。高密度时纵向展开/滚动，不缩小到无法读 |
| 任务详情 | 主/支线完成标准、可选性、必然/条件激活、失败和撤离规则、所有环境与活动效果、确切装备限制、奖励资格、Mod政策与包/版本/下载状态 | 给每条效果的作用对象、变化量、持续/触发条件、上限/例外与反制类型；不提供实例地图或最优路线 |
| 配装侧栏 | 同一任务与规则摘要、两槽平等目录、每件装备的实际属性/成本/活动影响、队友已提交配装 | 用事实说明“此武器不受贯穿强化影响”“此装置不在免耗材名单”；不是“你应该换枪”或“队伍缺反重” |
| Ready摘要 | 当前任务/难度、全部条件和禁槽、奖励资格、成员/配装/包锁及变更项、各人未准备原因 | 可原位展开全文；没有强制阅读时长、滚到底解锁、额外知识测验或自动Ready |
| 加载与入场 | 已锁任务身份与规则、加载状态；入场后主目标及已有合法定位 | 全文仍可复查，不默认展开挡战斗；不预览逐房平面图、敌人布置、秘密房或答案 |

任务板支持键鼠和控制器筛选区域、任务类型、预计长度和难度；无结果保留清除筛选。公开匹配允许精确选择或显式多选Quick Join；实际命中项在确认前完整呈现，不默认勾选更多任务/难度。预计长度是配置估计，不是任务倒计时；截止时间明确写“新行动截止”，不暗示倒数结束会杀死在局小队。活动与普通合同用文字和形状区分；当前只显示已发布且验证可用的内容，不把80项作者候选、三张纸面测试图或未来Descent当已开放关卡。

调整难度先展示新旧**公开规则**的差异：允许兵种与组成趋势、资源配置、救援/撤离或奖励中实际变化的项；未变化项不编造变化。固定有限敌群与有限增援的承诺仍可查，不公开本Seed各房数量。普通合同不宣称永久收复版图。必要装备、关键故事与唯一字形不因错过轮换永久丢失，未来联合行动另按已批准活动范围呈现。

Archive界面按事件、人物、设施、Faction与可信度筛选收藏，并明确区分记录事实、当事人陈述与环境推断。集合页显示已发现条目和缺失数量，可给出主题级线索但不直接标出秘密房间或字形答案。任务内发现必须同时提供字幕、可重读文本与非颜色唯一提示；合作拾取后全队符合资格者都得到清晰但不遮挡战斗的收录反馈。

## 公开规则与现场情报的边界

UX-BRIEFING-BOUNDARY · 2026-09-07受托DECIDED，来源SRC-USER-MISSION-BRIEFING-BOUNDARY。提前知规则不等于提前看解答；现场知识仍归[设施WRD-001/004/015/017](../玩法/设施信息与控制规则.md)。

| 信息 | 出发前 | 现场取得后 |
|---|---|---|
| 主/支目标及收益条件 | 完整公开本合同目标、必需数量/判定、支线是否帮助主线或给额外回报；不能把已抽定支线藏到进图才通知 | 显示完成事实和可执行下一步；不替玩家得出案件真相 |
| 交战规则 | 公开全程潜行可行/条件升级/必然激活；醒敌持续追杀、普通有限敌群、声明事件才有有限增援 | 控制台在承诺动作前显示本次作用域、已知响应与不可逆后果；未知项明确标未知，不能借此临时加惩罚 |
| 修改器与难度 | 公开全部变化及组合结果，包括周期、倍率、名单、数量上限与不受影响项；名字不能代替规则 | 设备/区域提供当前阶段、范围边界、剩余资格与合法操作，HUD不远程播未到区域的精确相位 |
| 地图与路线 | 设施主题、任务意图和已授权入口信息；不公开实例拓扑、逐门权限或最短路线 | 观察与合法终端授予地图/门/目标信息；高权限可给内容声明的设施地图，不把“保密”当理由删掉合法奖励 |
| 敌人 | 允许出现的类别、公开组成变化和行为说明，不把实际抽样结果包装成“已知兵力” | 目视、查询或探测按各自合同授予；终端可给带来源/时间戳的Zone数量/大型信号快照，不自动持续追踪 |
| 资源与设施 | 公开补给/能源/权限政策、可选收益类型和限制，不列本Seed每箱库存、电池/端口位置或接管最优顺序 | 发现/合法物流查询后显示实际位置与余量；损坏、断电和权限不足分别说明，不能把一次授权显示成全修复 |
| 字形与收藏 | 可公开主题级线索和通用使用规则，不确认本Seed秘密房、隐藏地址组合或稀有掉落 | 现有Archive及当局合法发现可用于解谜；不抹除老玩家知识，也不免费补出本地校验答案 |
| 制作数据 | 不显示B/F/L语义区号、生成预算、空间验收见证、调试Seed和敌人来源精确坐标 | 仍不进入正常玩家详情；需要的玩家地名与作者测试编号分开 |

“未知”不是“没有”。没有查到某房间生命信号，不显示“已清空”；一份旧扫描显示“扫描时记录：{count}；{age}前”，不改写为现在仍有这些敌人。已查询目标只有Zone时，只标该Zone，不能补一个精确物件waypoint；对象移动但无新证据时保留最后确认位置。手持与区域探测器的有效点标例外依UX-SENSOR-DOTS实时跟随并淡出，不降级成静态点。

### 首轮九项修改器需要解释的内容

UX-MODIFIER-DISCLOSURE · 这不是新参数表。具体名单/数值由[环境目录](../内容/设施与资源/关卡环境修正器候选与验证.md)、[活动目录](../内容/活动/特殊活动修改器候选库.md)、[强化目录](../内容/活动/玩家与敌人强化修改器候选.md)和[任务绑定](../内容/任务/修改器任务映射与组合准入.md)提供；界面读取本次编译值，不另存九套倍率。

| 修改器ID | 详情必须讲清 | 不应让玩家误会 |
|---|---|---|
| MOD-EM-STORM | 局部周期干扰；实际易受影响的电子辅助/暴露防御、屏蔽条件、预告及停机周期；必要操作和核心枪械不受此停机影响 | 不是所有能量/电磁枪失效，不提前标炮塔所在房间，恢复不免费修复 |
| MOD-INDUSTRIAL-NOISE | 局部设备轰鸣时哪些移动/交互声可被掩蔽、倍率及声路条件；可停机和绕行 | 不隐藏枪声、爆炸、近战命中、近邻反应或警报；另一房间的噪声不全图生效 |
| MOD-CONDUCTIVE-FLOOD | 通电积水的预兆、伤害脉冲、有限放电资格及干侧断电/绕行方式 | 不是必吃伤害的主线地板，不提前给开关和干路坐标 |
| MOD-LOW-GRAVITY | 局部重力变化、滞空/落点影响、地面路线仍可用；约束货轨与既有枪械规则的保护边界 | 不是全图飞行或免权限跳关，不表示货物会自动飞向目标 |
| MOD-PRIMARY-OVERDRIVE | Primary伤害倍率、Secondary禁用、其他来源不增伤、空槽补给权益不转移 | 不将Primary改成等级更高的槽，不销毁普通预设中的Secondary |
| MOD-UNLIMITED-TOOLS | 当前免除成本的C4/泡沫/区域监测器名单、个人/团队部署上限；生命、动作和外部材料仍正常 | 不是所有Tool/Utility无限、盾不无敌、不免费维修、满名额不暗删旧设备 |
| MOD-INFINITE-ENERGY-PORTS | 一处可选固定端口来源不耗尽、Energy接收限制、单次补量/时间、枪容量与供电要求 | 不是全图自动回弹、所有设备都能充、所有枪可用或能够兑换Credits；不要求带Energy才准入 |
| MOD-FAST-HANDLING | 当前九枪受影响的换弹/切枪阶段及倍率；射速、蓄力、终端、救援和投送不变 | 不是整局时间加速，也不把工具布置动作一起加速 |
| MOD-BODY-PIERCING | 当前适用线圈枪、贯穿数与逐目标衰减；厚甲/墙体终止规则 | 不是全武器穿墙或无衰减穿透；带其他合法枪仍可出发 |

若采用“干扰下的工具”组合，摘要同时注明免耗材的监测器仍会停机；若采用“单枪贯列”，说明额外贯穿只适用于对应线圈枪，其他Primary只获得自己的伤害效果。组合不是独立规则来源，最终值与例外必须来自同一编译结果。内容缺少某条效果的公开说明时拒绝该内容发布，不用“未知异常”遮住装备限制。

| 任务 | 中文任务说明 | English | 留在现场的信息 |
|---|---|---|---|
| 换流器黑启动 | 恢复换流器，完成启动并交付诊断。启动会唤醒目标区域及共振连通区的休眠敌人，并开启有限增援；先完成你们需要的准备，再提交启动。 | Restore the converter, complete the startup and deliver the diagnostics. ### 文本、焦点与信息理解验收

危机优先于普通结果、请求和探索通知，但不接管玩家操作。危险到来时可压缩终端面板/非关键说明，让出口键与危险保持可见；不自动关闭尚可执行的操作、不替玩家按取消、不暂停世界或改变攻击时点。真正导致中断的条件由动作合同判断。场景预兆、HUD和声音来自同一事实，谁先呈现不改变权威提交时刻。

只对玩家可知的事实显示方向与倒计时。听见不明设备声可以显示大致来向，不能从源实体读取门后坐标、敌人类型或射击目标；看不到也听不到且没有合法传感授权的敌人不生成“危险靠近”雷达。已授权的远端任务故障可报已知设备/Zone，但不附赠连接路线；只有系统确知的剩余时间才能倒数，不推算隐藏AI攻击时间。关闭声音/色彩辅助仍保留等价合法提示，不提升知识精度。

同一事件用因果事务、对象、阶段与受众范围去重：查询完成、HUD更新和人物确认不是三次“新发现”。同一个警报由“将触发”转“已触发”更新阶段；重发旧阶段丢弃，新阶段不能被旧冷却吞掉。两个不同危险不合并成单一泛化“注意”：紧凑区可以合并版式，但每个已知危险保留类型/范围及当前有效指示；普通通知上限不得删除危机、世界预兆、队员状态或操作拒绝原因。若实际四人战斗仍无法读清，应重审排版和遭遇同时压力，不靠隐藏信息过测试。

全队通知的对象是共享任务/资源的承诺与结果；本人操作失败、被限频或普通查询无结果只在本人当前面板解释。对未知区域的查询不得利用通知内容泄露未获权限数据。已提交的任务/资源结果在原状态与当局记录可复查，即使Toast没出现也不丢结果；普通每帧动作、每颗弹和全部环境声不进入这份记录，不新增永久日志或云聊天历史。
