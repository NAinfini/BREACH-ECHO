完整Beat Graph固定为：

`插入并读取公开风险 → 查询或现场定位同步耦合器 → 选择安保短路/维护长路 → 取得并向前安装耦合器 → 配置三枚可选电力单元 → 侦察两个共振连接Zone并封口/清场/布置资产 → 预览并提交主节点启动 → 沿B05/B06/B07处理三种不同故障 → 确认稳定输出与诊断上传 → 开启B08前方撤离`。

三种故障分别使用搬运安装、空间分工操作和破障/旁路，不允许生成器把它们全部替换成同一终端保持。`CouplerAcquired`、每项Cart选择、主节点启动、每个Fault完成、诊断上传和撤离各有独立幂等提交；客户端重放只返回原结果。

主节点启动后，故障链不能回退到未启动，也不允许重新配电抹掉已发生的激活。可选设施故障只让对应收益失效并开放已预告的较险路线；同步耦合器在安装前越界时回收到最近已知合法点，安装后成为设施状态而非可再次拾取物。全队Wipe是不可恢复失败；三项Fault中的单项设备损坏均有前向维护旁路或较低价值的降级完成，不能留下无目标状态。

## 权限、设施耦合与可观察后果

BLACKSTART-CONTRACT-003 · DECIDED。

起始旧制身份只允许公共Terminal查询、普通门和紧急维护设备。进入B02S需要下列两条真实路径之一：在B02M取得仍可验证的本地值班凭证，保持安静但增加路程；或在B01强制覆盖安保门，立即触发只覆盖B01、B02S与安控链的`SecurityIncident`。该事故启动旧防御、改变声明门态并以真实警报声刺激相邻传播群；进入B03后可在安控台切断广播并重映射防御，但已激活敌人和已提交攻击不回滚。当前Seed若没有B02S短路，不得显示该覆盖选项。

每个实例固定四套核心系统：配电、门/隔离、通信/扫描、运输；再从通风和安保中选择一至两套。至少存在两项耦合：

1. 三枚额外电力单元在通风、侧闸、防御、交通和研究库间竞争；没有“全开”配置。
2. 交通供电开放B06至B07短路线，同时打开一个可见侧向接缝；侧闸可以封其中一条压力线，但不能封掉全部必然来源。
3. 安控接管需要通信链和电力；成功后保留炮塔当前弹药、损伤和射界，不免费修满。
4. 研究库耗两枚电力单元并开放额外价值与前方侧入口；不开库不影响主线可解。

未选择的系统在现场保持可理解的断电、关闭或手动旁路状态。所有收益必须在3D世界中表现为雾层变化、门体移动、炮塔阵营/射界、交通平台位置、地图快照或实际可走路线，不能只改变HUD百分比。

## 刺激、敌人和有限来源

BLACKSTART-CONTRACT-004 · TEST。

初始休眠敌人由生成器锁定，完整四人Standard灰盒目标为24–32敌人角色点，分成4–6个可观察传播群；单个普通Cluster不超过两个传播群。首轮只使用逐能体与压射体，基础两敌人通过后，设施对照只加入B05一台哨戒炮塔；守备机不替换进入此固定样例。该数量是任务卡测试起点，不证明平衡。

五档初始实体数、完整角色池、重型/远程比例、设施上限和四人来源总额见[首轮任务难度、敌人和配装用途矩阵](首轮任务难度敌人与配装矩阵.md)。本文的24–32点是Standard任务基准，不得被误用为所有难度或每个入口各自的预算。

普通查询、安装耦合器和Cart配置只产生接触级或群组级刺激；强制覆盖产生声明安全域的区域级刺激。B05主节点启动产生设施级刺激，使B05、B06和B07中仍存活的休眠群进入`Stirring`，并开启一份`BlackstartIngressSource`。该来源的基础总预算为12角色点，再统一应用TP-DIFFICULTY-COMBAT的难度与有效Seat倍率；预算由B06侧接缝和B07货运闸两个实体入口共享，不是每个入口各12点。局部前兆不少于2秒。

侧闸配电可永久封B06入口；B07入口作为必然激活的最低来源不能在启动前完全移除，但能通过事前清场、门态和炮塔显著减压。来源预算耗尽、入口被合法封闭或B07稳定输出提交后停止新迁入；已经进入设施的敌人持续追杀，不因目标完成消失。生成器不得为“高潮不足”补齐被玩家提前杀死的休眠敌人。

## 团队重装备 / 破障分支

BST-006 · DECIDED / 2026-09-06受托选择；尺寸和时间TEST，玩法未测。

首轮B02O只放一件现场重机枪，性能由[战斗原型数值](../装备/战斗原型数值.md)拥有。它的收益是保留给B05–B07的短时强火力，不负责切割结构，也不是主任务钥匙。工业切割器保留在未来候选，不进入本轮。

B03卡滞货运隔板有普通机械释放装置；主路操作者近距保持2s便能开通，不消耗弹药、电力单元或配装工具。B02M另有沿侧维修架向前汇入B03的通路，预计比直接释放多走30–45s，允许在释放位置受敌人压制时绕行，不要求原路回B01。B02O取枪后经小货运出口在隔板后重接；未取枪、先用空、枪丢失与枪留在支路都不改变两条通路的合法性。Fault03同样采用机械释放或前向维修架，普通结构伤害只是额外可选解。

取枪支路使用原Optional预算，不因奖励改成重机枪而新增一份敌源。固定图验证不拿重机枪也能完成；持取、切枪、倒地、断线、多人抢取和越界都保存同一实例及剩余弹带，不凭空补枪。

取舍理由：保留切割器会使首轮多做一个平台；让机枪承担切割会损坏装备身份；取消旁路会把有限弹药变成软锁钥匙。因此采用“可选战斗收益＋无装备依赖的机械开路”。若实测支路收益不足，先调支路风险和重机枪弹带，不恢复唯一钥匙。任务种子、资源压力与真人走读仍须通过原有验收，纸面可达不等于试玩通过。
