# 标准长局：节奏、失误路线与前向资源验算

## 本批结论如何使用

本页负责Standard长局全程库存及五档名单/首补前派生；新增的高难四席混编压力对照、补给/救援/扫描动作下界归[高难后段验算](高难后段火力补给与行动窗口验算.md)。后者不把本文的阶段表变成AI等待指令，也不替代实际到达时刻的资源账。

RUN-PACING-SCOPE · 受托设计、数量TEST；未实现、生成Seed 0、试玩0。三任务的长局时间轴、初始兵力、来源候选与回收位置由各任务的STANDARD-LONG段拥有，本文只拥有核算方法、对照与缺口。原[三任务走读](首轮配装三任务走读与风险验收.md)中的小型功能样例继续验证动作和守恒，不再称作40–50分钟整图。

长局以“取得情报→选择路线→改变设施→承担结果”为重复单元，不要求所有人每分钟都开枪，也不把等待当紧张。阶段目标合计约46分钟；取证跳过补全约40分钟。此时间没有测量依据，不能保证所有队伍达到；熟练玩家更快完成是允许结果。若实际只有20分钟有意义的玩法，先承认长局内容不足，不延长读条、跑道、搬运或追加无来源敌人。

黑启动把前期准备兑现为三段移动故障；取证用证据/权限路径产生压力，可零交火离开；货运让人领先机器，选择隔离或全吞吐，不让玩家站圈。每段的查终端、占手交互仍采用原秒数。表中几分钟包含观察、同步、路线判断、搬运/摆位、交火与恢复，不是把一次三秒操作拉长。

## 名单与人数，而非运行时暗调

RUN-LOCKED-ROSTER · 所有者未确认具体数量，以下为受托TEST。长局配置只在生成前按锁定有效Seat选名单；来源沿既有1/1.5/2/2.5倍率，不改同屏准入、HP、伤害、武器补量、Cell费用或操作时长。断线不移除已存在敌人，迟加入不刷新名单/物资，来源开始后不重置。

初始四席名单取任务表。对每种生物，前k阶段累计数量取ceil(四席前k阶段累计×N/4)，相邻累计之差即该阶段数量；这是离散作者配额，不是半只敌人。固定炮塔不缩成小数，黑启动1至4席均是同一台可绕/接管资产。实际布局必须给每只实体位置和传播群，不把算术比例当空间证明。名单只能使用已通过单体Gate的内容；本批不改变M1两敌人的制作顺序。

|---|---|---|---|---|---:|
| 黑启动 | 26/3 | 38/5 | 52/6 | 64/8 | 32 |

这是按任务基础点派生的各人数候选核对表，不是第二份任务配置，也不是运行中用便宜敌人填余数。生成时检查其成本不超来源公式；各类按候选名单累计25%/75%/100%向下取整拆分，前段未投入者不转借后段。取证全部候选绑定首次覆盖后的安保响应，不把每台终端各设一源。关闭广播或入口、完成目标、阶段离开都会按责任合同阻止相应未来投入；名单不保证全出现，也不是必须清空的任务计数。

本节名单及下方2400个全程库存条件只针对Standard难度。其他四档已由[五档长局派生合同](../内容/任务/首轮任务难度敌人与配装矩阵.md#标准长度的五档派生合同)与三任务的附加落位表定义；本页末尾只登记其算术结果，不把Standard全程库存结果推广到高难，不把功能短图视为长局证明。

## 三种失误路线

RUN-PATHS · 以下用同一初始名单对照不同玩家行为，不因玩家失误另生敌人。分段数字是明确的作者试验输入，不能宣称已有人如此完成。

| 任务/路线 | 初始敌人中需要枪战的集合 | 来源压力 | 退出原则 |
|---|---|---|---|
| 黑启动/准备充分 | 导流4逐能；断路4逐能+1固守；释放4逐能+1压射 | 保守按全部候选投入；不计封口少刷、炮塔、C4收益 | 预清、绕行及隔离减少其他初始威胁；完成故障就停源 |
| 黑启动/一次打响 | 上行集合，加访问段8逐能+1压射 | 同一来源，不因枪声追加 | 第一补给前处理失误，不借后段额度 |
| 黑启动/连续失误 | 所有初始生物及敌对炮塔均用枪处理 | 同一最大来源 | 可被资源耗尽击败，不承诺全图乱打仍成功 |
| 取证/准备充分 | 0：要求实际证明安静证据路径 | 0 | 不为低消耗加终场战 |
| 取证/一次打响 | 第一来源段8逐能+1压射 | 0，普通枪声不等于强制覆盖 | 清掉已唤醒群后仍可安静封存 |
| 取证/连续失误 | 全图生物，包括替代和可选区 | 主动强制覆盖且不及时停广播，按全部候选 | 此为主动增加风险的对照，不是强迫失误者覆盖 |
| 货运隔离/准备充分 | 0：仍须证明机械刺激与路线上无必然交火 | 0 | 准备换取完整主货批，不追求附属货值 |
| 货运隔离/一次打响 | 仓储访问8逐能+1压射 | 0 | 打响不自动选择全吞吐 |
| 货运吞吐/准备充分 | 前送4逐能；异常4逐能+1固守；接收4逐能+1压射 | 全部候选，保守不计封入口收益 | 独立对照“主动选更大收益”，不是失误惩罚 |
| 货运吞吐/连续失误 | 全图生物 | 全部候选 | 允许放弃附属价值/降级，但已提交吞吐不能回滚 |

较少人数的上述初始枪战集合按ceil(四席集合×N/4)缩放，并逐阶段逐类裁切到该阶段确实存在的名单，不凭空造出额外固守。其余初始敌人被绕开、近战/低声处理或真实隔离是待证明的准备条件，不是脚本删除。尤其不能把“准备充分”理解成免费消灭全部敌人；真实安静路径需验证近战风险、噪声、门态、重敌与配装。

## 补给的时点与携带

RUN-SUPPLY-PREFIX · Standard单位沿现行经济合同，弹药发数不变。先计算抵达资源点之前的战斗，再加入实际送达/使用的物资。每人仍只携一个资源包，付费Pod仍需1s确认、8s到达和2s使用；未恢复点另需2s，不能在救人中凭未来补给开枪。

| 任务 | 第一固定Ammo/第一接收点 | 第二接收点 | 固定医疗 | 必需条件 |
|---|---|---|---|---|
| 黑启动 | 第4阶段入口B04 | 第6阶段前向工位B06 | 第3、第6阶段各160HP公共包 | 第4阶段前已收4额度，第6阶段操作前另4；固定母线不花三枚可选Cell |
| 取证 | 第3阶段入口F03 | 第5阶段入口F05 | 第5阶段160HP公共包 | 两次证据择路各有前向额度和无覆盖的最低接收 |
| 货运 | 第4阶段入口L05 | 第6阶段前向工位L06 | 第3、第6阶段各160HP公共包 | 接收在人员线上，不在货车或要求回仓；不依赖全吞吐 |

固定Ammo各一处，按席提供两个槽各一份。两次主路Pod应比较“Ammo+Ammo”“Ammo+Medical”“Medical+Ammo”，而非全部当作免费弹药。Tool替代Medical时，枪弹账相同，医疗收益不同。使用医疗包、操作设施、修工具和手动救援都要付真实占手窗口；战斗中不能同时做完。

固定医疗对1/2/3/4席的均分理论量，黑启动/货运为320/160/106.7/80HP每席，取证为160/80/53.3/40HP每席；这不是自动均分、一次可携带量或实际能用上的治疗。单人医疗相对宽裕是现行四包合同的已知结果，本批不偷偷缩包。一次额外Medical增加160HP公共治疗；超出缺血量保留包内，不转成复活次数。连续挨打与救援失败仍可在医疗总量耗尽前Wipe。

## 算术方法与否决条件

RUN-MATH-METHOD · 静态存量分配，不模拟战斗。读取唯一九枪、普通靶与固守完整正面甲断点；逐能/压射只打身体，霰弹有效发假设八丸全中，爆破满蓄只计直击。命中效率p=0.8的固定成本为ceil(所需有效发数/p)；突击与速射额外每目标多付一发停火浪费，其他枪不强行支付自动枪的过射税。这个取整压力不是实际平均命中率，也不是随机通关概率。

对20种合法两槽配装分别建立全队同配装的1至4席对照；每条路线及三种Pod选择均枚举两枪的有限库存分配，不穷举混编队。每个目标由一名玩家的一把枪打完，不混合尾弹、不借给队友、不计弱点/穿透/爆炸邻体/工具/重资产/炮塔援助。目标按阶段、逐能/压射/固守/炮塔顺序轮转分工，仅检验这份固定分工；失败不代表实际无解，成功也不代表能及时瞄准、换弹、躲避和救人。它检验弹量够不够分配，不检验同时到来的目标能否被及时处理。

入场为满匣+一份后备。每次补给分别加到两槽总弹量，但不能超过弹匣+后备容量；本计算不携带溢出的残包到下一区，因此是保守下界，**游戏依旧保留世界余量**。不把两次包全塞进一格。模型允许在该工位有合法窗口依次使用固定包和到达Pod；没有这个窗口的布局必须拒绝，不能因弹量通过忽略战斗时机。

校验还包括：名单分段守恒、来源点与人数上限、远程历史比例、关闭来源的零增量、初始枪战集合不超过真实名单，以及第一补给前的缺口。不会通过增加等待让所有来源刷完。所有路径仍需实体证明：可选资产不作为钥匙、最低交互点可达、搬运/救援处存在实体遮挡，未处理追兵不会被文字“安全段”消除。

拒绝条件：一次常规失误后所有合法配装都在同一前置门前缺弹；安静路径实际必然惊醒未声明群；三种任务都靠固定站守凑时长；接收点资源晚于必要交战；已清群/封源被追补；只能带某武器才能提交目标。极端配装在全图乱打对照里缺弹不自动构成设计错误。

复算入口：`python -B -X utf8 tools/check_standard_run.py`。输出逐条件有库存分配解的配装数量及失败阶段，不是玩家成功率。完整布局、事件到达速率、最坏并发、命中与受伤分布、救援/投送窗口和时长均未实测；下一步只能依据这些结果继续调整作者配置或等待获准后灰盒，不发布“已平衡”的结论。

连续失误的最早缺口：黑启动/货运第3段，取证第2段。它们发生在本路线主动扫光前区、或很早覆盖并承担全份来源时；追加后段供给不能补救此前负库存。作者应先保证可观察、可绕、可同步处理的实际路径，而非在缺口后补一个大包。全图连续失误仍有不少配装有解；因此这里只说明错误可能花掉选择余量，**不保证乱打必败或整局一定紧张**。

安静取证/隔离货运零枪弹消耗是输入条件，不是脚本证明潜行成立；四人每人分到较少固守、相同个人补给也会比单人宽裕。固定均分不覆盖“一个高手包办大半输出”，当前不得因此锁定人数平衡。

否决/未通过项仍包括：真实46分钟节奏；大量初始实体的空间与性能；已醒群跨区追杀叠加；敌人到达速率与装填/救援窗口；近战及Tool消耗；普通配装的安静前向路线；其他四档的全程火力分配与混编队。工业危险及五档名单现已补齐文档，但实际布局验证仍未获开工批准。没有游戏代码、生成Seed、构建或真人试玩。

## 单人末段缺口的成因与处置

RUN-INVENTORY-CAUSE · 2026-09-07受托复核；原数值与失败结果保留。复算入口为`python -B -X utf8 tools/check_inventory_causes.py`，独立读取两任务名单后核对准备路线，而不是只根据两行结果相同猜测原因。

低声针束＋蓄力爆破的Standard单人准备对照，在黑启动和全吞吐货运均需用枪处理第五段7逐能、第六段14逐能＋2压射、第七段8逐能＋1压射，共29逐能＋3压射。其余初始实体已由原准备路线假定安静处理或绕过，不能再免费减一次。按单人数名单取整后，这个枪战子集没有固守体；缺口不是重甲目标造成的。

| 检查项 | 静态结果与含义 |
|---|---|
| 弹药/医疗、医疗/弹药 | 两者第六段后均有可行余量`针束0/能量68`至`针束32/能量4`的九种互不支配分配，第七段均无原成本解 |
| 缺多少 | 只给其中一槽增加余量时，最少需4发针束或4能量单位；是敏感性试算，不是新增免费补给或改每份Ammo |
| 对必要枪战量多敏感 | 末段少由枪处理1逐能或1压射即可有解；必须由真实预清、隔离、工具或其他合法手段支付，不能直接删除该实体 |
| 双弹投送 | 原输入已有库存解，不需要换配装，也不是规定该配装必须双弹 |
| 连续失误 | 原表仍保留第二/三段开始的前置缺口；后段多4单位不能修复发生得更早的问题 |

采用**维持逐枪补给基线、保留专项枪的成本、把准备收益落实到实体**的处置，不为一组末段差额给所有枪统一加弹，也不把爆破改成高效单体枪。理由是当前对照不计爆炸邻体、弱点、近战及工具，但实战是否取得这些收益还没有证据；两种极端枪组合不是应被悄悄删去的合法配装。

下一次获准做地图验证时，以同种子、同武器、同补给执行准备/一次失误/连续失误三组，再分别不计指定工具、重资产和友军炮塔收益。记录被处理的EntityID、占手与材料、群伤位置/遮挡、实际前向剩弹和能否撤离。不把“少打一只即可”当已经找到可安全近战的那只；若普通准备也只能依靠唯一设备，先修可达路线与合法准备机会，再重算局部供给。没有地图前，缺口成因审查完成，单人战斗平衡Gate仍未通过。
