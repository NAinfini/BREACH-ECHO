# 视觉方向与可识别性

## 玩家目的与范围

一眼区分威胁、交互、造物体系、武器与世界异常；项目独特性必须进入画面，不能停在筑路者、界桥或共振等名词里。

ART-001 · DIRECTION · 来源：SRC-SSOT-2.0 §26.1–§26.3。

正式玩法为真 3D。低分辨率复古黑暗科幻不能作为唯一品牌，照片级写实和卡通低模也不是生产方向。世界原因必须先转化为形状与材质，再服务玩法可读性。

ART-006 · CANON/DECIDED · 来源：SRC-USER-2026-09-05-VISUAL-DNA-SELECTION；完整理由见[Visual DNA 决策](../governance/decisions/visual-dna-and-art-direction.md)。

唯一 Visual DNA 为 **分层壁垒 / Layered Bastion**，生产风格属于受控的风格化工业写实：可信工业结构与材质逻辑、强轮廓和大形体、受限表面噪声、明确玩法可读性。它允许免费、购买、自制与 AI 辅助资产经过 Kitbash 和统一修整后进入同一世界，但不允许来源本身决定美术身份。

Visual DNA 已锁定；现有三张图仍只是概念证据，不是 Unity 实机、性能、玩家识别或正式资产验收。Visual Production Gate 尚未通过。

## 三层造物语法

ART-003 · DECIDED。

| 对象 | 形状与材质 | 必须服务的玩法 | 禁止漂移 |
|---|---|---|---|
| 人类与守门人设施 | 矩形模块、外露载荷、紧固件、焊补、布线与可达维护面 | 电力、门、炮塔、终端、补给与交通状态可读 | 无功能噪声遮挡交互；整套赛博霓虹 |
| 筑路者结构 | 连续巨构、环形负空间、尺度失配、极少且精确的接口 | 一眼识别原生节点、界桥核心与异常空间 | 通用发光三角形；人类式螺丝和脚手架长进本体 |
| 虚空兽 | 不对称有机体量、低重心、越过工程网格的生长与停伏姿态 | 休眠、警觉、攻击方向和危险体量可读 | 穿着建筑零件；仅靠颜色区分敌人类型 |
| 武器与改装 | 稳定主体轮廓、真实挂点、机械状态和动作变化 | 队友能识别武器角色、改装与弹药状态 | 用稀有度颜色替代行为；无功能装饰堆叠 |
| 团队重资产 | 明显双手体量、可见供弹或耗材、放置后保持地标轮廓 | 队友立即认出携带者需要掩护 | 外观巨大但操控、资源和普通枪相同 |

## 颜色、明度与材质

ART-004 · DECIDED。

- 基础环境使用冷中性灰、煤黑、脏白与低饱和金属色。大形体先在灰度中读清，再允许局部色光。
- 青色只属于界桥、网络或筑路者能量；琥珀色只属于人类工作照明、维护和可用设施；红色只属于即时危险或不可恢复失败。关键状态必须另有形状、动作、图标或声音冗余。
- 人类材质强调涂层金属、橡胶、织物、磨损边缘和局部焊补；筑路者材质强调大面积连续矿物或陶瓷、克制接缝和与人类尺度不符的表面；虚空兽材质使用哑光、湿润或焦化对比，但不能把所有个体做成同一团黑亮肉。
- 人类实用灯形成局部暖区，界桥能量形成有限冷色路径，环境保持可读的冷色空气光。禁止常驻彩雾、全屏色偏和粒子把潜行前兆洗掉。
- 细节从大形体到中尺度功能件再到少量微细节。贴花、污渍、线缆和 greeble 不得抢占门缝、弱点、敌人轮廓或可交互边缘。

ART-007 · CANON WORKFLOW · 来源：SRC-USER-2026-09-05-ASSET-SOURCING-NO-QUOTA。

资产生产**不设置免费、购买、自制或AI生成的目标占比**，也不按预设比例分配资产家族。每个资产独立选择能通过视觉、技术、许可、修整工时和Unity性能Gate的最低总风险路径。默认候选顺序为：先搜索真正优秀且许可兼容的免费资产；没有合格候选时，以AI生成加人工拓扑、UV、材质、绑定和动画修整为主要路径；只有AI结果持续不过门、修整成本高于采购，或某个付费资产能明显降低总风险时才购买。来源比例只允许在生产后作为成本复盘数据统计，不能成为采购或生成KPI。

人类工业设施、管线、梯道、容器、普通机械、基础枪模、Humanoid动画和通用VFX更容易接受外部基础资产；四名外勤角色的关键轮廓、Human armor/exoskeleton language、核心武器外壳语言、虚空兽主体轮廓、筑路者结构与界桥必须有更强原创控制。一个资产家族可以混合来源，但都必须收敛到同一Visual DNA。不得把不同Marketplace或生成批次的完整角色/怪物原样并排，再靠统一后处理冒充同一美术体系。

采购、来源、许可证据和SDK/Workshop再分发边界由[Asset Policy](../production/asset-policy-and-provenance.md)唯一负责。Visual Gate通过前只能做少量代表性搜索、生成、采购和试装，不因当前候选领先而批量锁死资产库。

## Unity渲染边界

ART-008 · CANON · 来源：SRC-USER-2026-09-05-UNITY-URP-GAMEOBJECT-FIRST；技术责任见[TECH-ARCH](../technical/architecture-and-performance.md)。

项目正式使用 **Unity 6 + URP** 作为唯一生产渲染管线。HDRP不建立平行正式资产版本，也不为未来可能切换而维护兼容层。材质、Shader、LOD、VFX、Fog、Decal、Lighting和资产采购全部以URP为基线，同时必须满足Steam Deck性能和多人战斗可读性。Visual Gate仍然有效：URP已经锁定不代表当前美术方向、palette、材质语言或光照方案已经通过测试。

## 流程、状态与所有权

ART-010 · DECIDED · 来源：DECISION-VISUAL-DNA-ART-DIRECTION。

当前流程为：Visual DNA 已锁 → 同屏 Style Target → Unity 灰盒应用 → 无 Logo 识别与战斗可读性测试 → Visual Production Gate → 小批量资产家族。资源资产归内容包，碰撞和命中真相归模拟；`broken`、`sealed`、`charged` 等状态驱动呈现，不能由贴图反推规则。

状态表：概念证据 → 受控 Style Target → Unity 玩法应用 → Gate 通过 → 版本化资产。当前唯一母体已经批准，但没有正式 3D 生产资产证明后四步通过。

## 模式、内容与边界

ART-011 · DECIDED/DIRECTION。

Operation 密度服务视线、资源与路线。人类维修层承载大部分可操作对象，筑路者层建立地标、空间异常和路径边界；两者不能用相同模块换材质冒充。Lab 高效果密度仍遵守同一形状身份。内容卡包括轮廓、材质、缩略可读性、LOD、低色彩辨识、动画姿势、危险状态与叙事理由。多人 VFX 必须让队友区分谁创造了当前机会；表现密度可降，命中体积不随 LOD 缩水。色觉差异、夜间模式和 Deck 小屏是早期测试条件。

## 运动、VFX 与 UI

ART-009 · DECIDED/DIRECTION。

人类机械以分段锁止、重量和可见执行机构运动；守门人资产比人类临时设备更精确，但仍可读出功能；筑路者结构运动缓慢、连续、缺少可见传统驱动；虚空兽从近乎静止转入短促爆发，必须先给可辨前兆。相机、后坐力和动画可以强化重量，不能隐藏真实输入窗口或敌人攻击信息。

VFX 只强化状态变化，不持续覆盖几何。界桥共振使用细线、边界位移和有限粒子；人类电力使用局部灯、仪表和机械动作；危险爆发允许短时高对比，但立即归还视野。HUD 采用干净的工业维护界面，关键文字与图标保持屏幕空间清晰，不把污渍、扫描线或透视变形强加给必要信息。

## 几何生产档位

ART-012 · DECIDED · 来源：SRC-USER-2026-09-05-INDUSTRIAL-VS-LOW-POLY-CONCERN；[Visual DNA 决策](../governance/decisions/visual-dna-and-art-direction.md)。

正式模型采用**中等多边形的风格化工业科幻**，不把整款游戏改成低模美术，也不追求照片级微表面。先用大轮廓、模块尺寸、有限倒角、加权法线、Trim Sheet、平铺材质与贴花获得工业可信度；细小几何只有在改变轮廓、交互、动画或近距离第一人称观感时才保留。

低模只用于灰盒、远景、遮挡物、小型通用道具、碰撞代理和 LOD；不能以“低模”掩盖错误比例、坏拓扑、坏法线或不统一的形状语言。额外精度集中在第一人称武器与手部接触面、角色关节变形、敌人轮廓与弱点、关键门机和终端。AI 生成或购买的模型只有在完成拓扑、UV、材质、绑定/权重、碰撞、LOD 和 Unity 玩法视角验收后才算可用。

不预设全局三角面数。每类资产的预算由实际屏幕占比、变形复杂度、材质槽、Draw Call、纹理内存、阴影与目标硬件测量确定，并在 Style Target 后记录为 TEST 基线。

## 参数、示例与验证

ART-013 · TEST · 来源：SRC-CHATGPT-REVIEW-1.0 §4.9、§6；本轮适配。

完成同屏 Style Target 后，给 10 名未知项目者看无 Logo/HUD 的代表画面各 5 秒；目标是至少 7 人认为画面属于同一世界，少于 3 人只描述为通用科幻。另以静态灰度图测试门状态、敌人轮廓和可交互物。这是小样本否决启发，不是市场统计，也尚未执行。

正常：关门后的机械锁位变化让玩家无需看 HP 条知道状态。失败：界桥效果漂亮但挡住狙击前兆，应删遮挡层，不得延长敌人前摇掩盖视觉错误。精确色值、字体、材质参数、雾和特效预算需由 Style Target 与目标硬件校准；这些可调参数不重新打开 Visual DNA，除非触发决策记录中的重审条件。
