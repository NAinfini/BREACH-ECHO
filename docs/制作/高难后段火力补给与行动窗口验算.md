# 高难后段：火力、补给、救援与撤离窗口

## 结论与边界

LATE-SCOPE · 2026-09-07受托设计；参数TEST。本文拥有纸面试验、失败解释和实测准入，不拥有另一套枪械、敌人、补给或撤离规则。高难仍为Veteran、Nightmare、Cataclysm，不能靠涨生命、削逐枪补量、缩前兆或补刷撤离波维持压力。基础版和首个灰盒范围不扩大；没有生成地图、战斗模拟或真人试玩。

后段难度来自同时要处理的事情，而不只是场上总人数：打远处发射器时侧路逼近，搬人时少一把枪，换弹时需要空间，完成目标能停掉未投入的来源。**库存够用、来得及输出、能腾手做事是三项独立检查。** 其中任一项没有证据，就不能把这一段称为已平衡。

黑启动考验移动故障与先前配电；货运考验人员线先行、停靠与吞吐取舍；取证仍可全程安静完成。不能因为选择最高难度，就把三者都变成最后守一间屋。

- 固定Ammo及两次Pod仍在RUN-PATHS对应的前向接收阶段；比较弹药/弹药、弹药/医疗、医疗/弹药。固定份额按实际难度缩放，付费Pod不缩；未到达的补给不能填此前缺口。超容量保留在原地但本模型不带到下一段，单包容量不能变大。
- 命中成本沿RUN-MATH-METHOD：身体命中80%，逐目标向上取整；突击/速射各再算一发过射；固守与破阵从完整甲面打起；满蓄爆破每发四单位，仅直击；泵动全伤距离八丸全中。新增轻敌用其HP逐枪取整。穿透、群伤、弱点和控制均不算免费收益；这不是实际命中分布或严格最坏情况。
- 双槽库存保留互不支配的可行余量；小数补给权益不能当完整子弹射出。脚本只报告该分工在第几段失去库存解；不计算DPS通关率或宣称队员实际遵循了最优弹药分配。

这里的阶段首先是资源核算边界，不是运行时把敌人关在原房间的指令。黑启动提交已经会唤醒B05/B06/B07，后两段敌人可能提前追到B05；货运同样不能靠阶段名阻止真实追击。脚本按作者落位段计消费，仅是一种到达安排下的库存对照；实际更早汇合须将消费移到真实到达时刻再算，不能让晚段Pod倒流。是否能控制到达节奏由实体空间验收决定，不据此批准该布局。

## 火力能否转化为行动机会

LATE-FIRE-WINDOW · 下列为受托验收情境，战斗数值仍由原表拥有。计算从已持有相应枪、目标已可见且全伤距离开始；另加实际切枪、瞄准、飞行、重新取角和换弹时间。不能把最优断点直接当玩家平均表现。

| 局势 | 能做出的具体交换 | 不成立的简化 |
|---|---|---|
| 重敌压住一个工位 | 重狙打裸露部位，或其他枪破功能肢、绕厚甲；队友先截近群 | 重狙一枪固守感知器是当前理论断点，不是所有角度一枪，也不意味着打小怪划算 |

| 线圈获得队列 | 只有实际身体排线且首体不被完整厚甲挡住时才计多体收益 | 首目标破甲这一发仍然截断，不能顺手穿到后排 |

| 队伍交错换弹 | 保留至少一条真实可射枪线，再由完成换弹者接替；可取消收尾按枪型提交 | 纸面整队剩弹很多，却四人同刻空仓；切枪刷新射击间隔 |

盾300HP不是固定时长无敌：侧绕、曲射、重型与实际射界都会改变有效保护。泡沫消耗材料且会到期/受损；C4处理有限群，不提供保护罩；烟幕挡观察不挡已发弹。允许合理投入覆盖整场有限遭遇，不给工具偷偷叠抗性。丢失工具后的对照先检查真实门、墙与人员路线，不免费补设备。

## 补给：先建立可达条件，再分次腾手

LATE-SUPPLY-WINDOW · 必须按现场时序验证，不再把“入段拥有Pod”误作无条件事实。接收点几何由各任务的LATE-SPACE段拥有；公共生成规则见MIS-LATE-WINDOW。

未恢复点的完整最短链为恢复2秒、请求1秒、自主运输8秒、使用2秒，共13秒，尚未含移动和分包。已恢复点为11秒。运输期间可以移动、开火、救人，不必守住控制台；但不能把运输中的物资计入枪里。三档高难最短批间隔10/8/7秒均短于13秒，因此“等一批打完，再一口气呼叫并补好”不是保底策略。

在准备段先恢复当前前向接收点、领取已付物资；后段第二点先清接近线或利用实墙折角完成2秒和1秒动作，发出请求后继续处理来敌，物资落地后再找2秒使用机会。不是要求连续13秒无敌，也不保证连续安全。无盾单人可在入口还未启用时完成前点准备，后点则需实际杀掉/隔离挡路威胁或用路线争取动作窗口；不能假定有人永远替他架枪。

标准一份Ammo同时保留两个槽各自权益，不浪费已满的一槽；可以留包或把同槽余量转交队友。四人用同一容器时须有分散站位，不以重叠模型假定全部同时安全补满。携带医疗的人不能同时携另一Ammo包；可以先放下、取弹使用，再拿回尚在现场的医疗，移动/动作都计时。

第二Pod选医疗意味着放弃这次双槽Ammo，不是增加第三份主路投送。医疗也不等于复活或原地回满；检查固定医疗的前后位置和实际受伤，不把预计敌人伤害总和设为强制医疗税。若窗口失效，优先调整接收工位与侧路/初始群位置，不自动加包或削弱每份补量。

## 救援：先解除哪条危险，再决定在哪里拉

LATE-RESCUE-WINDOW · 救援3秒、搬起0.8秒、移动与出血沿现行生命参数。以下是可执行顺序的试验输入，不假定敌人临时停火或优先追某名玩家。

1. 就地救：先确认能命中救援者的枪线、近身单位与在途弹体；队友清除/挡住真实威胁后再开始，伤员可原地以倒地枪口协助。远程断视线不取消已发弹。
2. 搬后救：先创造0.8秒取人机会，沿同速人员线到实墙后放下，再完成3秒。搬运者和被搬者这段都不开枪，不能算作仍有四把枪的输出。
3. 贡献自救：伤员对本epoch内合法目标造成足够生命伤害，队友补刀仍可触发；打甲、旧epoch贡献或只有友军炮塔在射击不自动达标。它是另一种机会，不是每次倒地的必得保险。
4. 撤离取舍：正在共享扫描时可以留人守圈、转去救人，或主动全员离圈保留进度。若选择让扫描完成，区外成员被留下，不追加个人扣款；不能用本批设计改成全员到齐。

一个计算对照：到实墙后安全点的搬运路径6m，按走速5m/s、搬起0.8秒、放下即时及救援3秒，总占用5秒。该过程出血消耗为取人0.8秒＋搬运1.2秒×0.5＋救援3秒＝4.4秒，另加到达伤员之前的耗时与实际伤害折算。**6m是试验路径，不是全局保证。** 墙能挡直射，仍须单独验证缝行的侧路、破阵接近与投涌弧线；“在墙后”不等于能躲所有敌人。

起身保护最多2秒，而空仓重狙合法上膛需3.4×0.85＝2.89秒，保护不足以覆盖整次换弹。救起后仍需要掩体或切到尚有弹的另一枪，不应自动给弹/延长无敌。远程攻击前兆未被高难缩短，但多攻击错相可能覆盖所有动作机会：若唯一救援落位存在这种覆盖，布局不合格。

## 撤离：可以轮换，不要求最后硬扛到底

LATE-EXTRACTION-WINDOW · 共享模式沿OPS-EXTRACTION，本批不改进度、速率或成员结局。

普通扫描分别由1/2/3/4人维持时，未量化前时长为20、16.667、14.286、12.5秒；最终提交向上量化到60Hz。实际有人离圈/倒地就分段累计；所有人离圈暂停保留。实物扫描固定速率，不能把档案筒放入就自动当全员加速。

试验中，一人守圈8秒完成8工作秒，随后无人守圈5秒去救援，恢复两人守圈再需10秒：整段23秒，期间并非23秒持续读条或无敌。完成时全Run同时结束；不要靠故意剩一只怪无限刷收益，也不需等最后一只死掉才走。

接收区要允许在区内用实物掩体换位，而不是把扫描面全铺在远程交叉火力下；可被绕后的掩体、入口与人员退路仍要可读。高难可以迫使停扫换位，但不能让每种合法站位都被不可规避攻击同时覆盖。黑启动/货运完成主目标即停止其未投入来源，取证须实际停止相应安保；所有已Active敌人继续追杀。撤离扫描自身不开源。
