# 玩家故事与单一世界时间线

## 当前叙事合同

STORY-001 · CANON · 来源：SRC-USER-2026-09-04-SINGLE-STORY；SRC-USER-2026-09-05-FOUR-LIVING-FIELD-SQUAD-NONPROGRESSIVE-STORY；SRC-USER-2026-09-05-COLLECTIBLE-ACHIEVEMENT-LORE；SUPERSEDES：旧五幕、Final Revelation与账号剧情阶段候选。

官方世界只有一套客观历史，不使用多宇宙、时间重置或互相矛盾的个人正史。基础游戏不采用逐幕推进、按账号解锁真相的线性战役，也没有必须依次完成的“最终揭示”任务。筑路者、人类内战、封网、壁垒和虚空兽的真实历史由[世界观NAR-011](canonical-world-history-and-lore.md)唯一负责；玩家从一个已经进入常态化外勤行动的时代开始游玩。

程序Operation是这个时代里不断发生的新合同，不是同一段剧情反复重演。单局成功、失败、地图Seed和任务顺序不会为每个账号生成不同世界历史。未来若以更新、联合行动或Descent推进世界，只能把结果作为对所有玩家一致的公共时间线事件，不建立高低剧情进度玩家之间的剧透、跳关或状态兼容系统。

## 玩家是谁

STORY-007 · CANON · 来源：SRC-USER-2026-09-05-LEGACY-ID-LOW-CLEARANCE。

壁垒为外勤队重新签发断网前格式的设施恢复凭证。旧设施通常能够确认凭证格式和基础资格，却无法验证壁垒是否继承了全网授权，因此只开放公共区、最低生命保障和低权限终端。小队必须在现场寻找本地记录、读取载波、恢复协议、重建身份映射或完成设施能够验证的操作，才能取得更高权限。这解释了玩家为什么能进入设施，却不能在壁垒里一键接管门、炮塔、机器人和资源库。

STORY-008 · CANON/DIRECTION · 来源：SRC-USER-2026-09-05-FOUR-LIVING-FIELD-SQUAD-NONPROGRESSIVE-STORY；部分沿用SRC-CODEX-2026-09-05-BASTION-FIELD-TEAM-CANDIDATE。

玩家控制**壁垒外勤小队**。这是一支固定四人编制、拥有四名固定角色的专业行动队，定位接近固定人物组成的高风险合作小队，而不是可无限替换的匿名士兵池。四名成员在官方世界观中都活着；普通程序任务、玩家倒地和整队Wipe不得写成任何一人的正史死亡，也不使用克隆、复活舱、时间倒流或平行宇宙解释重新开局。

四名成员不使用真实姓名；代号、经历、性格、彼此关系和说话逻辑仍为OPEN。当前候选`断桥 / 回声 / 铁砧 / 寒蝉`及完整关系矩阵见[四名角色v1](../content/field-team-character-personalities.md)，状态为PROPOSED FOR USER VERDICT；前两组不够自然或不够有力的候选已明确作废。年龄、性别呈现、身体、服装、轮廓、动画外观和配音选角按用户要求全部延后，不属于本轮人物裁决。正式角色完成后，每个联机Seat占用一名未被占用的队员，不能让两名玩家同时扮演同一个正史角色。角色身份不等于硬职业：装备、武器和工具选择继续承担玩法构筑，四名玩家选择相似装备仍然合法；任何角色都不得因剧情身份垄断主任务必需能力。

小队是壁垒的正式外勤单位，不是囚犯、私人雇佣兵、克隆人或天选英雄。成员可以具有安保、设施工程、急救、运输、勘测或回收经历，但都接受能够覆盖武装战斗、终端、界桥、污染控制、资源搬运和撤离的共同训练。他们执行合同的共同理由不是奖金或寻找真相，而是壁垒必须持续取得燃料、冷却材料、工业部件、技术、研究数据和可用设施才能生存。

一至四名真人可进入同一局。少于四名真人时，本局只部署被玩家占用的成员；未部署成员仍属于四人小队并在世界观中存活，不要求强制Bot填满。队长只拥有组队、选合同和开始任务的会话职责，不在剧情中成为唯一主角或拥有更高正史地位。

## 玩家开局已经知道什么

STORY-009 · CANON/DIRECTION · 来源：SRC-USER-2026-09-05-FOUR-LIVING-FIELD-SQUAD-NONPROGRESSIVE-STORY。

基础游戏开始在最初重开线路和早期调查已经发生之后。壁垒已经确认并公开以下行动级事实：旧人类社会曾因无限探索与限界探索发生内战；虚空兽来自界桥外的贫能天体并沿能量梯度进入网络；两派在确认外敌后停战；旧网络后来被人为关闭；重新供能可能解除本地休眠条件并吸引其他个体。四名外勤员接受过相应训练，不会在任务里假装第一次听说内战、虚空兽、休眠体、失控防御或旧权限分裂。

公开知识不等于每份档案都完整。壁垒仍可能不知道某个设施的局部事故、具体命令链、人员名单、某条字形路线、筑路者遗迹用途，以及灼星种或借尸者在特定区域的计划。这些内容通过任务情报、环境叙事、物品说明、可收集故事碎片和成就集合增加上下文，可以影响当局路线与目标判断，但不承担“完成第X幕才能知道世界基础设定”的功能。

玩家开局必须能直接回答四件事：我们是壁垒外勤小队；壁垒需要外部资源和设施；旧网络里有虚空兽与失控机器；我们的工作是在资源受限的情况下完成合同并活着撤离。简报只说明本局已知地点、目标、威胁和奖励，不重新讲一遍宇宙历史。

## 非递进的玩家故事

STORY-010 · CANON/DIRECTION · 来源：SRC-USER-2026-09-05-FOUR-LIVING-FIELD-SQUAD-NONPROGRESSIVE-STORY；任务结构见[Operation OPS-011至OPS-013](operation-game-mode.md)。

玩家故事不是“无知新兵逐步发现终极真相”，而是四名熟练外勤员反复面对同一职业矛盾：壁垒必须打开旧设施才能生存，而每次供能、运输和权限恢复又可能激活敌人、唤醒休眠体或让错误的旧系统重新运行。剧情价值来自每局具体工作中的压力、队员互动、任务事故和局部发现，不来自账号剧情等级。

常规合同从同一任务板提供，按程序组合地图、主任务、支线、敌人、设施状态和资源局势。它们可以回收废料、取得战略资源、保护技术、恢复研究数据、重写设施协议、救援、捕获威胁或使用重资产破障。单局会真实改变该MissionInstance里的门、电力、炮塔、机器人、敌人和资源，但结算后不提交个人故事章节、节点所有权或永久清场地图。

四名角色可以有持续一致的关系和反应，例如谁谨慎、谁爱冒险、谁熟悉旧机器、谁对牺牲命令敏感，但这些是人物表现，不是分支剧情系统。对白不得假装他们忘记已经公开的历史，也不得因玩家任务顺序不同而互相矛盾。可选故事收藏可以解锁字形提示、档案关联、成就、挑战或外观，但不把基础敌人知识、普通任务类型或战力锁在故事收集率后面。

## 可收集故事与成就

STORY-011 · CANON/DIRECTION · 来源：SRC-USER-2026-09-05-COLLECTIBLE-ACHIEVEMENT-LORE。

玩家层故事采用类似碎片考古的非线性交付：日志、维护记录、私人通讯、物品说明、原型武器来历、尸体与环境痕迹、守门人状态、隐藏字形房和成就条目分别提供局部事实。玩家可以只做合同，也可以把分散线索按人物、设施、事件和阵营整理成更完整的历史。它不是按章节播放的剧情，也不要求所有玩家以同一顺序取得碎片。

故事碎片分三种可信度：`记录事实`来自可验证设备或多源一致数据；`当事人陈述`只证明某人曾这样认为；`环境推断`是壁垒档案员根据物理痕迹提出的解释。碎片可以残缺、带偏见或互相缺少上下文，但不得与作者层客观历史制造无法解释的硬矛盾。后续线索可以纠正人物认知，不能偷偷改写已经验证的物理事实。

成就承担发现确认和收藏目标，不承担剧情门锁。候选包括发现某次事故的全部关键证据、确认一名历史人物的最终去向、完成一个设施系列、解出隐藏字形路线或携出一件重要实物。游戏内Archive是故事文本与关系的唯一完整载体；Steam/平台成就只镜像关键收藏里程碑，不能成为玩家理解历史所必需的外部页面。成就名称和描述必须避免在获得前直接剧透答案；奖励只允许档案补全、外观、称号或展示物，不提供必要战力。

程序地图中的故事收藏必须绑定手制且语义兼容的房间/事件Cluster，不能把一封关于冷却事故的遗书随机塞进完全无关的军械库。重要集合不得因随机Seed永久不可得，也不得使用现实时间限时轮换制造FOMO。多人发现时，当前在场且有资格的所有玩家同时获得收藏记录，不需要抢拾取物。

## 死亡、复玩与公共世界变化

STORY-003 · CANON/DIRECTION · 来源：SRC-USER-2026-09-05-FOUR-LIVING-FIELD-SQUAD-NONPROGRESSIVE-STORY。

四名外勤员在正史中持续存活。单局倒地与救援可以发生；整队Wipe、退出或重新开同一Seed只是失败的游戏结果，不进入官方人物死亡记录。游戏无需为“为什么又能玩”提供复活机器，因为程序Operation不逐局书写人物传记或公共世界历史。

任务结算仍可保存账号奖励、挑战、外观和故事收藏，但不保存`CanonicalStoryStage`式主线阶段或玩家专属世界真相。不同游玩时长的玩家可以直接组队，不需要选择谁的剧情世界、避免剧透或同步章节；收藏差异只影响个人Archive中已经解锁的条目。Mod/TC继续使用独立命名空间，不得把自定义事件写成官方历史。

Descent发布联合行动是例外的公共世界事件：如果采用，它由服务器汇总全体Operation贡献并对所有玩家统一开放真实行星端点。它不是某个账号单独完成的主线，也不能让未参加活动或后购买内容的玩家永远停留在旧世界状态。

## 已否决结构与边界

STORY-004 · LEGACY · 来源：SRC-USER-2026-09-05-FOUR-LIVING-FIELD-SQUAD-NONPROGRESSIVE-STORY；SUPERSEDES：旧STORY-A1至STORY-A5候选。

旧五幕结构“任务→矛盾→第一层真相→封锁代价→最终揭示”、Handler与Archivist推动的逐幕调查、A1Resolved至RevelationResolved状态、Post-Revelation Hub以及逐账号证据资格已经被非递进方向否决。它们不得继续出现在任务板、存档、多人规则或制作计划中；被否决方案的依据只在[证据登记](../sources/evidence-register.md)和受保护来源快照中追溯。

基础版红线：不让四名老练外勤员反复假装第一次见虚空兽；不把内战真相拆成必须按顺序消费的剧情课；不以主线等级锁普通程序任务；不制造角色正史死亡；不因为固定四人角色就锁死武器或主任务能力；不把世界观百科塞进每局简报。
