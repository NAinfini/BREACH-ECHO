# 产品体验、受众与模式选择

## 一句话承诺、设计支柱与核心矛盾

VIS-010 · DECIDED · 来源：当前产品与本轮完整性审计。

**一句话承诺：**四名外勤队员进入每次结构与局势都不同的失联设施，在有限资源下侦察、计划并改变设施，用团队执行把一次可能团灭的行动带回壁垒。

| 设计支柱 | 必须在游玩中看见 | 否决信号 |
|---|---|---|
| 压力下的可解释计划 | 任务前信息、路线/资源承诺、世界变化和战报因果相连 | 随机惩罚、隐藏补偿、失败原因无法复述 |
| 规则稳定的高技巧战斗 | 响应性枪感、可学习取消/预输入、部位与环境反制 | 纯血量海、输入读心、宏/帧率成为必需优势 |
| 合作但不剥夺个人作用 | 1–4人都能独立做关键决定，公共资源有透明提交 | 一名指挥者玩游戏、其余三人搬箱子或等职业钥匙 |
| 熟悉语法中的未知局势 | 手制Cluster、任务/设施/敌人Source由Seed重组且可验证 | 只移动门和箱子、玩家靠背整图取胜 |

核心矛盾是“为了让壁垒继续活下去，必须重新启用那些会带来风险的设施”。玩家每一层都在回答同一个问题：**现在用时间、位置、物资与暴露换取更多情报和控制，还是带着未知与较少控制继续向前**。任务板体现为风险/回报，配装体现为专精/应急，潜行体现为准备时间/弹药消耗，设施体现为投入/战场控制，主目标体现为安静/快速，撤离体现为保住成果/继续贪取。任何系统若不能产生这个取舍，只增加术语、读条或奖励数字，就不进入首发。

所有主系统至少强化一项支柱且不得破坏另一项；无法指出所服务支柱的新功能默认不进入首发。

**标志性玩法：**侦察陌生设施，选择性恢复、隔离或改写其系统，再用玩家亲手改变的战场完成任务并撤离。玩家反复练习的三个核心动词是`侦察 → 改写 → 执行`；搜集、终端查询、守点和击杀只能服务这条链，不能各自膨胀成平行小游戏。**核心张力：**更多设施能力能节省资源并创造安全，也会扩大声、光、供能、路线或权限暴露；不开意味着更弱，乱开意味着更危险。若一项主任务从头到尾不需要玩家理解或改变任何空间状态，它可以是支线或战斗情境，但不能代表本作的核心Operation。

## 玩家目的

让好友一起进入陌生设施，在压力下计划、交火、改变环境，并对“为什么这次活了或死了”形成共同记忆。玩家的承诺应能用一段实际游玩解释，而不是听完 Proc Graph、Forge、IR 和五种武器哲学才明白。

VIS-001 · DECIDED · 来源：当前产品基线；历史见Git。

唯一基础产品为1–4人合作PvE Operation：裸枪手感、有限资源、真实设施后果与合作执行。少量有边界的武器/工具改装增加情境解法。Descent保留为FUTURE扩展；共享内核不等于两套首发内容。完整范围由[首发合同](产品范围与首发合同.md)拥有。

模式取舍依据见[产品核心取舍](../治理/选型依据/产品核心取舍依据.md)，不在愿景中维护第二套方案状态。少量改装是否增加选择须与无改装情境对照测试；共享内核不代表共享奖励资格。

## 为什么会爱、恨、退款、玩一百小时

VIS-005 · PROPOSED · 来源：本轮受众假设 E3；尚无玩家研究。

| 受众 | 会爱的具体体验 | 会恨/退款的机制 | 值得一百小时的条件 |
|---|---|---|---|
| 新手 | 十分钟内能救队友、用环境获得一场胜利 | 术语、终端、资源与自动合成同时教学；一局输四十分钟还不知道原因 | 首局懂一个战术，第三局独立提出计划 |
| 核心高难玩家 | 可预判威胁、承受失败、靠决策获胜 | 隐藏补偿、资源复制神器、剧情动作代替策略 | 多条可行路线与稳定规则，熟练不会只剩背图 |
| 好友队 | 共同犯错与扭转残局 | 一个专家全权指挥，其他人搬物资 | 每人都能改变至少一次关键局势 |
| 随机队 | 不开麦也可协调 | 公共物资被抢、Cart 被抢提交、后进者吃亏 | 清楚责任与反馈，沟通成本低于战术收益 |
| 单人 | 亲手布置与执行计划 | 为四人设计的同步开关、强制 Bot、搬运等待 | 无 Bot 可完成，压力有可观察的单人解法 |
| 主播/观众 | 能解释的翻盘、武器变化、任务后果 | 满屏粒子、所有死因是“Proc 又 Proc”，术语代替情节 | 看见原因、选择和后果，事件足够不同 |

## 残酷判断与定位边界

VIS-006 · PROPOSED · 来源：本轮产品评审推断 E3；外部基线见[研究](../参考/研究资料技能与文档格式.md)。

你现在最大的风险是把“我想要的系统清单”误认为“玩家愿意反复做的事情”。GTFO 的难不是所有玩家都等着填的市场空白；它也提高了组队、学习和失败成本。少产品可能代表未满足需求，也可能代表受众小、制作难、留存脆弱。没有样本前，两种解释都成立。

“能改一切”吸引的是一小部分创作者。普通购买者先问今晚好不好玩、好友愿不愿意来。社区不会自动替一个不好玩的底座生产内容。God Build 让一人爽却让三人无事可做时，宣传视频和真实留存会相反。高规格枪感、程序地图、开放 SDK、无损大规模模拟、双视角和两种模式同时推进，等于把最难交付的东西排列成目录。

范围控制、具体伤害机制、Severity、实验阈值与按依赖排列的否决关卡见[制作与风险](../制作/制作验证方法.md)。文档不能替代这些测试。
