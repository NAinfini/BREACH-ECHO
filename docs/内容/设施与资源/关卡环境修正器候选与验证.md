# 关卡环境修正器候选与验证

## 方向与责任

ENV-MOD-SCOPE · 所有者确认纳入设计候选；具体边界为受托设计，数值与玩法均未验证。

环境条件描述这个地点当前有什么特殊状况，通过路线、配装、布防、行动窗口和设施操纵改变队伍计划。普通Operation与特殊活动引用本文同一候选ID与定义，不建立两套环境规则。本文拥有环境内容、受影响对象、反制与验证要求；任务生成拥有准入与可解性，活动规则拥有额外组合与奖励。用户授权是将已讨论建议纳入文档，不是批准全部候选进入首发、确定实际参数或启动Unity。选择理由见[关卡环境修正器取舍](../../治理/选型依据/关卡环境修正器取舍.md)，研究限制见[证据登记](../../sources/证据登记与覆盖限制.md)。

普通任务首轮建议0–1个主要环境条件，正常环境仍进入候选池；这是TEST作者预算，不是永久数量上限。特殊活动可以使用通过组合验证的条件，但必须把地点已有条件计入总复杂度。条件可以覆盖整个Site或明确Zone，不要求每个房间同时受影响。仅换滤镜、增加等待或提高敌人血量不能证明候选成立。

## 新增候选

ENV-MOD-CANDIDATES · PROPOSED；复杂度为相对作者成本，1为单一清楚变化，2为改变路线/配装，3为改写整局节奏。

| ID / 名称 | 可观察变化与影响对象 | 战术收益、代价与反制 | 复杂度 / 准入边界 |
|---|---|---|---|
| `MOD-EM-STORM` 电磁风暴 | 预警后，暴露的数字瞄具、探测器与自动炮塔暂时失效，随后恢复；敌我同类设备同规则 | 提前选择屏蔽防区、恢复当地屏蔽设施，或趁敌方安保停机穿越；己方自动火力也会中断 | 2；具体停机合同见下节；不能整局废掉某类配装 |
| `MOD-LOW-GRAVITY` 低重力 | 固定向下的重力减弱，跳跃更高、滞空更久，投掷物下坠减少 | 利用高处和低障碍侧路；空中暴露时间与落点承诺增大 | 3；先局部区域；必须验证导航、搬运与任务物可达性 |
| `MOD-POWER-ROTATION` 轮换供电 | 已标明的区域按公开阶段轮换供电，照明、炮塔与运输设备随之变化 | 选择当前防区，或操作配电改下一阶段；通路与火力可能不能同时保有 | 3；与能源欠载默认互斥；门、电梯和任务设备必须有安全状态 |
| `MOD-SETTLING-FOG` 浓雾沉降 | 低处积雾，限制玩家与依赖视觉的敌人视线，不自动屏蔽其他已声明传感能力 | 低处隐蔽穿越，高架观察，恢复风机清出防区 | 2；可作为通风故障的具体配置，二者不重复计效；不让敌人无说明穿雾精确射击 |
| `MOD-INDUSTRIAL-NOISE` 工业噪声周期 | 压机/涡轮按可读周期轰鸣，在实际声音传播区降低部分行动声的探测距离 | 协调搬运、破拆、移动的时机；近处目标、视觉刺激与受击仍可能暴露 | 2；不保证枪声全被遮蔽，不重置已唤醒敌人；噪声源本身的刺激也须声明 |
| `MOD-CONDUCTIVE-FLOOD` 导电积水 | 漏电源使明确边界的积水区间歇带电，对可受该危险影响的实体生效 | 走高处、断电、排水，或诱敌进入带电区；断电可能失去友方设备 | 2；不得凭一片水材质传导到全图，不造成出生/必经点无反制伤害 |
| `MOD-FLAMMABLE-VAPOR` 易燃蒸气 | 泄漏区可被指定火花、火焰或爆炸点燃，形成有限范围与持续时间的燃烧 | 排气后安全通过，或诱敌引燃；玩家、友军及已声明可损设备也有风险 | 2；声明点火白名单、燃料库存和传播边界，不无限回填形成免费杀怪循环 |
| `MOD-PRESSURE-VENTING` 压力泄放 | 指定风口预警后喷出定向气流，影响可受力实体、烟雾和投掷物 | 借气流清除遮挡、推开敌人，或在背风处掩护搬运 | 2；作用体积和方向可辨认，禁止无预警吹落必经深坑或把任务物吹出可达区 |
| `MOD-COOLANT-RUPTURE` 冷却管破裂 | 泄漏产生局部霜雾和湿滑地面，改变玩家制动与适用冲撞敌人的停止距离 | 关闭阀门恢复稳定通路，或诱导冲撞目标越过有利位置 | 2；避免全图持续打滑，前兆与出口必须可读；不增加枪械Heat |
| `MOD-SENSOR-ECHOES` 传感器回波 | 异常区的探测结果带明确的低可信回波，不等同已确认敌人 | 到场确认，或修复中继取得可靠的带时间戳快照 | 2；不伪造队友求救、任务成功或交互提示；不把错误回波升级为确定敌情 |
| `MOD-SECURITY-IFF-FAULT` 安保识别故障 | 指定防御单位把未识别目标视为入侵者，包括怪物，依真实感知与射界攻击 | 借安保形成第三方火力，再绕过、关闭或接管；队伍也可能被攻击 | 2；与敌对安保默认互斥；与风暴组合时两者按同一设备状态生效 |

## 电磁风暴停机合同

ENV-MOD-EM-STORM · 受托DECIDED；首轮时序由ENV-MOD-PARAMETERS拥有，数值与乐趣仍未实测。

阶段固定为`预警 → 干扰 → 恢复`。任务卡说明主要条件及设备类别，现场用文字/形状与声音等至少两种通道表达当前阶段、受影响区与恢复信息；降低闪烁或静音后仍能判断。预警必须给出足够行动时间，具体窗口由原型确定，不采用无前兆的每帧随机故障。

| 对象 | 干扰期间 | 恢复与反制 |
|---|---|---|
| 数字瞄具、电子测距与照明分划 | 对应电子功能停止，明确显示失效状态；纯光学透镜仍能观察 | 恢复原功能；基础瞄准操作持续可用，不能靠永久禁瞄制造难度 |
| 扫描器与探测点标 | 停止取得新结果；旧结果保持原时间戳并按原规则淡出，不冻结成实时情报 | 恢复合法扫描，不免费补出干扰期内的隐藏信息 |
| 敌我自动炮塔 | 暴露且未屏蔽的设备停止索敌与发射，不继续暗耗弹药 | 保留阵营、库存、损伤与接管进度；恢复前给可读提示，按正常索敌/攻击前兆重新交战，不瞬间补射积压火力 |
| 枪械与专用近战核心机构 | 首轮设为明确具有屏蔽保护，基础攻击与射击仍可用；电子辅助按各自类别处理 | 配装说明公开保护边界；双电磁/能量枪组合不能同时失去核心战斗能力 |
| 门、电梯、运输与任务终端 | 首轮不因“电子设备”这一泛称自动停机；扩展到某设备前必须有作者声明的安全停靠、手动通路或可继续的任务状态 | 不抹除已完成阶段或再次扣费；没有完整失败/恢复解法的设备不进入受影响名单 |
| 语音、字幕、基础HUD与交互提示 | 继续可用，保留必要状态与导航，不模拟真实断网 | 不以夺走沟通或可访问性为难度 |

同类型、同暴露与同屏蔽条件的敌我设备必须同结果，屏蔽差异现场可识别，不能只凭阵营免疫。屏蔽房间和可恢复的本地屏蔽设施提供站位/路线选择，但不要求所有队伍必带某工具。暂时停机不等于永久接管、敌人死亡或恢复资源；反复风暴与读档不能补弹、修复或重新领取奖励。

## 低重力空间合同

ENV-MOD-LOW-GRAVITY · 受托DECIDED；倍率、动作参数与玩法为TEST。

先验证边界明确的局部区域，方向固定向下，不同时引入零重力漂浮、墙面行走或随机翻转。进区前能识别条件；同一适用类别的玩家、敌人、投掷物与可搬运物遵循公开规则。不是所有AI都必须跳跃，但必须验证真实到达/攻击路径，不能生成永久无伤清敌高台。

主线保持不依赖精密跳跃的通路；低重力侧路可提供站位收益，不能越过目标锁、任务阶段或安全结构。验证进出边界时的速度连续性、落地与坠落伤害、楼梯/门框净空、FPS/TPS相机、投掷落点、倒地救援及Cart/双手任务物运输。不通过隐藏瞬移或复制物件解决掉出地图；重力恢复不能突然把玩家或任务物摔进不可达区。

## 四项环境的首轮测试配置

ENV-MOD-PARAMETERS · 2026-09-07受托TEST，未实现或试玩。下表只拥有环境参数，具体空间与组合由[任务映射](../任务/修改器任务映射与组合准入.md)拥有。使用固定周期和局部边界，先问“是否值得改变行动”，不把等下一轮作为唯一解。一个环境槽只绑定一个连续影响区；多个房间副本须另建配置并重算复杂度与遭遇。

| 修改器 | 首轮参数 | 可利用的变化与反制 | 取消、停止和恢复 |
|---|---|---|---|
| MOD-EM-STORM | 正常30s → 预警4s → 干扰8s → 恢复2s，周期44s；预警仍可用，恢复阶段仍停机 | 只有登记暴露区内的电子辅助、探测采样及自动炮塔受影响；实体墙屏蔽维护侧可走。核心枪械、近战、基础HUD、队内通信和任务控制不受影响 | 周期从Run模拟开始计时，不随进房重启。被打断的扫描取消未提交采样；旧点标按原时戳跟随并衰减。恢复后重新采样/索敌，不补发射击；库存、阵营、伤势不变 |
| MOD-INDUSTRIAL-NOISE | 平稳12s → 预告2s → 排风轰鸣6s，周期20s；仅轰鸣期间生效 | 在已登记声学区内，满足下述载噪条件的脚步、接口、卡扣、校准与普通机构声，传播半径×0.5；中心刺激不变。可以借窗口移动/操作，也可走常态低声路线 | 同一固定模拟周期；独立安全侧开关1s停机，恢复1s后接回原相位，不重置周期或刺激。停机消除掩蔽，已醒敌人照常追杀 |
| MOD-CONDUCTIVE-FLOOD | 一处连续积水区，最大8m×4m、深度≤0.15m；独立故障储能最多3次放电；每次预警2s、带电3s，下一次开始预警前间隔8s | 干燥连续人员侧路无需跳跃。安全侧开关1s断开故障馈线，不自动重启；保持带电可诱导敌人涉水，但不是全房AOE | 初态有水、支路隔离、3次余量；主动接通1s才开始。每次进入预警即扣一次资格，断电取消余下伤害、不返资格；重新接通只用余资格，重连不补次数。第三次结束自动闭锁，关开不能充回 |
| MOD-LOW-GRAVITY | 局部向下重力为普通值×0.6；持续整局，首轮不提供运行中翻转/关闭；地面跑速、输入、跳起初速不变 | 玩家、离地敌人、自由投掷物与自由搬运物同倍率；固定/导轨约束物仍按机构轨迹。高处提供观察/站位，不跨任务门或替代唯一人员路 | 进出体积只改变后续加速度，不重置速度或抬升物体；不得在跳跃顶点切相位。物件越界沿原合法回收规则，不凭空复制或传送玩家 |

风暴边界按设备实体位置、手持设备按持用者身体位置判定，不能从枪口或镜头跨线钻取屏蔽。落地工具移动后同样重验暴露区。首轮固定端口及应急接收控制使用已声明屏蔽线路，不随风暴断电；这不让同区域炮塔免疫。屏蔽只限明确类别，不是一个全能安全房，敌人仍能进入。

工业噪声不是现实分贝模拟。载噪条件是接收者位于登记声学区，且从轰鸣设备至接收者存在开放声学路径、传声系数1；关闭门后的敌人不因视觉上同房而获得掩蔽。将符合条件的行动声半径减半后，再按TP-WAKE沿真实路径计算。轰鸣本身每1s发中心10、半径12m的独立稳态刺激；停机停止未来脉冲。普通供电运行声不再给同一设备重复添加一份。预告不使用频闪、震屏或强制镜头效果；范围与阶段用实体状态及文字/图形同时表达。

掩蔽明确不作用于枪声、爆炸、近战命中/尸体倒下、近邻受击反应、重型冲击、投送落地、安保广播、近距接触、光照和任务域唤醒。Active追杀不衰减为休眠。同一声源根事件仍取最大贡献，不能先扣半径又扣中心刺激。运行噪声可能与玩家动作共同促醒，应在声学走读中计算，不承诺站在机器边一直安全。

积水只在带电阶段的第0、1、2秒判定接触，每次12基础伤害；同一实体即使多碰撞体也只受一次。玩家与敌人均适用，按现有有效伤害/部位规则结算；工具设备沿其合法受损规则，绝缘或不接触水面的设备必须明确登记，不能按敌我豁免。没有额外硬直、瞬间处决或传导链。总计最多9次脉冲，不能把三次资格计成三个无限循环。倒地者不能靠0.8m/s爬行保证逃离，因此救援必须能从干侧断电及搬离；排水不是首轮新增必修动作。此模型与裸母线电弧不同；同一位置不同时生成两份触电伤害。

低重力首轮不改变既有直线枪弹；抛投物按局部重力运动。投涌体的固定飞行时间与预告落点若跨重力边界尚无对应求解器，本配置直接拒绝该弧线，必须有另一条真实合法攻击路径，不能让其停摆。首轮映射不在影响区及跨区射线放置投涌体；其他候选以后单独验证。平地跳跃理论高度变为普通高度的1/0.6，回到同高度的飞行时间亦为1/0.6；净空、落点和高台仍须实体检查。倒地、搬运、物品、敌人追击和弹道未通过前，不因单个玩家能跳就批准配置。

## 内容准入与状态连续性

## 组合与验证顺序

ENV-MOD-PROTOTYPE · 受托建议；不改变M0至M4前置，不启动游戏实现。

先在同一小图对照正常环境与单项修正器，顺序为**电磁风暴 → 工业噪声周期 → 导电积水 → 局部低重力**。前两项验证行动窗口，积水验证路线/配电/诱敌，低重力最后验证额外空间成本。其他候选保留，不能因排序删除；首批不是商业首发清单。

| 组合 | 要验证的队伍决策 | 主要否决风险 |
|---|---|---|
| 电磁风暴 + 敌对安保 | 停机穿越，恢复前夺取控制或进入安全区 | 只剩原地等下一轮，或炮塔恢复无前兆击杀 |
| 低重力 + 浓雾沉降 | 低处隐蔽与高处观察/暴露之间选择 | 高台永久无伤、雾只惩罚玩家；只能在单项通过后试 |
| 工业噪声周期 + 密集休眠 | 协调行动窗口，决定搬运/破拆和同步清除时机 | 噪声全图唤醒或免费抹除所有行动声 |
| 导电积水 + 轮换供电 | 用配电改变安全路线，同时权衡可用防御 | 多个周期无共同可行窗口、必经区域无解 |

组合按实际总复杂度与相互作用评估，超过普通活动预算的组合只能作为明确标记的高级测试配置，不能因表中列出就直接发布。全域熄灯、风暴和浓雾等信息限制不得未经验证叠加到基本信息不可读；通风故障/浓雾与两种安保初态的重复或冲突必须在准入时解决。

验收记录任务/配置ID、提交或构建、Seed、人数、配装、输入、视角与设置，比较实际路线、布防位置、突入时机、资源使用、等待时间与失败原因。必须观察到修正器对应的真实选择变化；若差异只剩看不清、持续等待、全程绕开或固定唯一答案，则拒绝进入任务池并重做。当前没有这些实测记录，不能宣称好玩、成本低或可解性已通过。
