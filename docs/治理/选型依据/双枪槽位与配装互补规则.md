# 双枪槽位与配装互补规则

## 决定

WEAPON-SLOT-001 · 已确认 · 2026-09-06 · 权威来源：项目所有者。

Primary与Secondary是两个系统能力完全平等的枪械槽位。系统不为任一槽位附加更高伤害、更大弹量、更快切换、更小体积、更高持续作战能力或“多数房间都能用”等固有规则。两槽的区别只来自各自固定且互不混用的合法武器目录，以及玩家如何让整套配装互补。

Primary不是必然通用的主枪，Secondary也不是较弱的备用枪。任一槽都可以容纳突击步枪、手枪、霰弹枪、狙击枪、电磁穿透武器或其他高专精平台，只要该武器被明确归入对应目录。武器的威力、体积、拔枪、装填、储备、射速、操控和适用目标全部由武器Profile决定，不由槽位名推导。

## 配装平衡单位

WEAPON-SLOT-002 · CANON。

平衡和内容验证的最小单位是`Primary + Secondary + Tool + Personal Utility`整套配装，而不是要求每件装备单独全能。玩家应能用第二枪、团队工具和个人Utility补足第一枪留下的距离、目标体量、群体密度、穿透、潜行、控制或情报缺口；也允许玩家故意重复同一强项，并承担明显盲区。

典型合法思路包括：突击步枪负责稳定交火，另一槽携带低射速高单体伤害武器，Tool使用可部署盾，Utility使用小范围扫描器；或磁驱穿透武器负责排队敌群，另一槽携带精确点杀武器，Tool携带C4承担波次清除，Utility携带雾气干扰装置。示例只说明互补关系，不批准其中任何具体装备。

## 强弱约束

WEAPON-SLOT-003 · CANON DIRECTION / 数值TEST NOT RUN。

每把枪必须有可观察强项、实际代价和失败情境，但不存在“Secondary总体数值必须低于Primary”的预算。狙击平台可以极擅长处理大型敌人与暴露弱点，同时因低射速、低储备、过度击杀、近距困难和弱清群而具有较低综合覆盖率；这不是槽位惩罚，而是武器身份的成本。手枪可以凭操控、响应或弹药效率赢得位置，也不能仅因“Secondary应该有手枪”自动入选。

不得用两个平等槽位制造两把无短板万能枪。固定目录的目的，是形成可读的组合空间和可维护的内容边界，而不是建立武器等级。改装不得跨越目录，也不得抹除一把武器的核心失败情境。

## 已选目录与待验证内容

WEAPON-SLOT-005 · 固定目录与首轮受托选择已完成 / 数值与乐趣未测。

所有者于2026-09-06明确委托代理扩展并挑选第一批装备。两个[固定目录](../../内容/装备/装备完整候选库与首发筛选.md)与[首轮验证批次](../../制作/首轮装备原型与验证计划.md)已经完成，不再要求所有者逐项重新分配。目录规模不是固定配额；候选不等于全部量产，商业首发数量待实测收敛。

整套配装检查互补、重复职责、极端盲区和潜在必带。所有者不需要阅读全部排列组合；文档保留有代表性的走读和可执行测试。伤害、弹量、切换、射速、装填、操控、性能和实际乐趣仍未验证，完整体验开工Gate尚未自动关闭。

## 玩家自行承担配装取舍

WEAPON-SLOT-PLAYER-CHOICE · CANON · 2026-09-06 · 所有者本轮明确纠正。

游戏不提供双枪短板警告、互补评分、推荐配装或因角色缺口阻止出发；只如实说明单件装备的性能、用法、资源与合法性。这里“不教玩家如何搭配”不撤销按键、基础操作与可访问性说明。玩家可以重复专精、偏潜行或偏激战，承担后果；设计者内部仍检查数值换皮、无作用装备和任务硬锁，不把内部评估做成玩家教学。

盾的耐久、泡沫的承受量/耗材与C4有限装药是允许强协同的代价；不为强迫更换打法而暗增敌人、制造反制或判定覆盖一场有限战斗的准备为违规。低声枪/近战可选，静音不等于零触发，低声平台用较低伤害和较慢攻击节奏换潜行能力；不保证任意配装都有同等安静通关能力。

情报与补给细节由[个人装置目录](../../内容/装备/个人战术装置候选目录.md)和[团队工具目录](../../内容/装备/团队工具候选目录.md)拥有；数值、资源守恒和试玩仍需验证。
