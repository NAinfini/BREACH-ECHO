# 产品分叉与首发核心

## Context / User intent

用户最初同时想要GTFO式Operation与Roguelike，后来明确更偏高紧张、资源管理与合作，并问最终该选哪边；曾提出先做无Roguelike解谜本体。以上为原话摘要，不是最终批准Operation-only。

## Options considered

纯Operation无成长；Operation加少量局内变化；纯Descent；对等双模式首发；固定解谜本体后加Roguelike。

## Evidence / assumptions

源§4双模式是现有归档基线；GTFO与Rogue Core市场页面只证明相邻产品存在。任务层是否提高复玩尚无测试。

## Review recommendation

DDD-0001-REC · PROPOSED · 来源：本轮讨论评审；源依据见责任文档。

强烈推荐Operation-first Systemic Tactical Operation：明确任务、不确定局势、稀缺资源、团队执行；少量武器/工具改装，Descent留Lab/未来候选。固定谜底解谜不能自动提供长期复玩。

## Risks / tradeoffs

牺牲部分肉鸽玩家即时成长满足；需证明设施规划值得其等待/失败成本；单模式仍不自动降低枪感与合作难度。

## Decision status

OPEN：推荐未获明确最终确认；最新偏好是DIRECTION。
