# 地球重联与持续扩展规划

本文件保留后续内容方向，不是基础版缺项，不授权当前施工、采购、商业承诺或新增平台。未来规划不得因为尚未排期而在文档清理中删除；只有被明确替代的方案才能退出现行规划。

## 地球重联

地球、火星等社会没有因壁垒断联而自动灭绝；真实历史和知情边界由[正史圣经](../世界与叙事/世界观与正史圣经.md)维护。后续可通过恢复旧路线、重建联系，让壁垒发现太阳系仍然存在且独立发展了技术，再引入合作反攻虚空兽、灼星种等威胁的任务。具体重联节点、角色、战役顺序和结局尚未决定。

不把地球写成基础故事突然出现的救援解法，也不提前在常规任务中生成必须同步的个人战役进度。重联属于所有玩家共享的世界发展；如何发布须另定产品范围。

## 武器与敌人的持续扩充

DLC 可以增加每个武器家族的平台和新敌人。动能、电磁、有限能量块武器与近战已允许进入基础版候选，不能又写成“重联后才能首次使用”。后续先进武器可提供更强烈的战斗体验，但具体资源、代价、准入和跨内容平衡要随其任务环境设计，不能仅靠无条件数值上位淘汰基础枪械。

## 行星深潜

抵达虚空兽原生天体、灼星种世界或借尸者占领行星后开放 Roguelike 远征，完整流程只由[深潜模式](深潜未来模式.md)维护；[遗物与融合候选](深潜遗物与融合候选.md)保留构筑想法。地球重联与行星深潜是两条保留的扩展方向，尚未规定谁先发布，也不要求一次制作全部异族行星。

## 活动与赛季

日、周、月和临时修改规则行动的共同合同见[在线活动](../玩法/在线活动特殊挑战与赛季边界.md)。未来可以依托它们发布扩展前的联合行动与新内容；赛季通行证只是商业候选，价格、付费权益、周期和实际销售均未批准。

## 进入制作前

先确认基础循环的试玩结果，再选择一个明确扩展主题，确定内容池、资源预算、奖励边界、叙事审阅与发布条件。不因存在此文件而预建第二模式、第二套后端或完整赛季商城。
