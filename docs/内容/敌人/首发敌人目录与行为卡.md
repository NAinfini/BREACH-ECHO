# 首发敌人目录与行为卡

## 范围与首发生态

ENY-001 · DECIDED。

基础版先生产两组敌对来源：虚空兽与失控设施防御。灼星种、借尸者及其完整生态属于未来内容，不进入首发最小内容量。本文拥有敌人身份、行为、部位、反制和组合；数值唯一由[战斗试制参数](../装备/战斗原型数值.md)拥有，感知/决策/导航实现由[AI运行架构](../../技术/人工智能运行架构.md)拥有。

首个战斗切片只做逐能体与压射体；随后按固守体、缝行体、穿线体、探讯体、破阵体、投涌体以及三种设施单位的顺序逐个验证。八种常规虚空兽和三种设施单位都通过灰盒后，才制作正式网格、动画和音频。工作名用于制作，可在不改变角色合同时重命名。

虚空兽不掉弹药、货币或装备。战斗收益来自解除压力、开放世界资产、样本任务或保护回收物，不能把它们变成刷怪经济。休眠体是同一敌人定义的`Dormant`状态，不是廉价雕像；供电不立即统一唤醒，具体刺激见[遭遇规则](../../玩法/敌人遭遇与难度.md)。

探讯体必须在生成时绑定一个具体`CallBinding`。绑定到已启用且有余额的有限来源时，通信成功只提交一次来源请求；绑定到生成时已存在的传播群时，只把刺激传给该组，不创建实体；没有合法绑定、来源未启用、余额耗尽、入口封闭或通信在提交前被打断时，必须给可见失败反馈且不生成任何单位。一个通信不能按入口数量复制请求，Host Migration也不能重放已提交调用。

## 顶层状态与行为共同合同

ENY-004 · DECIDED。

虚空兽激活主状态为`Dormant / Stirring / Active / Displaced / Disabled / Dead`；`Stirring`是短暂苏醒前兆，击杀可阻止其完成，普通硬直不能暂停或重置倒计时，进入`Active`后本局持续追杀可达的存活玩家，不会调查、放弃、回巢或重新休眠。视线只影响攻击选择与瞄准质量，不决定是否继续追击；门和地形必须通过真实寻路拖延或永久隔离，敌人不得穿墙或传送。设施单位以`Standby / Tracking / Engaged / Isolated / HostileProtocol / Controlled / Disabled / Destroyed`表达自身协议，不套用虚空兽休眠语义。每次转换必须由合法唤醒、协议或任务事件触发，并记录原因。

多帧动作声明前摇、Commit点、恢复、合法取消和部位要求。攻击在Commit后即使敌人随后死亡也按已提交弹体/冲量结算；前摇中关键能力部位被破坏则取消并给明确反馈。行为树不能每次Think重启动画，也不能因LOD切换重置冷却或仇恨。

## 组合与内容最低量

ENY-005 · TEST。

首发完整内容目标为八种常规虚空兽、一个特殊猎界体和三种设施单位；这不是销售充分性或制作可行性已经通过的证明。组合按玩家行为目的构成：逐能体+压射体训练移动与掩体，固守体+缝行体制造前后决策，穿线体惩罚排队站位，探讯体+真实Source测试潜行因果，破阵体打开普通防线，投涌体迫使离开固定阵地，设施防御+虚空兽测试第三方交火。每个常规任务最多突出两个新角色，其余为已学会的支撑，不能一局同时教学全部十二种。

Relaxed到Cataclysm优先改变合法来源、组合、协同、资源和环境，不偷偷按Build加抗性。特殊猎界体只进入声明`PredatorReversal`的任务，不进入普通随机预算。限界区提高设施单位权重，无限区提高虚空兽来源与休眠体密度；相同Difficulty仍保持不同问题。

首轮三任务的五档数量、同场种类、重型与远程比例、设施上限及来源构成由[首轮任务难度、敌人和配装用途矩阵](../任务/首轮任务难度敌人与配装矩阵.md)唯一收敛。难度提高时必须先让玩家看见更多实体、更多职责、更多重型与远程火力组合；不得用环境Debuff或资源削减假装已经增加了敌人内容。

## 反馈与可访问性

ENY-006 · DECIDED。

每种敌人必须有独立轮廓、移动节奏、攻击前兆和非颜色唯一提示。压射前摇、探讯通信、猎界体接近、炮塔锁定至少同时有两类信号（形体/光形、声音、字幕/方向提示）；关闭声音后仍可反应，降低闪烁后仍能区分Commit点。受损部位在模型、动作和行为上同时改变，不能只换血条图标。

## 两类基础敌人的可读攻击与弱点布局

ENY-FIRST-ATTACKS · 2026-09-06，受托设计；参数TEST、实现NOT RUN。本文拥有动作与布局意图，精确时序、范围、倍率和完整度只引用[战斗原型数值](../装备/战斗原型数值.md)，不在这里复制。正式模型与物种外观不因此锁定。

### 逐能体：读懂逼近，在落击前离开攻击线

首轮只验证一种近击，不同时加入扑杀、抓取、旋转横扫和隐形冲刺。接近时靠正常步行/奔行追上目标；进入攻击先压低身体、抬起攻击肢，最后支撑肢扎稳、攻击方向固定，然后向先前位置打出。识别重点是“正在接近—准备挥击—已锁向”，不是记闪光颜色。

玩家可以在锁向后横移离开攻击扇区，也可以后撤至范围外、绕到背后或利用真实门框挡住接触。跳跃和蹲下只有在玩家实际碰撞体避开攻击形状时有效，不附送无敌时间。敌人不能在前摇最后瞬移、延长手臂或转头补命中；玩家也不能只靠占住路径点让敌人永远无法提交。

感知器放在正面上部的可辨识实体上，与躯干分离但不能小到只能靠发光像素定位；左右推进肢位于较低、偏外侧的位置。攻击准备暴露其支撑动作，便于选择削弱移动。两肢破坏收益不重复相乘。休眠姿态至少提供一个可接近的身体或感知器角度，不读取玩家松键时刻突然藏头。破坏感知器不消除持续追杀，因此它首先是精确击杀位置，不宣传为“打瞎后可安全走开”。

攻击落空后完整恢复，给玩家补刀、换弹或援护机会；不是只有打中时才恢复。多个逐能体可真实同时攻击，但需各自实体站位和可读动作，不能叠在一个位置、靠多个看不见的手臂同时造成伤害。也不增加幕后轮流出手配额来假装玩家躲开了。

### 压射体：用有限枪线迫使换位

先停步支撑、抬起发射器并展开器官，再进入锁向，随后发出固定目标点的短连射。轮内弹体可见、速度有限、不追踪；玩家横移或换掩体能够离开弹线。正对它直线后退通常不可靠。声学前兆、器官动作与弹体路径互相吻合，不依赖震屏、运动模糊或铺满屏幕的警告。

感知器在正面上部；发射器偏侧上方，与感知器保持清楚的空间区分；支撑肢在下部。发射器在准备时更容易瞄准，但不是平时无敌、只能按节拍开窗。玩家可以杀本体、拆发射器或切断枪线；没有一种专用武器是必选答案。

压射体恢复时重新寻找合法射线；玩家主动压近后，它不能无限后退、每次恰好保持玩家近战距离之外。若无射线则接近/改道，不持续隔墙更新射击点。发射器被拆后改用参数表的退化近击，保留明确前摇，不偷偷恢复远射。手持探测器只提供跟随点，不额外显示这三个器官。

### 混合战斗的通过条件

同一组“两个逐能体与一个压射体”至少检查四种真实处理：先杀近敌再换线；先拆远射器再处理逼近；破坏推进肢争取救援时间；用盾或泡沫暂时隔开压力。此组只是验收情境，不替代程序任务兵力预算，也不规定队伍必须带控制工具。

验收需分别记录：受击前能否指出哪一个动作预告了攻击；侧移是否实际离开命中几何；锁向后敌人是否偷改目标；瞄不同部位是否改变下一项决策。关闭声音、关闭装饰性屏幕效果、多人动作叠加时重复检查。玩家只能靠背伤害数字才能作决定、躲到掩体后仍被枪口穿墙击中、破坏器官没有可见行为变化，均为失败。上述结果全部待构建和真人测试，不以纸面走读代替。
