# 修改器如何进入任务：空间、反制与组合准入

## 本批的边界

MOD-MISSION-SCOPE · 2026-09-07受托DECIDED，参数TEST，实体和乐趣未测。本文拥有修改器与具体任务的绑定、组合清单和拒绝条件，不拥有枪伤、补给总量、任务阶段或第二套修改器定义。环境参数归[环境目录](../设施与资源/关卡环境修正器候选与验证.md)，活动资源/槽位归[活动目录](../活动/特殊活动修改器候选库.md)，动作/穿透强化归[强化目录](../活动/玩家与敌人强化修改器候选.md)。

先做四种环境、三种已授权趣味规则、两种低依赖强化的纸面配置。没有增加普通任务难度档、强制阶段或敌源。全部80项候选和未来Descent仍保留；这里的九项不是商业首发承诺，也不自动叠到现有十二个程序配置。以下三种状态严格区分：已写出候选；纸面允许进入测试；实体/多人/试玩后批准发布。当前只有前两种，批准发布数为零。

MOD-MISSION-ROSTER · 下表是本批绑定目录，成本引用各唯一候选定义。普通地点仅可单选环境；活动可单选或选择下方明确列出的组合。

| 修改器 | 类别 | 复杂度 | 目标绑定方式 |
|---|---|---:|---|
| MOD-EM-STORM | 环境 | 2 | 一个暴露体积及屏蔽维护侧；易受影响能力清单 |
| MOD-INDUSTRIAL-NOISE | 环境 | 2 | 一台排风设备、一个声学区、安全侧控制点 |
| MOD-CONDUCTIVE-FLOOD | 环境 | 2 | 一处积水、独立馈线、安全侧开关与干燥旁路 |
| MOD-LOW-GRAVITY | 环境 | 3 | 一个连续体积、地面路线与边界净空 |
| MOD-PRIMARY-OVERDRIVE | 活动 | 2 | 全局固定枪械槽与已提交攻击来源 |
| MOD-UNLIMITED-TOOLS | 活动 | 3 | 各Seat已公开的三种工具与实例名额 |
| MOD-INFINITE-ENERGY-PORTS | 活动 | 2 | 一个可选固定端口，不是全部有电设备 |
| MOD-FAST-HANDLING | 强化 | 1 | 当前九枪的指定动作阶段 |
| MOD-BODY-PIERCING | 强化 | 1 | 当前线圈穿透步枪与真实射线命中名单 |

## 货运：改工位，不把机器变成慢车护送

MOD-MISSION-FREIGHT · L编号来自[货运合同](货运线夺回任务合同.md)。两整备故障和最多一项不同类别动态异常保持不变；新增环境设备只承载可选路线选择，不增加第四个必做维修。

| 修改器 | 绑定位置/对象 | 玩家能改变什么 | 不得覆盖或移除 |
|---|---|---|---|
| MOD-EM-STORM | L06开放侧区及已有设施对照的唯一炮塔，L06维护工位屏蔽 | 停机穿射界、提前接管或走维护侧；必须已有该炮塔配置 | 磁轨、吊车、牵引/冷却控制、接收及必要扫描；不让货物停8秒等风暴 |
| MOD-INDUSTRIAL-NOISE | L03M维护线的排风段，独立于货运机械 | 借声移动和拨动本地机构，或关机/绕行 | 全吞吐域刺激、实际货运声与来源；隔离方案仍可安静 |
| MOD-CONDUCTIVE-FLOOD | L06人员短线的低槽，与货轨实体分隔 | 断电、走干侧或诱敌；先请求Pod再处理另一工位，不用站水里取包 | 货物/货轨、故障操作点、第二额度/医疗/接收点和L08；不让任务货因修改器无预告报废 |
| MOD-LOW-GRAVITY | L02仓储中庭的人员与自由搬物区，不含约束货轨 | 变换观察、投掷与站位；L03M保留地面路径 | 货批运动速度、装卸锁、货柜约束、人员退路；不能用低重力穿过尚未移开的货柜 |
| MOD-PRIMARY-OVERDRIVE | 全局配装；L05选方案至L07接收 | 双倍火力影响是否选全吞吐，但不替玩家自动选高噪方案 | 隔离零来源、有限吞吐来源与完成立即停源；空Secondary权益不补Primary |
| MOD-UNLIMITED-TOOLS | 全局三工具；L05预布置及L06前向工作 | 可频繁布胶/爆破保住人员接近线；满额要先结束旧效果 | 自主货运、伤员路线、设备HP及安全停靠；胶不把任务货物无限定住 |
| MOD-INFINITE-ENERGY-PORTS | L06动态工位前干侧的一处可选端口 | 在前进方向补Energy；端口与可选冷却收益的机会成本事前公开 | 目标货物最低冷却/压力、接收母线和主路Ammo；若无多余可用回路则拒绝此配置 |
| MOD-FAST-HANDLING | 全局九枪；L06换弹后处理异常 | 更快腾出后续行动空间，不让3秒安装变2.4秒 | 货物速度、故障提交和撤离速率 |
| MOD-BODY-PIERCING | 全局线圈；L06–L07货轨旁斜向射线 | 利用真实排线，不进入货轨或躲在不可达位置射击 | 货柜遮挡、侧翼接近线、厚甲终止；不强制把群全部排直 |

每处可选端口都是原ECO-ENERGY-PORT名额的具体落位，不再添第二份“活动端口”。条件缺失时应在作者配置/生成前拒绝，不在Run中临时免费开线路。风暴首轮保护这些端口的屏蔽控制，但普通断电、权限或毁坏仍可停用；“无限”不覆盖物理可用性。

## 组合：明确允许的测试组，不做自由乘法

MOD-MISSION-COMBINATIONS · 以下允许仅指纸面进入后续测试。简称在表内沿用正式ID；全三任务均须逐个绑定成功。普通预算4、高级6沿LIVEOPS-005，本批每组最多一项复杂度3，且最多一项新增环境；已有地点环境同样计入，不能免费再叠一项。

| 测试组合 | 修改器A | 修改器B | 等级 | 需要验证的相互作用 |
|---|---|---|---|---|
| 停机突入 | MOD-EM-STORM | MOD-PRIMARY-OVERDRIVE | 普通 | 枪可正常射击，炮塔停机只改真实射界压力；单Primary后段库存另算 |
| 轰鸣掩护 | MOD-INDUSTRIAL-NOISE | MOD-FAST-HANDLING | 普通 | 减少换弹空档但不隐藏枪声；行动声按真实阶段计算 |
| 带电侧路 | MOD-CONDUCTIVE-FLOOD | MOD-PRIMARY-OVERDRIVE | 普通 | 借环境伤害或直接打；不能据更高火力删干路/主路弹药 |
| 干扰下的工具 | MOD-EM-STORM | MOD-UNLIMITED-TOOLS | 高级 | 无限监测器仍停机、点标仍过期；胶与爆破保留有限并发 |
| 轰鸣与持续充能 | MOD-INDUSTRIAL-NOISE | MOD-INFINITE-ENERGY-PORTS | 普通 | 两者依映射位于不同工位；端口校准默认不获远处噪声掩蔽，不把全Site算一个声区 |
| 低重力整备 | MOD-LOW-GRAVITY | MOD-FAST-HANDLING | 普通 | 换弹更快不缩短滞空/落地与物件动作，边界仍有合法导航 |
| 单枪贯列 | MOD-PRIMARY-OVERDRIVE | MOD-BODY-PIERCING | 普通 | 仅选线圈时两效果同时兑现；四级衰减分别结算，无穿墙；选其他Primary合法但不获贯穿 |
| 工具下的整备 | MOD-UNLIMITED-TOOLS | MOD-FAST-HANDLING | 普通 | 枪械换弹加速不缩短爆破布置/泡沫喷射，名额不随切枪刷新 |
| 持续供能与整备 | MOD-INFINITE-ENERGY-PORTS | MOD-FAST-HANDLING | 普通 | 枪械换弹变快，端口2s不变；不把端口时间乘倍率 |

未列组合默认不进入本批，不等于永久否决创意。单项也要经过完整生成与试玩Gate。四个环境单项先按既定顺序对照，随后三种趣味单项、两种低依赖强化单项，最后上表组合；不一开始把九项全挂上。

## 冲突与禁止生成条件

MOD-MISSION-REJECT · 错误指出对象、位置和冲突原因；不删规则后继续、不退回普通任务骗过验证。下面的覆盖要求是生成器输入及未来负例，不是当前已存在的求解器。

| 拒绝码 | 条件 | 应如何重做作者配置 |
|---|---|---|
| 未登记映射 | 修改器不在本批，或不存在该任务的绑定行 | 先补内容合同和目标清单，不用全局Tag盲选 |
| 目标缺失 | 风暴炮塔配置不存在、固定端口/开关/体积缺失，或数量不是所声明值 | 修改作者配置；不能为通过验证凭空补敌人或给免费电力 |
| 预算超限 | 普通总成本>4、高级>6，或本批多于一项成本3 | 减少已选规则；不通过改名降低成本 |
| 未列组合 | 两项不在组合表、三项以上、重复同ID/别名 | 分开验证；不能“最后覆盖” |
| 关键能力受损 | 唯一任务读头、应急接收、证据、最低冷却、主路资源或撤离能力被环境关闭/摧毁 | 缩作用体积、隔离回路；不能临时送新钥匙 |
| 危险封路 | 最坏相位无干侧/屏蔽/地面人员路，必须吃伤或等周期才能推进 | 在原空间加入有代价但合法的前向路线，不送无敌/传送 |
| 操作自锁 | 隔离开关、充能接入、必要维修或救援接近线在其自身不可规避危险内 | 将控制放到安全侧，保留实际敌人压力而非取消战斗 |
| 双重触电 | 同一接触区同时套裸母线电弧与导电积水 | 只选一个伤害模型，独立位置须另建高级配置 |
| 供电争写 | 轮换供电+能源欠载；同一馈线多规则无确定恢复顺序 | 用一个供电状态Owner和明示分支，不叠两个Enabled开关 |
| 感知矛盾 | 风暴+地图盲区/熄灯/传感回波未经专案；通风故障与浓雾重复；识别故障与敌对安保争写阵营 | 保留一种可读信息题；共同介质只一份状态，阵营只一个Owner |
| 时序矛盾 | 快速整备与紧凑弹匣/其他未声明动作缩放共同写换弹；依赖两个周期恰好同时安全 | 明确合成再验证；本批不批准靠等共同相位完成唯一任务 |
| 资源伪造 | 无限工具叠按支出退款/回收、无限端口兑换额度、禁槽补量转移 | 零支出不触发回收；改公开奖励条件，不用假扣费补回 |
| 交战合同改写 | 环境/普通失败新增来源、全图唤醒、取证必报警、隔离货运被改全吞吐 | 保留原交战合同与有限名单；要改任务身份必须另审 |
| 跳跃越权 | 低重力跨权限门/阶段、物件落进不可回收区、敌人无到达或攻击路径 | 修几何及实体约束；不能靠敌人瞬移或空中隐形墙 |
| 证据失真 | 取证环境破坏最低独立证据，或把本局干预结果当事故前记录 | 保护锚点与作者真相，分开现场状态和历史事实 |
